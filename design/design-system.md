## 1. Палитра

| Роль | Hex | Применение |
|---|---|---|
| Фон | `#0E0E0E` | Фон страницы. Единственный фон. |
| Поверхность карточек | `#1A1A1A` | Карточки, поля форм, модальные окна, контейнеры. |
| Линии | `#2A2A2A` | Все границы, разделители, обводки в покое. 1px. |
| Текст основной | `#F5F5F5` | Заголовки, основной текст, значения метрик. |
| Текст приглушённый | `#8C8C8C` | Лейблы, подписи, второстепенный текст, плейсхолдеры. |
| Акцент | `#D4FF33` | Один сигнальный цвет: CTA, активные состояния, ключевые числа, прогресс. |

Функциональный (не бренд-акцент): `#FF5C5C` — только текст и рамка ошибки валидации формы. Не появляется в кнопках, заголовках, индикаторах прогресса, иконках навигации.

Светлой темы нет. Продукт тёмный всегда.

## 2. Шрифты

- Заголовки: **Archivo Black** (Google Fonts), вес 900. Только для display/H1/H2.
- Текст: **Archivo**, вес 400 (текст) и 500 (выделения, подписи к кнопкам внутри текста). Одна типографическая семья на заголовки и текст — это пара.
- Моно: **JetBrains Mono**, вес 400 (значения, код) и 500 (лейблы капсом). Для всех чисел, метрик, тегов, лейблов, навигации, статус-строк.

Числа всегда в JetBrains Mono — включая внутри обычного текста, если это метрика (VPIP, BB, %, $).

### Размерная шкала

| Токен | Размер | Шрифт / стиль | Где |
|---|---|---|---|
| display | 64px / 4rem | Archivo Black, line-height 1.05, letter-spacing −0.02em | Hero-заголовок, ключевая метрика на карточке разбора |
| h1 | 40px / 2.5rem | Archivo Black, line-height 1.1 | Заголовок страницы |
| h2 | 28px / 1.75rem | Archivo Black, line-height 1.15 | Заголовок секции |
| h3 | 20px / 1.25rem | Archivo 500, line-height 1.3 | Заголовок карточки, подзаголовок |
| body | 16px / 1rem | Archivo 400, line-height 1.5 | Основной текст, реплики диалога |
| small | 14px / 0.875rem | Archivo 400, line-height 1.5 | Вторичный текст, описания |
| label | 12px / 0.75rem | JetBrains Mono 500, uppercase, letter-spacing 0.08em | Лейблы полей, навигация, теги, статус-строки |

Контраст обязателен: display/h1 всегда соседствуют с label/small на том же экране. Промежуточных размеров (18px, 24px, 32px) нет.

## 3. Геометрия

- Скругления: `0px` везде, без исключений. Кнопки, карточки, поля, модальные окна — прямые углы.
- Толщина линий: `1px solid`. Цвет в покое — линии `#2A2A2A`. Цвет в активном/фокус-состоянии — акцент `#D4FF33`.
- Тени: `box-shadow` с затемнением запрещён. Глубина — только через 1px-границы и точечное гало акцентом: `box-shadow: 0 0 24px rgba(212, 255, 51, 0.25)` — исключительно для focus и active-состояний.
- Базовый шаг отступов: `8px`. Шкала: `8 / 16 / 24 / 32 / 48 / 64 / 96`. Любой `margin`, `padding`, `gap` — кратен 8.

## 4. Компоненты

### Кнопка главная (primary)

- Покой: фон `#D4FF33`, текст `#0E0E0E`, рамка `1px solid #D4FF33`, padding `12px 24px`, шрифт JetBrains Mono 500 12px, uppercase, letter-spacing 0.08em, radius 0.
- Hover: фон `transparent`, текст и рамка `#D4FF33` (инверсия). `transition: 150ms ease-out`.
- Active/pressed: фон `#B8E600` (лайм затемнён на ~10%), текст `#0E0E0E`, `transition: 80ms ease-out`.
- Disabled: `opacity: 0.35`, hover отключён, курсор `not-allowed`.

### Кнопка вторичная (secondary)

- Покой: фон `transparent`, текст `#F5F5F5`, рамка `1px solid #2A2A2A`, padding `12px 24px`, тот же шрифт что у primary.
- Hover: рамка `1px solid #D4FF33`, текст без изменений. `transition: border-color 150ms ease-out`.
- Active/pressed: фон `#1A1A1A`.
- Disabled: `opacity: 0.35`.

### Поле формы

- Лейбл: над полем, JetBrains Mono 500 12px, uppercase, letter-spacing 0.08em, цвет `#8C8C8C`, margin-bottom 8px.
- Покой: фон `#1A1A1A`, рамка `1px solid #2A2A2A`, текст `#F5F5F5` (Archivo для текста, JetBrains Mono для чисел), padding `12px 16px`, radius 0.
- Focus: рамка `1px solid #D4FF33`, гало `box-shadow: 0 0 0 3px rgba(212, 255, 51, 0.15)`. `transition: 100ms ease-out`.
- Ошибка: рамка `1px solid #FF5C5C`, текст ошибки под полем — `#FF5C5C`, small 14px.

### Карточка

- Покой: фон `#1A1A1A`, рамка `1px solid #2A2A2A`, padding 24px, radius 0.
- Hover (только если карточка кликабельна): рамка `1px solid #D4FF33`. `transition: border-color 150ms ease-out`.
- Active/pressed: фон `#202020`, рамка `#D4FF33`.
- Некликабельная карточка не имеет hover-состояния.

## 5. Анимации

Бюджет: 2–3 типа анимации на экран. Не больше.

1. **Hover-переход границы/цвета** на кнопках, карточках, полях — `150ms ease-out`. Один тип на весь интерфейс, не считается отдельно для каждого элемента.
2. **Фокус-гало** на полях форм — появление `box-shadow`, `100ms ease-out`.
3. **Появление метрики/результата парсера** — `opacity 0 → 1` + `translateY(8px → 0)`, `300ms ease-out`, один раз при загрузке данных.

Запрещены: parallax, скролл-триггеры, бесконечные/циклические анимации (pulse, spin, bounce) кроме явного индикатора загрузки в виде статичного моно-текста с динамическими точками (`...`).

## 6. Запрещено

| Запрет | Почему |
|---|---|
| Фиолетово-синие градиенты | Визуальный штамп «AI-стартап» 2023–2024 годов. Градиент из двух цветов автоматически создаёт второй акцент и разрушает правило «один сигнальный цвет = вся смысловая нагрузка». |
| Эмодзи вместо иконок | Эмодзи рендерятся по-разному на разных ОС и не управляются цветом/размером как остальная типографика. Противоречит тону «аналитический инструмент, не казино» (`.business/assets/brand-guidelines.md`). |
| Третий шрифт | Пара Archivo (заголовки/текст) + JetBrains Mono (числа/лейблы) покрывает все роли. Третий шрифт ломает контраст «технический фон / выразительный передний план» и увеличивает вес страницы. |
| Второй акцентный цвет | Один сигнальный цвет несёт всю смысловую нагрузку (CTA, ключевые числа, прогресс). Два акцента распыляют внимание — интерфейс выглядит «раскрашенным», а не спроектированным. |
| Стоковые картинки | `.business/assets/brand-guidelines.md` запрещает покерный гламур и рекламную эстетику. Героическая визуальная единица в этой системе — диаграмма или график данных, а не фотография. |
