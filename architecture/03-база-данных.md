# База данных

## Черновик

*Здесь должны появиться: выбор СУБД и обоснование (PostgreSQL vs SQLite на старте);*
*стратегия миграций (Prisma Migrate); политика хранения HH-файлов (сырой файл vs распарсенные данные);*
*накопление baseline (как «твой средний» считается из загруженных сессий);*
*индексы для частых запросов (поиск похожих рук по позиции / стеку / улице);*
*план для «первого расширения» — хранение полной истории (10K–100K+ рук).*
