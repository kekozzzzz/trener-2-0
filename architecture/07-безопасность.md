# Безопасность

## Черновик

*Здесь должны появиться:*
*— аутентификация (как пользователь входит, хранение сессий);*
*— авторизация (пользователь видит только свои сессии и руки);*
*— защита API-ключей Claude и Stripe (env-переменные, никогда на клиент);*
*— валидация загружаемых файлов (только .txt/.hh, размер, санитизация);*
*— rate limiting на загрузку файлов и вызовы Claude API (защита от перерасхода);*
*— GDPR-минимум: что храним о пользователе, политика удаления данных.*
