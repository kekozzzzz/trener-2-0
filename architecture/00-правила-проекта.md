# Правила проекта

## Черновик

*Здесь должны появиться жёсткие инварианты, которые нельзя нарушать ни в одном PR:*
*— парсер считает числа детерминированно, LLM только объясняет;*
*— сократовский вопрос «почему» идёт до показа оценки (никогда после);*
*— никакого кода в продакшне до подтверждения спроса незнакомцами;*
*— публичный деплой только после рабочего парсера (не на LLM-угадайке);*
*— MVP строго под MTT GGPoker, без расширений до первых платных.*
