# Что строим

## Одно предложение

Сократовский тренер для микролимитного турнирного игрока GGPoker, который разбирает его вчерашний турнир за 20–30 минут: находит раздачи где он терял деньги, спрашивает «почему ты так сделал?» — и показывает, что именно стоило ему этого турнира.

## Какую проблему закрываем

Сыграл турнир, пришёл в минус — и снова не знаешь, что именно пошло не так. Коуч стоит $80+ за час, при банкролле $200 это нереально. Трекер показывает цифры — но не объясняет, почему ты именно так играл и что с этим делать. Форум долго, и там разбирают абстрактные ситуации, а не твои конкретные раздачи. В итоге завтра повторяешь те же ошибки — просто потому что сегодняшние так и не разобрал.

## Для кого

Микролимитный турнирный игрок GGPoker. Банкролл $100–500. Играет 3–7 дней в неделю. Приходит к продукту на следующее утро после проигрышного турнира — когда эмоции улеглись и хочется понять, что именно пошло не так, не на ощупь, а с числами.

## Что входит в первую версию

1. **Загрузка одного HH-файла GGPoker** (MTT, включая bounty-турниры) — вручную, через браузер
2. **Три метрики турнира** — VPIP, количество рук, итог (±бай-ины) — каждая в формате «вчера · твой средний · оптимально»
3. **Стилевой диагноз одной фразой** — лузовый / тайтовый / пассивный / агрессивный — по числам из парсера, не угадывается LLM
4. **~10 раздач за турнир** в адаптивном соотношении:
   - **Критические (~3)** — наибольшие потери → полный сократовский диалог: ситуация → «почему ты так сделал?» → ответ игрока → разбор + как лучше
   - **Сильные (~2)** — лучшие решения турнира → короткое подтверждение без принудительного диалога
   - **Средние (~5)** — серая зона → ситуация + «можно было чуть иначе» + полный разбор по желанию
5. **Чат** — задать любой вопрос по любой разобранной раздаче в контексте этой руки
6. **Аккаунт пользователя** — регистрация и вход (email + пароль)
7. **Подписка $12/мес** — платёжная система, управление подпиской
8. **Хранение турниров на сервере** — каждый загруженный турнир сохраняется в базе данных; «твой средний» по VPIP и другим метрикам накапливается из реальных загрузок, а не берётся из общих ориентиров

## Что НЕ войдёт в первую версию

- **Другие румы** — только GGPoker. PokerStars, PPPoker — позже
- **Кэш-игры** — только турниры (MTT). Кэш — после рабочего турнирного парсера
- **Автоматический мониторинг папки** — только ручная загрузка. Анализ в момент тилта вредит, не помогает
- **Массовый импорт истории** (10К–100К+ раздач одним файлом, то есть сразу нескольких турниров «сессией») — турниры хранятся на сервере, но загружаются по одному
- **GTO-солвер** — LLM-разбора достаточно для микролимитной аудитории
- **Геймификация** — стрики, accuracy score, лидерборды — после первых платных
- **Визуализация прогресса** — графики трендов по турнирам — следующий этап после накопления истории
- **Социальные функции** — поделиться разбором, Discord-интеграция
- **Несколько тарифов** — только один тариф $12/мес. Тиры вводятся когда пользователи упираются в лимит
- **B2B (покерные фонды)** — только прямые пользователи

## Готово, когда

**Работает:**
- Незнакомый человек может зарегистрироваться, оплатить $12/мес и войти в продукт
- Пользователь загружает HH-файл GGPoker (MTT) → видит карточку с тремя метриками, стилевым диагнозом и ~10 раздачами
- По критическим раздачам работает полный сократовский диалог: ситуация → «почему ты так сделал?» → разбор + что лучше
- Чат по любой руке отвечает в контексте именно этой раздачи
- Все числа (VPIP, потери по рукам, стиль) считает парсер детерминированно — LLM получает готовые данные и только объясняет
- Турниры хранятся на сервере; «твой средний» накапливается из реальных загрузок

**Пока не жду:**
- Точных персональных средних до накопления ~10+ турниров — пока их мало, показываем ориентиры для микролимитов с явной пометкой
- Мгновенной реакции на новый файл без клика
- Визуализации прогресса по истории турниров

## Журнал решений

**Сократовский диалог оставлен в ядре MVP, не срезан ради упрощения** — это единственное, чего нет ни у одного конкурента: все останавливаются на «покажи ошибку», но не спрашивают «почему». Без этого продукт падает обратно в категорию трекеров, которых уже десяток. Детерминированный парсер для чисел выбран вместо LLM-расчёта — один неправильный разбор, ушедший скриншотом, закрывает репутацию в маленьком покерном сообществе до того, как продукт наберёт аудиторию.
