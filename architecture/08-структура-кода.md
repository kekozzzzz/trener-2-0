# Структура кода

## Черновик

*Здесь должна появиться структура папок с объяснением назначения каждой:*
*— где живёт парсер HH-файлов (отдельный пакет / src/parser);*
*— где живут промпты для Claude (src/prompts или рядом с фичей);*
*— где живут API-роуты;*
*— соглашения об именовании файлов, компонентов, функций;*
*— где находятся тесты (unit для парсера — обязательно, интеграционные для диалога);*
*— как добавляется новый тип покерного клиента (PokerStars и др.) без переписывания ядра.*
