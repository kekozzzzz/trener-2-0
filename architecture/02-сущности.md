# Сущности

## Черновик

*Здесь должны появиться доменные сущности и их отношения:*
*User, Session (один турнир = один HH-файл), Hand (раздача), HandLevel (critical / strong / medium),*
*SessionMetrics (VPIP, количество рук, результат), PlayerProfile (стилевой паттерн),*
*Dialogue (обмен в сократовском диалоге по руке), ChatMessage (вопрос в свободном чате).*
*Для каждой сущности — поля, типы, связи, бизнес-инварианты.*
