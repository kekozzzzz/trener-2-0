# Потоки данных

## Черновик

*Здесь должны появиться сквозные потоки:*
*1. Загрузка файла → парсер → SessionMetrics + список рук → выбор 10 раздач по уровням;*
*2. Критическая рука → показ ситуации → ввод «почему» → Claude API → разбор + что лучше;*
*3. Свободный чат → контекст раздачи + история диалога → Claude API → ответ;*
*4. Накопление baseline (каждая новая сессия обновляет «твой средний» по пользователю).*
*Для каждого потока — входные данные, преобразования, выходные данные, кто отвечает (парсер vs LLM).*
