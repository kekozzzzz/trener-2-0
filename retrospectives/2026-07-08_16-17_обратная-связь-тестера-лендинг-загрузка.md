# Ретроспектива — правки по обратной связи тестера (лендинг, загрузка, разбор)

**Дата:** 2026-07-08

## Задача
Разобрать docx с замечаниями живого тестировщика (4 скриншота со стрелками) по сайту whygrid.app и пошагово исправить.

## Что было в документе (5 замечаний)
1. Кнопки «Войти» и «Регистрация» в шапке — незаметны, «не сразу интуитивно понятно».
2. Геройский блок переписать короче и конкретнее с первой строки; «терять деньги» — слишком общо.
3. В «Как выгрузить руки» добавить скриншоты со стрелками.
4. На загрузке нельзя перетащить файлы — только через кнопку.
5. Разбор долгий, «кажется, как будто зависло» — хочется времени/прогресса.

## Как решал
- **№1** `components/auth-nav.tsx`: «Войти» → кнопка-рамка (была текст-ссылка), «Регистрация» → залитая акцентом (была маленькая рамка `sm`). Обе полного размера.
- **№2** `messages/{ru,en}.json` `Landing.heroTitle/heroSubtitle` (вариант А, выбрал Артём): «Разбор твоих раздач - вместо дорогого тренера» + подзаголовок в одну ёмкую строку.
- **№3** — отложено по решению Артёма («потом найдём» скрины). Текстовая инструкция по румам оставлена как есть.
- **№4** `components/upload/file-input.tsx`: drag-and-drop. Брошенные файлы кладём в сам `<input>` через `DataTransfer` (иначе server action их не увидит), подсветка зоны при наведении, тихая подсказка «или перетащи файлы прямо сюда». Новые строки словаря `FileInput.dropHint/dropNow`.
- **№5** `app/tournament/[id]/analysis-progress.tsx`: успокаивающая строка «разбор идёт на серверах, это нормально, не зависло» + честная оценка остатка по РЕАЛЬНО наблюдаемой скорости (не выдуманные «10с/раздача»). Новые строки `AnalysisProgress.reassurance/etaAbout/etaUnderMinute`.

## Решил: да (4 из 5; №3 отложен намеренно)
- Типы `tsc --noEmit` — чисто. JSON валиден. Линтер в проекте не настроен (`next lint` предлагает интерактивную настройку). Полная `next build` из облака не запускается (пререндер лендинга лезет в БД, доступа нет).

- Заголовок при желании отшлифовать после живого просмотра.
