# Ретроспектива 2026-08-15 — SEO, шапка сайта, соцсети

## Задача

Артём: «никто не видит наш сайт» → полный SEO-аудит и правки. По ходу сессии выросло в
несколько связанных тем: перелинковка и контент, страницы по румам, соцсети (Telegram/
Instagram/TikTok) на сайте и в разметке, редизайн шапки, замена термина «парсер», описания
каналов.

## Как решал

1. **SEO-аудит.** Проверил вживую через браузер (Playwright, впервые доступен в этой
   сессии) + код. Диагноз: техника (robots/sitemap/canonical/JSON-LD/IndexNow/llms.txt) в
   порядке, причина невидимости — молодой домен без обратных ссылок (подтверждено WebSearch
   по нескольким темам). Нашёл реальный технический дефект: гайд-кластер (`/range`,
   `/push-fold`, `/icm`, `/leaks`, `/hand-review`, `/ggpoker`) не был связан ни с главной
   навигацией, ни с `/charts` — сиротки, находились только через sitemap.
2. **Перелинковка + контент.** Хаб-секция на `/charts` (все 6+1 ссылок), заполнил страницы
   без исходящих ссылок, нарастил 4 самые тонкие страницы новыми H2-секциями — каждая на
   теме с двойной опорой (реальный код продукта `isBountyTournament()` + подтверждённый
   внешний факт про GGPoker). Отклонил находку про срок хранения истории в PokerCraft —
   источник не подтвердился первичным ресурсом.
3. **8 страниц по румам.** По просьбе Артёма («инструкции по выгрузке тоже в SEO») —
   один динамический роут `/how-to-export/[room]` на базе `SUPPORTED_ROOMS`, а не 8 файлов.
4. **HowTo-разметка + sameAs.** Нашёл и почистил старое ограничение в `structured-data.tsx`
   («свободный текст в JSON-LD не кладём — React экранирует &») — правильным приёмом
   (`\uXXXX`-эскейпы), не обходом. Это разблокировало разметку с реальным текстом шагов.
5. **Иконки соцсетей.** Telegram/Instagram/TikTok — сначала в футере, потом (по заказу
   Артёма) ещё и в статус-баре шапки. Единый источник `config/social.ts`. Ссылку на
   Instagram Артём дал сам (с трекинг-параметрами — почистил до канонического вида).
   TikTok — тоже по его ссылке; иконку (сложная геометрия, музыкальная нота) нарисовал сам
   и проверил скриншотом перед тем, как класть в код — совпало с настоящим логотипом.
6. **Меченая ссылка для TikTok.** `config/acquisition-sources.ts` — тот же паттерн, что
   у остальных источников.
7. **Редизайн шапки + правки «Разбор изнутри».** Артём прямо попросил не соглашаться молча,
   спорить, если есть контраргументы. Разобрал каждое из двух его замечаний по существу:
   - «Окно» стола — отбил (это доказательство заявления «настоящие экраны, не мокапы»,
     решение уже принималось 09.08) — оставил как есть.
   - Подпись второго окна без номера раздачи — согласился, поправил.
   - «[ Рис. 01 ]» под столом/сеткой — контраргумента не нашёл (нумерация нигде не
     цитируется в прозе, функции техдокументации не несёт) — согласился и убрал.
8. **«Парсер» → «алгоритм».** Артём: слово непонятно обычному человеку. Разведал масштаб —
   оказалось, слово ещё и в промптах ИИ и в самом Rule 1 из CLAUDE.md. Разделил зоны: сайт
   меняем, промпты/код-комментарии/llms.txt — нет (отдельное разрешение, ИИ слово понимает
   нормально, пользы посетителю ноль). Переписал 19+18 мест по смыслу, не механической
   заменой — местами перестраивал фразу целиком, а не только слово.
9. **Описания каналов.** TikTok/Instagram bio — переписал без «парсер». Telegram — нашёл,
   что запланированный ещё в июне текст так и не был применён на живом канале (там до сих
   пор старый отклонённый тэглайн «Почему ты сливаешь») — отдал текст заново.

## Решил (да/нет/частично)

Да, по всем пунктам — включая находки, которые не были частью исходного запроса
(орфан-кластер гайдов, старая иконка Telegram задублирована в коде, живой bio Telegram не
совпадал с планом, «[ Рис. NN ]» оказался не метафорой Артёма, а буквальным текстом).

## Что лучше сделать (уроки)

- **Live-браузер меняет качество аудита.** Раньше SEO-работа шла по коду вслепую; сегодня
  прямой просмотр (с очисткой кук — иначе видно admin-версию сайта) вскрыл вещи, которые
  грепом не найти (сиротский кластер, старый Telegram bio).
- **«Найди контраргумент, а не соглашайся» — рабочий режим, не разовая просьба.** По двум
  из трёх замечаний Артёма нашёлся реальный контраргумент (оба увязаны с прошлыми
  решениями 09.08 из журнала дизайн-системы), по одному — не нашёлся, и это тоже нормальный
  результат, не поражение.
- **Механическая замена слова — плохая идея для готовых фраз.** «Парсер - код» → «алгоритм
  - код» звучало избыточно; пришлось читать предложения целиком.
- **Скриншоты Playwright в этой среде — ненадёжны** (`target`/`clip` иногда пустой чёрный
  кадр без ошибки) — рабочий обход: `page.screenshot()` без clip после ручного `scrollTo`.
  Записано в память отдельно.
- **Не доверять «раз это в файле — значит уже проверено».** Готовый caption для TikTok взят
  из `.business/marketing/` без сверки с правилом «подпись ≠ пересказ» — файл был написан
  до того, как правило появилось. Пришлось переписывать второй раз.

## Как стало

- 8 коммитов и пушей за сессию, все с меткой `[тихо]` (локальная сессия).
- Сайт: гайд-кластер связан, контент нарастили на 4 страницах, 8 новых страниц по румам,
  HowTo-разметка, соцсети видны в шапке и футере, слово «парсер» нигде не осталось.
- Три соцсети (Telegram/Instagram/TikTok) — с рабочими описаниями и меченой аналитикой.
- Справочники `.business/marketing/messaging.md` и `telegram-channel.md` синхронизированы
  с решением по «парсер».
