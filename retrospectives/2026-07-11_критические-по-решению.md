# 2026-07-11 — Критические по решению + движок веток в промпте

## Задача

Раздачи с тяжёлым решением без денежного следа (крупный фолд, выигранный блеф, недобор,
пограничный колл) не попадали в критические — отбор смотрел только на потерю фишек и
вскрытие. Запрос Артёма: отбирать и по весу решения. Плюс договорённость: вся промпт-часть
движка альтернативных веток (построен соседней сессией) — на этой линии, одним деплоем.

## Как решал

1. Замер по 85 турнирам из Test/ ДО кода: ~4 тяжёлых решения на турнир проваливались.
2. `parser/decision-weight.ts` — 5 детерминированных каналов + вес решения (банк+цена в
   точке решения) + `renderCriticalReason` (блок «почему раздача в разборе»).
3. Квоты потолка 7 в classify.ts: потери ≤5, решения ≤2, свободный остаток по цепочке.
4. `parser/alt-facts.ts` — один заход всего движка веток в снимок стола (все 4 роли);
   отдельный модуль, чтобы не словить циклический импорт с facts.ts.
5. Причина отбора в промпты разбора/диалога/вердикта; фреймворк: «критическая — не всегда
   про потерю», «ветки — числа, не вердикт», «доля диапазона, не частота раз» (обе строки).
6. Калибровка BIG_FOLD по глазам Артёма: список 20 кандидатов из его турниров → фильтр
   «было за что держаться» (своя пара+/живое дро/карманная пара/крупное своё вложение);
   канал ужался 4.1 → 2.0 на турнир, итог критических 5.7/турнир.

## Решил? Да

910 тестов зелёные (34 новых), tsc чист, боевой билд прошёл. Пример боевого промпта и
замеры лежат в Test/audit/. Задеплоено по команде Артёма.

## Что можно лучше

- Полный прогон тестов валился на негейтованном manual-генераторе таблицы эквити
  (наследство соседней сессии) — гейт по env добавлен; впредь проверять, что manual-тесты
  гейтованы, сразу при их создании.
- Параллельный `next build` рядом с бегущим vitest дал ложный провал пререндера — сборку
  гонять одну, не в параллель с тестами.
- В замер-прогонщике сначала жила копия логики каналов — после калибровки переведён на
  боевой `decisionMarks`, чтобы не было двух правд.

## Как стало

Тяжёлые фолды (JJ в 3-бет-поте, трипс против олл-ина, AA префлоп), выигранные блефы и
недоборы теперь всплывают в критические с честной причиной для тренера; тренер получает
числа непройденных веток и форму агрессии, но вердикт по-прежнему выносит сократовским
диалогом по диапазону — из точки решения, не по вскрытию.
