# Голосовой ввод ответа (микрофон в поле)

**Дата:** 2026-06-25
**Зачем:** игрок может не печатать ответ на сократовский вопрос, а надиктовать его
голосом. Снижает трение, особенно с телефона. Запускаем на первых платящих игроках.

## Развилка движка (решено)

Звук в текст превращает «расшифровщик». Решение Артёма — **Yandex SpeechKit**:
из РФ работает, отличный русский, звук остаётся в РФ-контуре, ложится в адаптеры
(правило 4). Браузерный Web Speech API отвергнут как боевой — гонит звук через
Google, из РФ недостижим.
