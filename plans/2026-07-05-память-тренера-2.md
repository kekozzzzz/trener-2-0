# Память тренера 2.0 — окно на турниры, «та же ошибка», конкретика в подаче

Дата: 2026-07-05. Запрос Артёма: память тренера должна реально срабатывать и звучать конкретно —
«ты в прошлый раз, такого-то числа, был в такой же ситуации и ничего не поменял». Бэкафилл старых
раздач НЕ делаем — работаем для новых загрузок.

## Проблема

1. Окно поиска — последние 200 раздач (~1-2 турнира), похожие споты почти не находятся.
2. Похожесть только по отпечатку спота (5/6 признаков) — постфлопные критические раздачи
   (доезды) почти никогда не набирают порог.
3. Даже найденное подаётся как «используй, если естественно» — тренер молчит.
4. Про прошлую раздачу нечего сказать конкретного: нет даты, нет вердикта прошлого разбора.

## Решение (Правило 1 цело: всё находит парсер/код, ИИ только проговаривает)

### Фаза 1 — метки ошибок на раздаче (при парсинге)
- [x] `features/memory/spot-marks.ts`: computeSpotMarks(snapshot) — переиспользует
      countLeaks (8 префлоп-ликов) + detectHeroLuckyWin (доезд: крупное вложение с эквити <33%).
      Метки пишутся в тот же JSON `hand.spot` рядом с отпечатком (`marks`), схема БД не меняется.
- [x] `parse-tournament.ts`: сохранять `{ ...fingerprint, marks }`.

### Фаза 2 — окно поиска: последние 100 турниров, двухфазный запрос
- [x] `config/memory.ts`: MEMORY_SCAN_TOURNAMENTS=100, потолок раздач, порог 5/6, топ-3.
- [x] `similar-spots.ts`: фаза A — лёгкая выборка (id+spot) раздач последних 100 турниров;
      скоринг в памяти; фаза B — детали (tableData, диалог, вердикт, турнир) только для топ-3.

### Фаза 3 — канал «та же ошибка»
- [x] Кандидат попадает в выдачу, если совпал отпечаток (≥5/6) ИЛИ совпала метка ошибки.
      Ранжирование: один-в-один → та же ошибка → похоже; свежие выше при равенстве.
- [x] PriorSpot: + matchLevel "SAME_MISTAKE", + mistake (человеческая метка), + verdict
      (вердикт прошлого разбора, обрезан), when = дата + турнир.

### Фаза 4 — подача в промпте диалога
- [x] renderPriorSpots: дата, что сделал, чем кончилось, что игрок тогда ответил,
      вердикт прошлого разбора.
- [x] Инструкция: при [один в один] / [та же ошибка] тренер ОБЯЗАН сослаться конкретно
      (дата, что было, «что изменилось?»), один раз за диалог, без лекции. Выдумывать нельзя.

### Фаза 5 — тесты и проверка
- [x] Тесты: spot-marks (лимп/доезд/чисто), selectSpotPicks (ранжирование, каналы, порог, топ-3).
- [x] Полный прогон vitest + tsc + build.


## Итог

Сделано полностью 2026-07-05, все тесты зелёные (686), tsc и build чистые. Память ищет по
последним 100 турнирам двухфазным запросом (лёгкая выборка отпечатков → детали только для
топ-3), находит и «тот же спот», и «ту же ошибку» (8 префлоп-ликов + доезд), напоминает
вердикт прошлого разбора и обязана озвучить совпадение с датой. Метки ошибок пишутся при
парсинге в JSON hand.spot (без изменения схемы) — работает для новых загрузок, бэкафилл
сознательно не делаем. Деплой — отдельной командой Артёма.
