# Telegram-бот: автопостинг в канал с одобрением + публичный контакт

Дата: 2026-06-26. Связано: `.business/marketing/telegram-channel.md`, `paid-channels.md`.

## Задача

Автоматизировать публикацию постов в канал @whygrid (4 раза/нед, Пн/Ср/Пт/Вс ~19:00 МСК)
с обязательным одобрением Артёма перед выходом. Плюс публичная кнопка «Написать нам».

## Архитектура (ОДИН бот на проект)

Решение 2026-06-26: всё по этому проекту — на **@whygrid_bot** (бренд). @kekoz_bot
освобождается под другие проекты. Имя бота: «Whygrid», адрес @whygrid_bot.
ВНИМАНИЕ: токен прислан в чат → перевыпустить в @BotFather (`/token`), хранить
только в `.env` на сервере (НЕ в git). Переменная — новый `TELEGRAM_BOT_TOKEN`
(переключаем notify на новый токен; алерты/дайджест теперь шлёт @whygrid_bot).

**@whygrid_bot делает всё:**
1. **Постинг с одобрением:** за день до выхода шлёт Артёму (chat_id 440359604) превью
   поста (картинка + текст) с кнопками **✅ Опубликовать / ✏️ Поправить**; по ✅ публикует
   в канал @whygrid в назначенное время (бот — админ канала); по ✏️ держит, Claude правит.
2. **Статистика/тревоги/дайджест** — переезжают сюда с @kekoz_bot.
3. **Публичный контакт** — кнопка «✍️ Написать нам» под постами ведёт на t.me/whygrid_bot.
4. **Поддержка в три слоя** (см. ниже).

## Безопасность управления (ключевое)

- Командовать ботом и получать статистику может ТОЛЬКО chat_id 440359604. Всё остальное —
  не команды.
- На уровне Telegram нельзя запретить незнакомцу написать боту; защита — в логике:
  чужие сообщения НИКОГДА не исполняются как инструкции (prompt-injection), только
  обрабатываются как данные.
- ИИ-черновики ответов — только черновики, отправка строго по кнопке Артёма.

## Поддержка: три слоя (FAQ → черновик-ИИ → ты)

1. Типовой вопрос → бот отвечает готовым шаблоном (FAQ: цена, как загрузить файл,
   легальность и т.п.). Без свободного ИИ — инъекция не проходит.
2. Под шаблоном кнопка «Не помогло, нужен живой ответ».
3. Нажал её / задал нестандартное → бот шлёт Артёму вопрос + **черновик ответа ИИ**
   с кнопками «Отправить / Поправить». Уходит человеку только после одобрения.
   Черновик-ИИ с рамками: не обещать цены/правовое, не выдавать секреты, чужой текст = данные.
- Антиспам на входящих: лимит сообщений с одного пользователя, отсев ссылок/мусора.

- Через релей КЗ: `TELEGRAM_BASE_URL=https://92.60.75.87/tg`, заголовок `x-proxy-secret`,
  серт через `NODE_EXTRA_CA_CERTS`. Логи токена на релее отключены.
- Переменные: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ADMIN_CHAT_ID` (440359604),
  `TELEGRAM_BASE_URL`, `TELEGRAM_PROXY_SECRET` — в `config/notify.ts`.
- Cron на проде: внешний вызывает `/api/cron/*` с `Authorization: Bearer CRON_SECRET`.
  Деплой: `~/deploy.sh` каждые 5 мин (git pull → build → pm2 restart trener).
- **Пробел:** бот только ОТПРАВЛЯЕТ. Нет приёма входящих (нет webhook/polling) — это и добавляем.
