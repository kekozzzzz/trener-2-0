# Сетка диапазона как способ ответа в сократовском диалоге

**Дата:** 2026-06-25
**Идея Артёма:** когда тренер спрашивает «какой диапазон ты даёшь оппоненту» (открылся / заколлировал 3-бет / сбросит на 3-бет), вместо набора текста появляется сетка 13×13 — игрок кликает руки, которые, по его мнению, есть у оппонента. Сетка появляется **именно на таком вопросе**, не раньше и не позже.

## Принципы

- **Правило 1 не нарушается.** Диапазон даёт человек, а не код и не LLM. Никаких утверждённых чартов 3-бета/защиты не нужно. «N комбо · X% рук» считает детерминированный код (169-сетка: пара=6, одномастная=4, разномастная=12 комбо, всего 1326).
- **Правило 2 не трогаем.** Сетка — это форма ответа на стадии `QUESTION_ASKED`. Стейт-машина диалога без изменений: вопрос → ответ → следующий вопрос/вердикт.
- **Без миграции БД.** Метку «это вопрос-диапазон» несём токеном `{{range}}` в начале текста вопроса (как токены кликабельных рук `{{h:...}}`). Токен ставит код по флагу LLM, не сам текст модели → безопасно.
- **Контекстный триггер** (выбор Артёма): LLM помечает вопрос `answerMode:"range"`. Правка 2 боевых промптов — разрешена.

## Фаза 1 — сетка и арифметика (без риска для потока) [x]

- [x] `config/poker/hand-grid.ts` — порядок 169-сетки (строка/столбец → код руки; пары по диагонали, одномастные выше, разномастные ниже), `comboCount(code)`, `formatRange(codes[])` → компактная нотация (`99+`, `AJs+`) + комбо + % от 1326. Чистые функции.
- [x] `__tests__/config/hand-grid.test.ts` — коды ячеек, счёт комбо, компактная нотация, проценты (8 тестов).
- [x] `components/poker/range-grid.tsx` — клиентский компонент: матрица 13×13, клик + протягивание мышью, выделение лаймом, живой счётчик «N комбо · X%». По дизайн-системе. Проверено скриншотом на /design-preview.

## Итог

Все 3 фазы в коде, НЕ задеплоено. tsc чист, 19 тестов зелёные, сетка проверена визуально. Осталось до деплоя: 1) показать Артёму формулировки двух промптов; 2) приёмка вживую на реальной раздаче; 3) проход hardening (см. [[feedback_hardening_before_deploy]]). Диапазон оппонента считает ИГРОК кликами — Правило 1 не затронуто, чартов 3-бета/защиты не нужно.
