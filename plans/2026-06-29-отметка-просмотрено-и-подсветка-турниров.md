# План: отметка «просмотрено» по раздачам + подсветка пройденных турниров

Дата: 2026-06-29

## Зачем
При большом числе загруженных турниров легко запутаться, что уже разобрано. Нужно
визуально подсвечивать пройденное:
- критические раздачи — уже есть бейдж «разбор завершён» (вердикт диалога), оставляем;
- сильные/средние — нет отметки, что игрок их смотрел → добавить «Просмотрено»;
- список «Мои турниры» — подсветить турниры, пройденные целиком.

## Решения
- Хранение отметки «просмотрено» — в БД (выбор Артёма 2026-06-29 = разрешение на миграцию).
- «Зелёный» по дизайн-системе невозможен (один акцент). Done-состояние = фирменный
  лайм `#D4FF33` (новый вариант бейджа `done`: лаймовая обводка + лаймовый текст) +
  обводка карточки лаймом.
- Раздача «просмотрена» = игрок открыл её страницу разбора (фиксируем `viewedAt`).
- Турнир «пройден целиком» = `status = CARD_READY`, разбор открыт, есть карточные
  раздачи и КАЖДАЯ карточная раздача «готова»:
  - есть диалог → `state = VERDICT_SHOWN`;
  - нет диалога (простая) → `viewedAt != null`.
