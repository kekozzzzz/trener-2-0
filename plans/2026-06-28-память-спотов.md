# Память тренера — отпечаток спота и ссылки на прошлое

Тренер помнит историю игрока по всем турнирам и дням: ловит повторяющиеся споты, тычет в
несогласованные решения, обновляет профиль в Аккаунте. Запрос Артёма 2026-06-28.

## Железное условие (Правило 1)

«Похожесть» раздач считает ПАРСЕР детерминированно (отпечаток спота), LLM только проговаривает
уже найденные РЕАЛЬНЫЕ раздачи. Сама решать «похоже/не похоже» модель не может — иначе выдумает
совпадения. Метку «один в один / что-то подобное» ставим мы из числа совпавших признаков, не LLM.

## Что считаем «тем же спотом» (решено с Артёмом)

Отпечаток из независимых признаков; совпадение градуируем по штукам (полное → «один в один»,
частичное → «похожее»):
1. позиция; 2. роль префлопа (открыл/3-бет/колл/защита ББ/лимп/пуш/пассив); 3. глубина стека
(SHORT ≤15 / MID 15–35 / DEEP >35 BB); 4. улица; 5. текстура борда (масти/спарен/связность);
6. как Hero попал — собрал сильное / пара / на дро / ПРОМАХ. Пример Артёма «три-флеш-доска без
попадания» = MONOTONE + WHIFF — ловится точно.

понадобится усилить.
