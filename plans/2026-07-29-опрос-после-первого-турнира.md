# План: опрос после первого турнира

Дата: 2026-07-29

## Задача

После того как игрок впервые открыл готовый разбор своего первого турнира (страница
`/tournament/[id]`, разбор уже не в процессе), один раз показать модальное окно:
короткое вступление «мы только в начале пути, твоё мнение может повлиять на продукт»
+ опрос из 10 вопросов (4 обязательные оценки 1–5 + 6 необязательных текстовых полей)
про контент разбора, тон/стилистику тренера и качество сократовских вопросов.
Показывается один раз навсегда — независимо от того, ответил игрок или закрыл окно.

Решения по формату утверждены с Артёмом (см. диалог сессии):
- Триггер: первый турнир игрока, после того как разбор готов (не во время processing).
- Хранение ответа: новая таблица в БД (не просто текст в Telegram, как у `/support`) —
  структурированные оценки нужны для анализа позже. Разрешение на смену схемы БД получено.
- Повтор: один раз навсегда, даже если закрыл не ответив.
- Формулировки вопросов утверждены как есть, без правок.
- UI: один длинный скролл в модалке, без пошагового визарда.

## Реализация

### 1. Prisma-схема
- `Player.introSurveyShownAt: DateTime?` — флаг «уже показывали» (ставится и при
  отправке ответа, и при закрытии без ответа).
- Новая модель `IntroSurveyResponse`: 4 обязательные Int-оценки (usefulness/tone/
  questions/recommend) + 6 опциональных текстовых полей + связь с Player и Tournament.
- Локальная миграция (`prisma migrate dev`), прод не трогаем.

### 2. Server actions (`app/tournament/[id]/actions.ts`)
- `submitIntroSurveyAction` — валидирует 4 оценки (1–5, обязательны), создаёт запись,
  ставит `introSurveyShownAt`, шлёт сводку админу через уже существующий
  `safeNotifyAdmin` (без новой инфраструктуры, переиспользуем notify-адаптер).
- `dismissIntroSurveyAction` — закрытие без ответа: просто ставит `introSurveyShownAt`.

### 3. UI-компонент (`app/tournament/[id]/intro-survey.tsx`)
Мирроринг паттерна `self-level.tsx` (авто-открытие один раз, `Dialog` из
`components/ui/dialog.tsx`, `useActionState` как в `support-form.tsx`). Радио-группы
1–5 для обязательных оценок, `Textarea` для опциональных полей.

### 4. Точка показа (`app/tournament/[id]/page.tsx`)
Считаем `isFirstTournament` через `prisma.tournament.count` (единственный турнир
игрока без учёта удалённых), берём `introSurveyShownAt` вместе с существующим
запросом `me`. Показываем компонент, когда `isFirstTournament && !processing &&
!me.introSurveyShownAt`.

### 5. Переводы
`messages/ru.json` / `messages/en.json` — новый namespace `IntroSurvey`.

## Итог

Реализовано полностью, статус `[x]`:

- Схема: `Player.introSurveyShownAt` + таблица `intro_survey_responses` (4 обязательные
  оценки 1–5 + 6 опциональных текстовых полей). Миграция `20260729120000_add_intro_survey`
  написана вручную (не через `prisma migrate dev` — известная особенность репо: он лезет
  чинить ручные partial-индексы старых миграций) и применена и на `trener_dev`, и на
  `trener_test`.
- `submitIntroSurveyAction`/`dismissIntroSurveyAction` в `app/tournament/[id]/actions.ts`:
  сохраняют ответ, ставят флаг показа, шлют сводку владельцу в Telegram через уже готовый
  `safeNotifyAdmin` (без новой инфраструктуры).
- UI — `app/tournament/[id]/intro-survey.tsx`, паттерн один в один с `self-level.tsx`
  (`Dialog` из `components/ui/dialog.tsx`, `useActionState` как в `support-form.tsx`).
  Один длинный скролл, радио-группы 1–5 как квадраты с рамкой (стиль `border-primary`
  из design-system), 6 текстовых полей необязательны.
- Триггер в `page.tsx`: показывается один раз, когда у игрока нет других (неудалённых)
  турниров кроме текущего и разбор уже не в processing.
- Найден и закрыт конфликт: на первом турнире строчка «Ориентир» (self-level) тоже
  авто-открывает свой диалог — стек из двух модалок разом. Решено клиентской проверкой
  той же localStorage-метки `wg_selflevel_seen`: если self-level ещё может показаться
  в этом браузере, опрос уступает очередь и пробует на следующем подходящем визите
  (турнир остаётся «первым», пока не загружен второй) — сервер показ не отмечает, ответ
  не теряется.
- Переводы (`messages/ru.json` + `en.json`): namespace `IntroSurvey`, плюс два ключа в
  `Errors`.
- Проверено: `tsc --noEmit` чисто, `npm run build` чисто, `npm test` — 1343/1344
  (единственный красный тест не связан с задачей, про Instagram-источник трафика,
  падал и до этой сессии), дев-сервер поднимается без ошибок.
