# План: парсер WPN (ACR / PokerKing) + честный результат в бай-инах

**Дата:** 2026-06-20
**Задача:** научить продукт читать HH-файлы сети Winning Poker Network (ACR Poker, PokerKing), а не только GGPoker. Заодно починить метрику «результат в бай-инах», которая на GG всегда показывает `+0.00`.

---

## Почему это отдельный парсер, а не правка регулярки

Реальный файл ACR (`Game Hand #...`, сеть WPN) отличается от GGPoker по всем ключевым местам. Разобрано на живом файле пользователя:

| Что | GGPoker | ACR / WPN |
|---|---|---|
| Заголовок | `Poker Hand #RC-GGPoker-... : Tournament #N, <название> - Level...` | `Game Hand #N - Tournament #N - Holdem (No Limit) - Level X (sb/bb) - дата UTC` |
| Кто такой Hero | прячется под словом `Hero` | реальный ник (`kekozzz`); определять по строке `Dealt to <ник>` |
| Строки действий | `Hero: folds` (с двоеточием) | `kekozzz folds` (без двоеточия) |
| Анте | `posts the ante` | `posts ante` |
| Блайнды | `Name: posts small blind` | `Name posts the small blind` (с «the», без двоеточия) |
| Суммы | целые (`1500`) | дробные (`100000.00`) |
| Название турнира | есть в заголовке | нет (только «Holdem (No Limit)») |
| Бай-ин в долларах | иногда в заголовке | нет вообще |
| Сбор банка | `Hero collected N from pot` | `<ник> collected N.NN from main pot` / `from side pot-1` |
| Анкол | `Uncalled bet (N) returned to Hero` | `Uncalled bet (N.NN) returned to <ник>` |

Совпадает: `Seat #N is the button`, `*** FLOP/TURN/RIVER ***`, `Board [...]`, `*** HOLE CARDS ***`, `*** SUMMARY ***`, структура `raises X to Y` (берём Y как абсолют).

**Хорошая новость:** ACR и PokerKing — одна сеть (WPN), формат общий → один парсер закрывает обе комнаты.

---

## Метрика «результат в бай-инах» — почему всегда +0.00 и решение (РЕШЕНО: убираем)

Почему было `+0.00`:
- бай-ин читался шаблоном `$X+$Y`, которого нет в реальных TM-файлах → подставлялось `1` → деление на весь стартовый стек → округление в `+0.00`;
- «результат» = разница стартовых стеков двух раздач (не реальный выигрыш), да ещё со сбитым знаком (файл идёт от свежих к старым);
- метрика не покрыта ни одним тестом.

**Проверено на реальном файле (Test/, 110 раздач):** в хенд-хистори НЕТ денег вообще — ни `$`, ни места, ни приза, ни строки вылета. Только фишки. Значит денежный результat турнира (с учётом призов/ITM) из HH-файла невычислим в принципе. Деньги живут в отдельном файле «сводка турнира» (tournament summary).

**Решение пользователя (2026-06-20):** для турниров результат **убираем из показа совсем**. Фишковый результат турнира малоинформативен (вошёл со стеком — проиграл стек), а денег в файле нет. Денежный ROI вернём позже на **кэш-игре**, где «выиграл/проиграл за сессию» считается чисто, либо через отдельный парсер сводки турнира.

**Что подтвердили/уточнили живые файлы (важно для парсера):**
- Суммы — с `.00`, но **без разделителей тысяч** (`1841925.00`), в отличие от iPoker (там запятые). Парсить как float/центы.
- Анте `posts ante 4500.00` (без «the»); блайнды `posts the small blind` / `posts the big blind` (с «the»); действия без двоеточия (`kekozzz folds`, `IG2000 raises 1780425.00 to 1797925.00 and is all-in`).
- Улицы: `*** HOLE CARDS ***`, `*** FLOP/TURN/RIVER ***`, **`*** SHOW DOWN ***` с пробелом** (не «SHOWDOWN», как у GG), `*** SUMMARY ***`.
- После каждого маркера улицы идёт служебная строка `Main pot N.NN` (и `Side pot(1) N.NN`) — это бегущий банк, парсер должен её **пропускать**, не путать с действием.
- Результат руки доступен прямо в SUMMARY: `Seat N: <ник> showed [..] and won X` / `did not show and won X` / `folded on the Turn`. Можно брать оттуда, не пересобирая из `collected`.
- Сайд-поты: `collected N from main pot` + `collected N from side pot-1`.
- 🔴 **Новое и важное:** один турнир = **несколько файлов по столам**. Игрока пересаживают при балансировке (kekozzz прошёл Table 36 → 54 → 7 по уровням). Дедуп по `Tournament #` сольёт их в один турнир — значит для WPN нужен **мердж раздач из нескольких файлов одного турнира** (у GG было «один файл = один турнир»). Учесть в роутере/загрузчике.
- Статус-строки игроков: `is sitting out`, `will be allowed to play after the button` — не падать на них.
- Бай-ина/денег в заголовке нет (как и ожидали) — результат в фишках, деньги невычислимы из HH.
