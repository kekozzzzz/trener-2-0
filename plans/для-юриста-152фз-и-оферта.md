# Запрос юристу: документы и согласия для онлайн-сервиса (152-ФЗ, оферта, ЮKassa)

## О проекте

Онлайн-сервис (веб-приложение) — обучающий AI-тренер по покеру. Пользователь регистрируется, оформляет платную подписку и загружает файлы истории своих игр для разбора. Сервис работает по модели **подписки с автоматическим продлением** (рекуррентные платежи).

- **Статус исполнителя:** самозанятый (плательщик НПД), ИНН **861713618271**, ФИО: _[вписать]_.
- **Приём платежей:** ЮKassa, физлица-пользователи, оплата картой на сайте.
- **Тарифы:** 900 / 2000 / 3000 ₽ в месяц.
- **Сайт:** https://whygrid.app

## Какие персональные данные обрабатываются

1. **Email** пользователя (регистрация, вход, уведомления).
2. **Пароль** (хранится только в виде хеша).
3. **Загружаемые файлы истории игр** — содержат **игровые никнеймы** игроков.
4. **Текстовые ответы пользователя** на вопросы тренера в диалоге.
5. Платёжные данные обрабатывает ЮKassa (мы карту не храним, храним только токен метода оплаты для автосписания и журнал платежей: сумма, статус, дата).

## Ключевой момент — трансграничная передача данных

Для анализа сервис передаёт **текстовые ответы пользователя и данные о его игре во внешнюю ИИ-модель (провайдер Anthropic, США)**. То есть часть персональных данных пользователя передаётся за пределы РФ, в страну, которая может не входить в перечень обеспечивающих адекватную защиту.

## Вопросы, по которым нужна консультация

1. **Уведомление в Роскомнадзор об обработке ПДн** — нужно ли его подавать в нашем случае (самозанятый, сбор email и иных ПДн через сайт)? Если да — помочь корректно заполнить и подать.
2. **Трансграничная передача в США** — как её правильно оформить юридически:
   - нужно ли отдельное уведомление в РКН о трансграничной передаче и в какие сроки (до начала передачи?);
   - как должно выглядеть согласие пользователя на такую передачу (отдельное согласие, формулировки).
3. **Пакет документов сайта** — составить или проверить:
   - **Договор-оферта** на оказание услуг по подписке;
   - **Политика обработки персональных данных** (152-ФЗ);
   - **Согласие на обработку ПДн** (форма при регистрации);
   - **Политика возврата** денежных средств;
   - страница **реквизитов**.
4. **Автопродление (рекуррентные платежи)** — как корректно оформить в оферте согласие пользователя на автоматическое списание за следующий период; что обязательно раскрыть (порядок отмены, уведомление перед списанием).
5. **Возврат за цифровую услугу по подписке** — особенности по Закону о защите прав потребителей: за какой период и в каких случаях пользователь вправе вернуть деньги, как это отразить в оферте и политике возврата.
