# Анимация знака логотипа (один проход лайма)

**Срез:** когда игрок открывает любую страницу сайта или наводит курсор на логотип, лаймовая ячейка знака один раз обходит сетку 2×2 по часовой стрелке (верх-право → низ-право → низ-лево → верх-лево → домой), 1.2 с, и знак возвращается в обычный вид.

**НЕ входит:**
- Бесконечное/постоянное вращение (запрещено §5 дизайн-системы, исключения не добавляем).
- Индикатор загрузки разбора с бегущей ячейкой (отдельный заход, если Артём захочет).
- Изменение вида знака в покое, размеров, цветов, favicon.
- Новые библиотеки, JS, изменения БД.

**Решение:** Артём, 2026-10-09: «при наведении и при загрузке ... давай так и сделаем» (из трёх предложенных вариантов).

## Как делается
- Только `trener/components/ui/wordmark.tsx` (разметка знака) + `trener/app/globals.css` (keyframes).
- Чистый CSS: у каждой из 4 ячеек `fill-opacity`/`stroke-opacity` переключаются по слотам времени; без JS, без гидрации.
- Загрузка = анимация по умолчанию при первой отрисовке; наведение = те же keyframes под другим именем (иначе CSS не перезапустит).
- `prefers-reduced-motion: reduce` отключает полностью. Тач-экраны: проход при загрузке остаётся, наведения нет.
