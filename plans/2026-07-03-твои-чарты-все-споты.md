# План: «Твои чарты» — зеркала всех спотов (v1 только открывашки → все пять)

Дата: 2026-07-03. Запрос Артёма: «у нас только префлоп-открывашки — давай все добьём».

## Цель

Кнопка «Твои чарты» (страница «Мои турниры») сейчас показывает одно зеркало —
открывания (RFI) + SB-лимпы. На странице /charts эталонов уже пять. Добиваем личные
зеркала по остальным спотам, чтобы игрок видел «как играю Я» рядом с «как надо»:

1. **Защита BB** — по позиции открывашки (UTG…BTN), слои Колл / 3-бет.
2. **Против опена (не BB)** — по нашей позиции (UTG…SB), слои Колл / 3-бет.
3. **Изоляция лимпера** — по нашей позиции, один слой (рейз).
4. **Пуш-фолд (опен-шов)** — по позиции × стек-бэнд (до 10 BB / 10–14 BB).

## Что уже есть (ничего не изобретаем)

- Детекторы спотов в парсере, задеплоены и оттестированы: `parser/bb-defense.ts`,
  `parser/vs-open.ts`, `parser/iso.ts`, `parser/open-shove.ts`. Каждый отдаёт
  позицию + код руки + действие.
- Грейдеры «заметно шире нормы» в конфигах эталонов: `isBBThreeBetSignificantlyWide`,
  `isVsOpenThreeBetSignificantlyWide`, `isIsoSignificantlyWide`,
  `isOpenShoveSignificantlyWide`.
- Сетка 13×13 зеркала: `components/profile/open-chart-grid.tsx` (вариант judged/plain).
- Образец агрегатора и данных: `features/profile/open-chart.ts` + `getOpenChart`.

## Решения

- **Правило 1 цело**: частоты и флаги «шире нормы» считает код, LLM не участвует.
- Эталон в зеркале НЕ рисуем (как решено в v1 открываний): зеркало — «как ты играешь»,
  лаймом только явно широкие действия; эталоны живут на /charts.
- Коллы (защита BB и холодный колл) **не судим** — грейдеры флагают только 3-бет
  вне мягкой границы (так решено в конфигах эталонов). Слой колла — серый со счётчиком,
  как SB-лимпы.
- Все зеркала грузим одним ленивым экшеном по клику (как сейчас): руки уже тянутся
  одним запросом, агрегируем за один проход.
- Колл BB против пуша — детектора нет (есть только данные `BB_CALL_VS_PUSH`);
  в этот заход НЕ входит, отдельной задачей при желании.
