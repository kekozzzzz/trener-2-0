# Кулеры и перезаходы (re-entry)

Запрос Артёма 2026-07-05 (голосом, по живой проверке тренера).

## Зачем

1. **Кулеры.** Сейчас крупная спорная потеря автоматически кандидат в CRITICAL → сократовский диалог. Но если деньги зашли, когда игрок был далеко впереди (соперник доехал), — разбирать нечего: «сыграл правильно, не повезло». Тренер на таких раздачах чаще всего и лажает (выдумывает ошибку под минус). Решение: парсер детерминированно распознаёт кулер (вскрытые карты уже есть — тот же механизм, что у доездов-выигрышей) и уводит его в отдельную тихую стопку на странице турнира — без диалога, без LLM, с подписью от парсера. Критические слоты освобождаются под настоящие ошибки, себестоимость разбора падает.

2. **Перезаходы.** GG пишет каждый вход в турнир отдельным файлом с одним номером турнира (#295720745: файл -1415 = вход 1, -1436 = перезаход). Сейчас второй файл упирается в дедупликацию по номеру и молча отбрасывается. Решение: при «дубле» сравнить раздачи по времени — если это ДРУГИЕ раздачи, создать второй турнир с пометкой «Перезаход №2».

## Фазы

- [x] Фаза 1 — парсер: детектор кулера `parser/cooler.ts` (зеркало lucky-win: последнее крупное вложение Hero, эквити ≥67% против ЛЮБОЙ вскрытой руки, потеря фишек) + фильтр «чистый префлоп» (без флагов «шире нормы» от эталонных чартов и без лимпа) — грязные остаются критическими.
- [x] Фаза 2 — классификация: `assignImportanceLevels` возвращает COOLER для чистых кулеров-потерь; критические слоты их не тратят. Тип `HandImportance` + enum в Prisma + миграция (`ALTER TYPE ADD VALUE 'COOLER'`; SQL чистим руками — prisma migrate dev суёт лишнее).
- [x] Фаза 3 — UI: стопка «Кулеры» на странице турнира (под сильными/средними, свёрнута), карточки без ссылки и чата, подпись парсера «деньги зашли на тёрне с 74% — соперник доехал». i18n ru/en.
- [x] Фаза 4 — перезаходы: `Tournament.entryNumber` (default 1); в `uploadTournament` при совпадении номера сравнить `playedAt` раздач: пересечение → настоящий дубль (как раньше), нет пересечения → новый турнир с entryNumber = max+1. Бейдж «Перезаход №N» на странице турнира и в списке «Мои турниры».
- [x] Фаза 5 — тесты (детектор кулера, классификация, решение дубль/перезаход), билд, тихая выкатка.
