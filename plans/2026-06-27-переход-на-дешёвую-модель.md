# План: переход разбора на дешёвую модель (DeepSeek через OpenRouter)

Дата: 2026-06-27
Связан с: `plans/2026-06-27-обогащение-фактов-парсера.md` (уже сделано)

## Зачем

После обогащения фактов парсера дешёвый DeepSeek V3.2 на 30+ реальных руках:
факты держит, вердикты совпадают с Sonnet, формат JSON стабильный, результатоориентированность
убрана правкой промпта. Цена — **в ~16 раз дешевле** Sonnet ($0.0037 против $0.06 за разбор).
Себестоимость турнира падает с ~$0.26–0.90 до ~$0.02–0.06. Это и есть цель — минимизировать
расходы на ИИ без потери качества.

## Что уже готово в коде (НЕ задеплоено)

- Парсер проговаривает всё: готовая рука по улицам (`parser/made-hand.ts`), масти словами,
  блайнды везде, состав стола, дро по улицам, явное «дро нет», код руки.
- Промпт (`COACH_FRAMEWORK`, общий для всех ролей): правило «суди по моменту, не по борду»,
  запрет капса и артефактов в словах-действиях.
- 345 тестов зелёные. В прод ничего не ушло.

## Решения (зафиксированы с Артёмом 2026-06-27)

Проверка доступности с боевого сервера показала:
- Напрямую из РФ: DeepSeek **флаки** (то 401 за 0.4с, то 6 таймаутов подряд), OpenRouter и Anthropic
  заблокированы. → прямой выход из РФ ненадёжен.
- Через казахский релей (92.60.75.87): DeepSeek 401 за 0.6с (5/5 стабильно), OpenRouter 200 за 0.4с.

**Итог — релей ОСТАЁТСЯ** как надёжная дверь из-под блокировки. Архитектура:
- **Основное:** прод → казахский релей → **OpenRouter** → DeepSeek. OpenRouter уже оплачен ($4.4),
  регистрацию DeepSeek НЕ трогаем.
- **Запасной:** Anthropic (Sonnet) через тот же релей — переключение одним env-флагом (Правило 3).
  Те $15 на Anthropic не сгорают, это топливо отката.
- **Будущее (когда кредиты OpenRouter будут заканчиваться):** релей → напрямую DeepSeek без посредника
  (чуть дешевле). Тогда же пробить регистрацию DeepSeek. Не горит.

Разрешения CLAUDE.md получены: OpenRouter как внешний сервис — ок; смена модели — ок.

## Критерий успеха

Себестоимость турнира падает в разы, качество разбора на глаз не отличается, формат стабилен,
откат — одним env-флагом. Сократовский вопрос «почему» и Правило 1 (числа — за парсером) не затронуты.

## Не ломаем (проверки правил проекта)

- Правило 1: числа по-прежнему считает парсер; новые факты — детерминированная арифметика.
- Правило 2: сократовский вопрос на месте, диалог-машина не тронута.
- Правило 4: вендор за адаптером; бизнес-логика дёргает порт, не знает про OpenRouter.
- Секреты: ключ OpenRouter только в env прода, не в git (тестовый `openrouter-key.txt` уже в .gitignore).
