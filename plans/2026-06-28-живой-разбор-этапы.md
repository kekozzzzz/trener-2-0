# Живой экран разбора турнира — честные этапы («тренер думает»)

**Задача.** Пока турнир разбирается (LLM по очереди анализирует ~10 раздач + собирает обзор),
экран сейчас просто молча обновляется. Заполнить ожидание ощущением настоящей работы:
показать реальные этапы воркера + живой счётчик «N из 10». Вариант 1 из обсуждения 2026-06-28.

**Где.** Экран разбора раздач турнира (после парсинга). Парсинг (UPLOADED/PARSING) и ошибка
(FAILED) уже имеют свои экраны — их не трогаем.

**Честность (Правило 1).** Каждый этап = реальный шаг воркера. Никаких выдуманных шагов
(в частности «вспоминаю похожие споты» — такой функции нет). Данные счётчика — из status-API
(`handsReady/handsTotal`, `summaryReady`). Парсер/LLM не трогаем — только индикация.

**Тон.** Простой человеческий язык, без жаргона (новичок должен понять).

## Этапы (из реальных данных status-API)

1. Разобрали файл и посчитали статистику — на этом экране всегда готово (парсинг позади).
2. Выбрали {handsTotal} раздач, где было что решать — готово (selectedForCard выставлен).
3. Разбираем их по одной — {handsReady} из {handsTotal} — активный, живой счётчик.
4. Собираем общую картину турнира — активен, когда раздачи готовы, но обзора ещё нет.

Готово (CARD_READY + summaryReady) → router.refresh() → обычная страница турнира.

## Дизайн (по design-system.md)

- Один акцент — лайм `#D4FF33`: маркер готового этапа, активный счётчик-число.
- Эмодзи запрещены → маркеры этапов геометрические (квадрат 1px-рамка / залит лаймом).
- Числа — JetBrains Mono. Лейблы — моно капс. Скруглений нет.
- Анимации: только разрешённый `LoadingDots` на активном этапе + одноразовый fade появления.

## Итог

Сделано. Пока турнир разбирается, вместо молчаливого полупустого экрана — выделенный экран
«Тренер разбирает турнир» с четырьмя честными этапами и живым счётчиком «N из M» (данные из
status-API, опрос раз в 1.5с). Маркеры этапов — геометрические квадраты (готов = залит лаймом,
активный = лаймовая рамка, ждёт — серая), активный этап с `LoadingDots`. Склонение «раздача/
раздачи/раздач» по числу. `tsc` чистый, `next build` зелёный. НЕ задеплоено.

Тонкая правка вкуса (на потом, если захочется): сейчас до готовности обзора прячем половинчатую
страницу — это вариант 1 (чистый «экран размышления»). Вариант 2 (раздачи всплывают по очереди
на самой странице) — отдельный апгрейд.
