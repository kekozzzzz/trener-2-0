# План: парсер считает ЛЮБЫЕ ауты на улучшение + запрет выдумывать ауты

## Зачем
Тренер в разборе написал «сет из 6 аутов» для 77 на монотонном 9♣K♣4♣, хотя до сета
ровно 2 аута. Причина: парсер считал ауты ТОЛЬКО для флеш/стрит-дро (`draws.ts`), а
улучшение пары до сета/двух пар/фулла игнорировал → LLM выдумал число и ошибся. Это
прямое нарушение Правила 1 (числа считает парсер) и Критической поломки №2 (LLM
вычислит число и ошибётся → скриншот в Discord).

Артём: пусть парсер считает ВООБЩЕ любые ауты всегда (не только сет — фулл, пара,
что угодно). И запретить в промпте называть ауты без фактов парсера.

## Риск и как его снимаем
«Любые ауты» буквально = для 77 на монотоне 11 карт (2 сет + 9 спаривают борд), но
почти все грязные (борд одномастный → сет позади флеша; спаривания → слабые две
пары, тоже позади). Голое «11 аутов» было бы хуже исходного бага. Поэтому парсер
отдаёт ВСЕ ауты И отдельно ЧИСТЫЕ + причину «грязности», а промпт велит тренеру
опираться на чистые.

## Фазы

- [x] Ф1. `parser/draws.ts`: функция `improvementOuts(hero, board)` — перебор колоды,
  аут = карта следующей улицы, поднимающая КАТЕГОРИЮ руки Hero И дающая руку сильнее
  голого борда (иначе улучшение играет борд). Грязные ауты: спаривают борд / на борде
  3+ одной масти при том, что Hero сам флеш не собрал. Возврат: всего/чистых/разбивка
  по итоговой руке/причины.
- [x] Ф2. `parser/facts.ts`: рендер строки «Ауты Hero на улучшение…: всего N, чистых M,
  разбивка …» по улицам (флоп/тёрн), рядом с существующими дро.
- [x] Ф3. Промпт `config/prompts/hand-analysis.ts` (COACH_FRAMEWORK_BODY, общий всем
  ролям): в Правило 1 — число аутов только из строки парсера; опираться на чистые; у
  пары до сета ровно 2 аута; нет строки — не выдумывать.
- [x] Ф4. Тесты `__tests__/parser/draws.test.ts`: 77 на монотоне (11 raw / 0 clean,
  разбивка 2 сет + 9 две пары), чистый сет на сухом радужном борде, оверкарты (пара-ап).
- [x] Ф5. `npm test` (755 зелёных) + `tsc` чист. Деплой — по команде Артёма.

## Итог
Сделано. Парсер теперь честно перебирает ЛЮБЫЕ ауты на улучшение (не только флеш/стрит),
отдаёт всего/чистых + разбивку + причину «грязности»; промпт запрещает называть ауты не
