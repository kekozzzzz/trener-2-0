# План: чат на простых раздачах карточки

/ Задача: дать игроку открыть любую раздачу карточки (~10) и задать прямой вопрос с конкретным ответом. На критических — как сейчас (сначала сократовский диалог, чат после вердикта). На простых (STRONG/MEDIUM, без диалога) — прямой Q&A сразу. Объём согласован с Артёмом: только ~10 раздач карточки (не все ~70 — это режим «Тренировка», отдельная задача).

## Раздел 0 — Решение и правило проекта №2

Правило №2 защищает критическую ошибку: по ней нельзя спросить «как надо было» в обход вопроса «почему». Поэтому:

- **CRITICAL** (есть `Dialogue`): гейт `VERDICT_SHOWN` сохраняется без изменений — чат открывается только после сократовского диалога.
- **STRONG/MEDIUM** (нет `Dialogue`, но есть `analysis` и `selected_for_card`): прямой чат доступен сразу. Критической ошибки там нет — разбор это «сыграно / можно было чуть иначе», поэтому прямой вопрос не обходит правило №2.

Чат переиспользует существующий `GENERATE_CHAT_REPLY` — новый промпт не нужен, стоимость турнира не меняется (раздачи карточки уже разобраны).

## Фазы

- [x] **Фаза 1 — единый гейт доступности чата.** Хелпер `isChatAvailable(hand)` (`features/chat/availability.ts`) применён в `getChat`, `sendChatMessage`, `generate-chat-reply`. В воркере дополнительно `hand.dialogue?.verdict ?? null` — у простых раздач вердикта нет.
- [x] **Фаза 2 — страница раздачи без диалога.** `page.tsx` ветвится: с диалогом — прежний поток; без диалога, но с `analysis` — блок «Разбор» (optimal + note) + чат. `notFound()` только если нет ни диалога, ни разбора.
- [x] **Фаза 3 — список простых раздач на карточке.** Секция «Остальные раздачи» (selected_for_card, без диалога, analysis есть) со ссылками; бейдж важности + результат в фишках.
- [x] **Фаза 4 — тесты.** Обновлены `get-chat`/`send-message` (простая раздача с разбором → доступна; без разбора → нет; CRITICAL до VERDICT_SHOWN → закрыто — регресс правила №2); добавлен случай воркера на простой раздаче (`verdict = null`). Всего 122 теста зелёные, tsc и build чистые.
- [x] **Фаза 5 — hardening + журнал.** IDOR закрыт прежними `authorizeHand`/`requireSession` (новый путь идёт через те же входы — новой дыры нет). Запись добавлена в журнал `00-правила-проекта.md` (2026-06-17); старая запись 2026-06-15 не тронута (журнал append-only).

## Итог

Готово. Чат теперь доступен на любой из ~10 раздач карточки: критические — после сократовского диалога (правило №2 сохранено и покрыто регресс-тестами), простые — сразу. Новый промпт не понадобился, стоимость турнира не изменилась. Не сделано (осознанно, вне объёма): чат на всех ~70 раздачах турнира — это режим «Тренировка» с разбором по требованию, отдельная задача с другим потолком стоимости.
