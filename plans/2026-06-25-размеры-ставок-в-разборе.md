# План: размеры ставок в разборе

Дата: 2026-06-25

## Зачем

Разбор должен опираться на размер ставки как на самостоятельный рид:
1. крупная ставка / овербет **в Hero** = чаще Hero позади (поляризация: сила или редкий блеф);
2. крупный бет **самого Hero** = больше фолд-эквити, выбивает больше рук;
3. **дро + крупный сайзинг** = два пути выиграть: выбить сейчас ИЛИ собрать большой банк при доезде (имплайд-оддсы).

Правило 1 проекта: числа считает парсер, LLM только объясняет. Поэтому классы размера
и обратные оддсы — детерминированно в парсере; трактовка — в промпте.

## Что уже есть (не дублируем)

`parser/facts.ts`: размер ставки соперника (`BetFact`), размер бета Hero + нужное фолд-эквити
(`HeroBet`), пот-оддсы при защите (`HeroFacingBet`), дро/ауты/эквити (`DrawInfo`). Промпт уже
содержит раздел «Чтение по размеру ставки».
