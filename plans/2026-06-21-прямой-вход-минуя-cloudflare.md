> Дата: 2026-06-21
> Причина: Роскомнадзор душит Cloudflare из российских мобильных сетей.
> Симптом: whygrid.app «крутит и не открывается» на телефонах и в сети ЮKassa
> (проверяющий не может открыть сайт → блокирует верификацию платежей).
> Сайт жив: отвечает 200 снаружи и с десктопа. Проблема только в пути через Cloudflare.
> ECH уже отключён через API (value=off) — не помогло, значит блок шире ECH.

## Цель

whygrid.app открывается напрямую с российского сервера Yandex Cloud
(IP в РФ дата-центре), минуя Cloudflare-проксирование. Адрес и приложение
не меняются — меняется только сетевой путь. Tunnel оставляем как резерв
для мгновенного отката.

## Исходные данные

- VM: 81.26.186.177 (динамический IP! → сделать статическим), ru-central1-d
- SSH: `ssh -l trener-vm 81.26.186.177`, ключ `~/.ssh/id_ed25519`
- Прод: Next.js под pm2 (`trener`) слушает localhost:3000; cloudflared — pm2 `tunnel`
- DNS whygrid.app: зона на Cloudflare (zone_id f897...79f0), запись проксируется (orange)

## Откат

Вернуть A-запись whygrid.app в Cloudflare в режим «Proxied» (orange) — мгновенно
возвращает прежнюю схему через туннель.

## Риски

- Уходит защитный слой Cloudflare (DDoS/WAF). На раннем этапе приемлемо.
- Origin-IP становится виден. Приемлемо.
- Динамический IP без статики слетит при ребуте ВМ → сайт ляжет (Фаза 1 закрывает).
