# План: «Твои чарты» — зеркало открываний игрока (v1)

Дата: 2026-06-29
Связано: память тренера (личный чарт-дельта, v2), профиль игрока, open-leak.

## Замысел

Кнопка «Твои чарты» под профилем игры на «Мои турниры». Открывает сетку 13×13
по позициям (EARLY/HJ/CO/BTN/SB) — **как игрок реально открывается** по всей
дистанции. Это ЗЕРКАЛО, не учебник: базовый RFI-чарт игроку не показываем как
«эталон», он живёт под капотом и лишь решает, какая клетка «заметно шире нормы».

### Решения (из обсуждения с Артёмом 2026-06-29)

- **Частота, не результат.** Красим по тому, КАК открывается (частота — надёжна от
  ~30 турниров), НЕ по выигрышу/проигрышу руки (результат = дисперсия, сходится за
  тысячи турниров). Цвет = тенденция, не EV.
- **Мягкий порог.** «Широко» = `isOpenSignificantlyWide` (вне диапазона И вне полосы
  допуска), не любая нестандартная рука.
- **Порог выборки.** Клетка «горит» только если открыта ≥ N раз
  (`OPEN_CHART_FLAG_MIN_COUNT`); реже — приглушённый «звоночек», не приговор.
- **30 турниров** — порог надёжности (уже есть `CHARACTERISTIC_RELIABLE_FROM`), ниже
  — оговорка «картина предварительная».
- **Цвет.** Дизайн-система = один акцент (лайм). Красный зарезервирован под ошибки
  форм. Поэтому: лайм-заливка = широкое открывание с достаточной выборкой (сигнал,
  «найденный спот»); лайм-контур = широкое, но тонкая выборка; серая заливка =
  открывается в рамках нормы; пусто = не открывает. Буквальный красный/зелёный = не
  делаем без правки дизайн-системы.
- **Без LLM.** Чистая детерминированная агрегация (Правило 1).
- **Без схемы БД.** v1 считает на лету по клику (ленивая загрузка), новых колонок нет.
