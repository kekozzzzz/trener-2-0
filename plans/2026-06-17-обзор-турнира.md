# План: обзор турнира («общая картина» сверху карточки)

/ Задача: над списком раздач показать общую картину турнира — короткий обзор (стиль, итог, на чём терял) + список ключевых моментов, каждый со ссылкой на свою раздачу. Согласовано с Артёмом: формат «обзор + список моментов»; новый вызов LLM разрешён.

## Раздел 0 — Правила

- **Правило 1.** Обзор собирается из уже посчитанных парсером чисел и уже готовых разборов раздач (`analysis`, `verdict`). LLM пишет прозу и выбирает моменты — но не вычисляет метрики. Промпт содержит строку «все числа уже посчитаны — не вычисляй сам».
- **Надёжность ссылок.** LLM ссылается на раздачи по **индексу** из переданного списка (0..N−1), не по id/тексту. Шаг проверяет индекс и детерминированно мапит его в `handId`; невалидные индексы отбрасываются — галлюцинация ссылки невозможна.
- **Стоимость.** +1 вызов на турнир (~$0.02–0.03), один раз при готовности карточки (CARD_READY). На марже не сказывается (см. `.business/products/pricing.md`).

## Фазы

- [x] **Фаза 1 — схема.** `tournaments.summary JSONB?`. Миграция `20260617120000_add_tournament_summary` (чистый SQL вручную), применена в dev (`db execute`+`migrate resolve`) и trener_test (`migrate deploy`).
- [x] **Фаза 2 — порт LLM + промпт + адаптеры.** `TournamentSummary{Request,Result,Hand,Moment}` + метод `generateTournamentSummary` в `LlmPort`; промпт `config/prompts/tournament-summary.ts`; реализация в `anthropic.ts` (валидатор фильтрует мусорные моменты) и `fake.ts` (до 3 моментов на первые раздачи).
- [x] **Фаза 3 — шаг очереди.** `steps/generate-tournament-summary.ts`: грузит карточные раздачи с разбором в порядке createdAt, зовёт LLM, мапит index→handId (out-of-range отбрасывает), сохраняет `summary`. Идемпотентно (summary уже есть → пропуск). Зарегистрирован в `bootstrap.ts`.
- [x] **Фаза 4 — постановка задачи.** `markCardReadyIfComplete` при `count > 0` (переход в CARD_READY случается один раз) ставит `GENERATE_TOURNAMENT_SUMMARY`.
- [x] **Фаза 5 — карточка.** Секция «Общая картина» над «Раздачи для разбора»: обзорный абзац + моменты-ссылки на `/tournament/[id]/hands/[handId]`.
- [x] **Фаза 6 — тесты.** Шаг (мапинг индексов в handId, идемпотентность, пустой случай); постановка задачи при CARD_READY в тесте hand-analysis. 125 тестов зелёные, tsc и build чистые.
- [x] **Фаза 7 — hardening + журнал.** Безопасность: обзор из обезличенных данных, ссылки только на раздачи своего турнира, страница раздачи проверяет владельца — новой дыры нет. Журнал: `03-база-данных.md` (колонка) + `08-структура-кода.md` (шаг/порт).

## Итог

Готово. Над списком раздач — секция «Общая картина»: короткий обзор турнира (стиль, итог, на чём терял) + список ключевых моментов, каждый со ссылкой на свою раздачу.
