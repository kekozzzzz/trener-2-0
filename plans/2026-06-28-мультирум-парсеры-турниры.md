# План: мультирум-разбор турниров (PokerStars + WPN + Winamax)

**Дата:** 2026-06-28
**Задача:** научить продукт читать турнирные HH-файлы не только GGPoker, а ещё PokerStars, WPN (ACR/PokerKing) и Winamax. Один загрузчик — много форматов.

**Решения пользователя (2026-06-28):**
- Румы первой очереди: **PokerStars, WPN (ACR/PokerKing), Winamax** (GGPoker уже готов).
- Хвост (888 / partypoker / iPoker-XML / Chico) — НЕ сейчас, только если игроки реально оттуда.
- Разбираем **только турниры**. Кэш — отдельный трек позже (см. заметку в конце).

---

## Почему это адаптеры, а не правка одной регулярки

Заголовок и строки действий у каждого рума свои. Сверено на живых/открытых файлах (PokerStars и Winamax — в `Test/samples/`, GG и WPN — в `Test/`):

| Что | GGPoker (готов) | PokerStars | WPN (ACR/PokerKing) | Winamax |
|---|---|---|---|---|
| Сигнатура заголовка | `Poker Hand #...: Tournament #N, <название> - Level...` | `PokerStars Game #N:` / `PokerStars Hand #N:` `Tournament #N, $10+$1 ... - Level I (10/20) - ... ET` | `Game Hand #N - Tournament #N - Holdem (No Limit) - Level X (sb/bb) - ... UTC` | `Winamax Poker - Tournament "Имя" buyIn: 0.22€ + 0.03€ level: 1 - HandId: #... - Holdem no limit (10/20) - ... UTC` |
| Кто Hero | слово `Hero` | реальный ник по `Dealt to <ник> [..]` | реальный ник по `Dealt to <ник>` | реальный ник по `Dealt to <ник> [..]` |
| Действия | `Hero: folds` (двоеточие) | `Name: folds` (двоеточие) | `kekozzz folds` (без двоеточия) | `FredTeahupoo folds` (без двоеточия) |
| Блайнды | `Name: posts small blind` | `Name: posts small blind 10` | `Name posts the small blind` | `Name posts small blind 10` |
| Стек в Seat | `($N in chips)` | `(1500 in chips)` | дробный | `(1500)` — без «in chips» |
| Улицы | `*** FLOP/TURN/RIVER ***` | `*** FLOP/TURN/RIVER ***` | как GG | `*** ANTE/BLINDS ***`, `*** PRE-FLOP ***`, `*** SHOW DOWN ***` |
| Борд тёрна/ривера | `[..] [x]` | `[..] [x]` | как GG | **склеен**: `[8h Ks Jh][4h]`, `[8h Ks Jh 4h][Jc]` |
| Сбор банка | `collected N from pot` | `collected N from pot` | `collected N.NN from main pot / side pot-1` | `collected N from pot` |
| Бай-ин / деньги | иногда в заголовке | `$10+$1` в заголовке | нет | `0.22€ + 0.03€` в заголовке |
| Название турнира | есть | нет (только id) | нет | есть (в кавычках) |
| Валюта/суммы | фишки целые | фишки целые | фишки дробные | фишки целые, бай-ин в € |
| Кодировка ников | ASCII | бывает non-ASCII (`Ass'e bast�`) | реальные ники | non-ASCII (фр.) |

**Вывод:** PokerStars — ближе всех к GG (двоеточие, те же улицы) → легче. Winamax расходится сильнее всех (улицы, склеенный борд, без двоеточий) → среднее. WPN — уже расписан в отдельном плане.

## Архитектура (код уже к этому готов)

- Единый контракт `ParseResult` / `ParsedTournament` / `ParsedHand` в `parser/types.ts` — менять НЕ нужно. Поле `room` уже есть.
- Сейчас точка входа жёстко одна: `parseGGPokerMtt(buffer)` в `parser/ggpoker/index.ts`, её зовёт `features/tournaments/actions.ts`.
- Всё, что ниже парсера (факты, отпечаток спота, промпты, БД), форматонезависимо — лишь бы рум отдал турнир в общей форме.

Значит работа = **роутер форматов** + по одному **адаптеру на рум**, переиспользующих общие чистые функции (позиции, важность, стиль, агрегаты VPIP/PFR/AF).

Кэш — отдельная история: другой заголовок (`($0.05/$0.1)`), рейк в каждой раздаче, нет анте/уровней/ICM, и нужен свой коучинг-фрейм (глубина в BB, без ICM). Образец GG-кэша уже лежит (`Test/samples/ggpoker_cash_6max_sample.txt`). Берём после мультирума по турнирам.

## Обновление 2026-06-29 (по реальным файлам)
- **Героя определяем автоматически во всех румах** — отдельная кнопка «обозначь себя» НЕ нужна (решение Артёма). GG → слово `Hero`; WPN/Chico/PokerStars → `Dealt to <ник>`; iPoker → `<nickname>`. Ник у игрока в разных румах разный (kekoz / kekozz / kekozzz), но каждый файл сам указывает героя.
- **Chico = формат PokerStars** (проверено на `Test/samples/Chico/`): заголовок `PokerStars Hand #…: Tournament #…, $X+$Y USD … - Level (sb/bb) - … UTC`, действия с двоеточием, `Dealt to <ник>`, рейк в SUMMARY. → переиспользуем PS-парсер с правками (имя стола `CHC_…`, Level без римских цифр). Переезжает из «хвоста» в **PS-семью** — дёшево.
- Реальные образцы сложены (вне git): `Test/samples/wpn/` (ACR, турнир #34811363, 3 стола), `Test/samples/Ipoker/` (2 XML), `Test/samples/Chico/` (3 файла, PS-формат).
- Итоговая прикидка по сложности: **PS-семья одним парсером — PokerStars + Chico** (+ WPN близко, но свои мелочи); **Winamax** — отдельный текстовый; **iPoker** — отдельный XML. PokerKing (ещё один WPN-скин) ждёт файла.
