# План: ленивый разбор + лимиты по турнирам + приоритет очереди

Дата: 2026-06-28

Три связанные фичи, делаются по порядку: ленивый разбор → лимиты → приоритет.
Цены/лимиты/гейт трогают деньги (критическая поломка №1) — менять только по слову Артёма.

## Что уже есть (важно)

- «Разбор по клику» УЖЕ работает: `unlockTournamentAnalysisAction`
  (app/tournament/[id]/actions.ts) проверяет доступ (`assessAiAccess`) + часовой лимит,
  идемпотентно ставит `GENERATE_HAND_ANALYSIS` по одному турниру. Страница запертого
  турнира уже рисует кнопку «Разобрать этот турнир» (есть доступ) / «Оформить подписку».
- Значит ленивый разбор ≈ «не разбирать автоматически при заливе, всё гнать через
  существующую кнопку».

## Фаза A — ленивый разбор (фундамент)

- `parse-tournament.ts`: убрать авто-постановку `GENERATE_HAND_ANALYSIS`. Турнир рождается
  `analysisUnlocked=false` — «распарсен, не разобран». Метрики/раздачи/споты пишутся как
  сейчас (память не задета).
- Страница: поправить `canUnlock` — у первого бесплатного (если решим оставить хук)
  показывать «Разобрать», а не «Оформить подписку» (через `assessAiAccess`, а не
  `hasActiveAccess`, который знает только про подписку).
- Тесты: приёмочный — после залива турнир НЕ разбирается сам; клик «Разобрать» запускает.

## Фаза B — лимиты по турнирам

- `config/plans.ts`: + поле `tournamentLimit` (50 / 250 / 500), цена max 50 → 45.
- `features/usage/budget.ts` `assessAiAccess`: гейт по ЧИСЛУ разобранных за период
  (турниры с `analysisUnlocked=true`, созданные в текущем периоде) вместо суммы $-бюджета.
  Владелец/первый-бесплатный/paywall — сохранить.
- `config/usage-limits.ts`: ослабить часовой лимит загрузок (загрузка отвязана от денег).
- Страница цен: показывать «N турниров» вместо невидимого бюджета.
- Тесты: гейт пускает до лимита, на N+1 — стена.

## Фаза C — приоритет очереди

- `schema.prisma`: + `Task.priority` (миграция — КООРДИНИРОВАТЬ с памятью, она сейчас
  правит схему; делаю последней, впишусь после памяти).
- `claimTask` (worker.ts): `ORDER BY priority DESC, created_at`.
- `enqueue`: интерактив (DIALOGUE_QUESTION/VERDICT/CHAT_REPLY) — высокий приоритет,
  массовый разбор (HAND_ANALYSIS/PARSE) — низкий.
- (опц.) bump-on-open: открыл турнир — его разбор наверх.
- Тесты: интерактив обгоняет массовый разбор.

## Развилки (ждут слова Артёма)

1. **Первый бесплатный турнир нового игрока — авто-разбор (мгновенный «вау») или тоже по
   клику?** Рекомендую авто — это конверсионный хук, новичок сразу видит магию. Остальное
   (у подписчика) — по клику.
2. **Числа тарифов кодируем: Базовый $9/50, Продвинутый $20/250, Максимальный $45/500;
   «разбор» считается в момент клика «Разобрать».** Подтвердить.
3. **Приоритету нужна миграция, память сейчас правит схему. Делаю приоритет последним и
   впишу миграцию, когда увижу, где осела схема памяти.** Ок?
