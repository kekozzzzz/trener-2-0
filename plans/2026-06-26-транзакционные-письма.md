# План: транзакционные письма (приветствие, оплата, смена пароля, напоминание)

Дата: 2026-06-26

## Зачем

Уже есть почтовый адаптер (Unisender Go) и письмо сброса пароля. Добавляем остальные
транзакционные письма, чтобы пользователь получал подтверждения по ключевым событиям:
регистрация, оплата, смена пароля, скорое списание/истечение подписки.

Решения согласованы с Артёмом 2026-06-26:
- регистрация — **мягкое приветствие** (без блокировки доступа, без обязательного подтверждения почты);
- доп. письма: **«оплата прошла»**, **«подписка скоро спишется/истекает»**, **«пароль изменён»**;
- письмо «разбор готов» — НЕ делаем.

Все письма: русский, отправитель Whygrid (no-reply@whygrid.app), HTML + plaintext,
через существующий `safeSendEmail` (мягкая отправка — сбой доставки не роняет основное действие).
