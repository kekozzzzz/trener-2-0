# План: публичная страница-пример полного разбора

Дата: 2026-08-17
Источник: реакция реальных игроков на GipsyTeam (тред 2026-08-16, см. `.business/marketing/gipsyteam.md`
и `.business/audience/objections.md` п.5) — скептики не верят заявлению «числа считает алгоритм» на слово,
просят показать внутреннюю логику. Пункт бэклога `.business/execution/backlog.md` → «Публичный пример
полного разбора» (приоритет усилен этим сигналом).

Задача: одна страница сайта с ПОЛНЫМ настоящим разбором одной реальной раздачи (стол → вопрос тренера →
ответ → реплика → вердикт с числами парсера), доступная без регистрации. Не макет и не демо-форма (как
сейчас в секции «Разбор изнутри» на главной), а честно пройденная раздача. Design-system.md запрещает
показывать на витрине то, чего нет в продукте — вся разметка собирается из уже существующих компонентов
(`ProductWindow`, `HandTable`, диалоговые блоки, `TicketCta`), новый визуальный язык не изобретаем.

**Раздача выбрана скан-скриптом `__tests__/manual/lucky-win-scan.test.ts`** (запуск
`RUN_LUCKY_SCAN=1 npx vitest run __tests__/manual/lucky-win-scan.test.ts`) по реальным файлам `Test/`:
`Test/GG20260611-1320 - Bounty Hunters Deepstack Turbo 5.40.txt`, раздача №59. Hero A♣K♠ 3-бетит префлоп,
на флопе 6♥7♦4♥ ставит крупно без пары и без дро, соперник коллирует ва-банк парой шестёрок — эквити
Hero в этот момент **18.5%** (посчитано `detectHeroLuckyWin`/`equityVsHand`, парсер, не ИИ). Ривер K♥
докатывает Hero пару королей, итог **+14 398 фишек (28.8bb)** — средний банк, выигранный на объективно
слабом решении. Соперники в файле уже под хэш-ID (`d343e857` и т.п.) — анонимные GG-столы, реальных
ников нет, обезличивать вручную не требуется.
