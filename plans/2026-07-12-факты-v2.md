# Факты-v2: парсер отдаёт готовым всё, на чём ИИ «думает»

**Дата:** план написан 2026-07-11 вечером, работа — с 2026-07-12.
**Замысел.** Аудиты 11.07 показали: все места, где модель без размышлений небрежничает, — это места, где ей не хватает готового факта, и она вычисляет сама. Отдаём эти вычисления парсеру (правило 1 расширяется), чтобы быстрый режим (reasoning off, 8–9 с) догнал по точности вдумчивый (low, 21–34 с). Всё детерминированно: наши конфиг-чарты + движок эквити (range-equity, Монте-Карло кулеров) + перебор. Никакого солвера, никаких «оценок из головы модели».

**Критерий приёмки всего плана:** контрольная восьмёрка + полный турнир на GLM-off больше не показывают классов небрежностей из прогона 11.07 (перепутанное фолд-эквити, потерянная механика излишка, «нокаут-фактора нет», гадание «вероятно сет» при вскрытых картах).

## Фаза 1 — Эквити против чартового диапазона [ ]

Самый большой эффект. В спотах, где диапазон соперника формализован нашими чартами (опен-пуш → чарт пуш-фолда; рестил → чарт рестила; колл vs пуш; опен позиции → RFI-чарт), парсер перебором считает эквити руки Hero против этого диапазона и отдаёт строкой с готовым сравнением:

> «Эквити ATo против чартового диапазона опен-пуша HJ ≤10 BB: ≈47% — выше порога колла ≈8% с большим запасом.»

- [ ] хелпер: грид чарта → список комбо → эквити перебором/Монте-Карло (переиспользовать range-equity.ts и движок кулеров);
- [ ] строки в renderHandFacts для спотов: колл vs пуш, рестил (эквити при колле по чарту колл-vs-рестил), ре-джем поверх пуша, защита BB vs опен;
- [ ] в промпт: «эквити против чартового диапазона — из парсера; свои проценты не выводи»;
- [ ] тесты на известных матчапах (ATo vs широкий пуш ≈47–50%, 55 vs пуш BTN ≈45–48% и т.п.).

## Фаза 2 — Готовое фолд-эквити по чартам [ ]

Обе половины пуша — фактами: доля опен-диапазона позиции (по RFI-чарту), которая продолжает против пуша (по чарту колла), остальное — фолд:

> «По эталонным чартам: опен LJ ≈13% рук; из них колл против пуша 17 BB ≈5% → сбрасывает ≈2/3 диапазона.»

- [ ] подсчёт долей комбо грида (уже есть подсчёт комбо в чартах /charts);
- [ ] строка в facts для рестил/ре-джем спотов;
- [ ] тест: доли совпадают с тем, что показывает страница /charts.

## Фаза 3 — Геометрия олл-инов и ре-джемов [ ]

Арифметика, которую быстрый режим теряет, а старая модель путала всегда:

> «Ре-джем 29.2 BB поверх олл-ина 12.6 BB: излишек возвращается, если никто не заколлирует шире, — эффективный риск 12.6 BB. Покрывают тебя: SB 28.8 BB. Мёртвые деньги в банке: 4.1 BB.»

- [ ] детектор: Hero ALL_IN поверх чужого входа → эффективный риск (макс. стек соперников, не больше своего), список покрывающих живых, мёртвые деньги;
- [ ] отдельная пометка «короткий уже в олл-ине — его не выбить, фолд-эквити только против живых позади» (ровно тот ляп off-режима);
- [ ] тесты на раздачах #0 (ATo) и #25 (55) из контрольного набора.
