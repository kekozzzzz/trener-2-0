# Каталог типов раздач (концепт, на согласование)

**Дата:** 2026-07-14. Задача Артёма: вместо абстрактных «сильная/средняя/слабая» показывать игроку
КОНКРЕТНЫЙ ТИП МОМЕНТА раздачи — так интереснее заглянуть. Группы (сильные/слабые/спорные/кулер)
остаются только ВНУТРИ (сортировка, цвет), игроку не показываются как названия.

**Принцип (Правило 1):** каждый тип — детерминированный ДЕТЕКТОР в парсере. Помечено, что уже есть
(канал/детектор в коде) и что нужно писать заново. «Переиграл» — не отдельная группа, а плюс к
сильным + возможная позитивная подсветка «тут ты молодец».

---

## 🔑 НЕСУЩИЙ ПРИНЦИП: тип детектирует парсер, «молодец / ошибка» вскрывает ДИАЛОГ

Один и тот же ход — разная оценка по ОСОЗНАННОСТИ (инсайт Артёма 2026-07-14):
- **«Выбил блефом»**: если игрок ПОНИМАЛ, что выбивает (читал слабость соперника, ставил по плану) —
  сильный ход, молодец. Если выбил СЛУЧАЙНО, не понимая, что делает — это везение/ошибка, и
  разбирать надо именно это.
- Парсер видит только ФАКТ (соперник сбросил на агрессию Hero). ПОНИМАЛ ли игрок — вскрывает
  сократовский вопрос «зачем ты поставил, что ты читал?». Оценка — из ответа.
- Это и есть **Правило 2**: тип-момент = повод для диалога; молодец/ошибка = вывод из ответа игрока,
  а не из результата раздачи.
- Так же со сквизом / изоляцией / 3-бетом / чек-рейзом: сам ход нейтрален. Нажал сквиз, СМОТРЕЛ
  чарт, понимал — очень молодец. Нажал наугад — сомнительно, разбираем. Нет за ходом ничего
  значимого — раздача уходит в мусор (не показываем, см. фикс отбора).

**Следствия для реализации:**
- У агрессивных/инициативных ходов метка типа НЕ несёт готовой оценки — она открывает диалог про
  замысел. Тренер не хвалит и не ругает до ответа.
- Несколько меток на раздачу — ДА (Артём подтвердил), если моментов было несколько.
- Ход без значимости (механический сквиз ни на что не влияющий и т.п.) = мусор, скрываем.

## 🟢 СИЛЬНЫЕ (ты переиграл / сыграл сильно)

| Тип (что видит игрок) | Что за момент | Детектор |
|---|---|---|
| **Выбил блефом** | последней агрессией заставил лучшую руку сбросить | ЕСТЬ (WON_BLUFF) |
| **Поймал блеф** | тонкий колл-кэтч поймал блеф соперника | ЕСТЬ (BIG_CALL_WON, частично) |
| **Добрал велью** | вэлью-бет, слабейшая рука заплатила | НОВЫЙ |
| **Тонкий велью-ривер** | доставил тонкую велью-ставку на ривере | НОВЫЙ |
| **Дисциплинированный фолд** | сбросил сильную руку там, где реально был бит | ЕСТЬ (BIG_FOLD, если фолд верный) |
| **Верный олл-ин** | пуш/колл по чарту в своей зоне, сыграл правильно | НОВЫЙ (сверка с пуш-фолд/чартами) |
| **Выжал максимум** | верная линия/сайзинг с монстром — забрал по максимуму | НОВЫЙ |

## 🔴 СЛАБЫЕ / УТЕЧКИ (ошибки, часто без потери фишек — их сейчас НЕ видно)

| Тип | Что за момент | Детектор |
|---|---|---|
| **Пропустил контбет** | был агрессором префлопа, чекнул выгодную доску вместо ставки | НОВЫЙ |
| **Не поставил пробу** | флоп прочекан всеми, не забрал банк ставкой в свою очередь | НОВЫЙ |
| **Недобрал велью** | прочекал сильную руку насквозь, где платили | ЕСТЬ (MISSED_VALUE) |
| **Перефолд на 3-бет** | сбросил играбельную руку на 3-бет (отдал без боя) | НОВЫЙ (сверка с vs-3bet чартом) |
| **Перефолд на 4-бет** | сбросил то, что по стеку/чарту надо было играть | НОВЫЙ |
| **Недоколл** | сбросил в пот-оддсах, которые оправдывали колл | НОВЫЙ (пот-оддс уже считаем) |
| **Лузовый колл** | заплатил слабой рукой (вторая пара и хуже) без оснований | НОВЫЙ |
| **Слишком широкий опен** | открыл мусорную руку не с той позиции | ЕСТЬ (open-leak / RFI-чарт) |
| **Переоценил руку** | вложил лишнее средней рукой (overplay) | НОВЫЙ |
| **Блеф в станцию** | блефовал против того, кто не сбрасывает (телефон) | НОВЫЙ (нужен тип соперника) |
| **Лимп не по делу** | лимп/долимп там, где не нит-спот | ЕСТЬ (limp detector) |
| **Не защитил BB** | сбросил ББ в хороших оддсах защиты | ЕСТЬ (bb-defense чарт) |

## 🟡 СПОРНЫЕ (неочевидно → сократовский диалог «почему»)

| Тип | Что за момент | Детектор |
|---|---|---|
| **Крупный олл-ин** | пуш/ре-пуш на коротком стеке — правильно ли | ЕСТЬ (пуш-детекторы) |
| **Крупный колл олл-ина** | заколлировал олл-ин в спорном споте | ЕСТЬ (BIG_CALL) |
| **Крупный фолд после вложения** | сбросил, уже вложив заметную часть | ЕСТЬ (BIG_FOLD / FOLD_INVEST) |
| **Дорогая потеря** | крупно проиграл спорную раздачу | ЕСТЬ (loss-ранжир) |

## 🔵 ИНИЦИАТИВНЫЕ ХОДЫ (оценка — ТОЛЬКО через диалог про замысел)

Сам ход нейтрален: молодец если осознанно (смотрел чарт / читал соперника), разбор если наугад,
мусор если ни на что не влияет. Метка открывает вопрос «зачем?», а не готовую оценку.

| Тип | Что за момент | Детектор |
|---|---|---|
| **Сквиз** | 3-бет против опена, когда уже есть коллеры | ЕСТЬ (squeezePosition) |
| **Изоляция лимпера** | рейз-изоляция поверх лимпа | ЕСТЬ (iso-chart / limp) |
| **3-бет** | ре-рейз против одиночного опена | ЕСТЬ (vs-open чарт) |
| **Чек-рейз** | чек, затем рейз в той же улице | ЕСТЬ (renderTacticalMarks) |

## 🎲 КУЛЕР (не повезло — сыграл верно)

| Тип | Что за момент | Детектор |
|---|---|---|
| **Проиграл впереди** | вложился далеко впереди, соперник доехал | ЕСТЬ (cooler) |
| **Повезло доехать** | выиграл далеко позади — «повезло» тоже разбираем | ЕСТЬ (lucky-win) |

## Итого
- **~29 типов**, из них ~15 уже детектируются (каналы decision-weight + кулеры + чарт-лики +
  сквиз/изоляция/3-бет/чек-рейз), ~14 новых детекторов.
- Игроку — конкретный тип момента. Внутри — группа (для сортировки/цвета/приоритета в диалоге).
- У инициативных ходов метка НЕ несёт оценки — открывает диалог про замысел (осознанность).
- Несколько меток на раздачу — ДА (если моментов несколько). Раздача без значимого момента — мусор,
  не показываем.
- Порядок реализации: сперва подключить УЖЕ имеющиеся детекторы как метки-типы (дёшево — большая
  часть), потом писать новые по приоритету (пропущенный контбет / перефолд / недоколл — самые частые
  утечки).

## Открытые вопросы к Артёму
1. Список из ~29 типов — что ещё убрать/добавить? (пока покрыты: потери, утечки-бездействия,
   инициативные ходы, кулеры, сильные ходы.)
2. Позитивные типы («Выбил блефом», «Добрал велью») — показывать наравне с ошибками (учим И хвалим),
   или ошибки всё же крупнее/приоритетнее в списке?

## Решено (Артём, 2026-07-14)
- Оценка хода — по ОСОЗНАННОСТИ, через диалог, не по результату (несущий принцип выше).
- Несколько меток на раздачу — да.
- Раздача без значимого момента — мусор, скрываем.
- Инициативные ходы (сквиз/изоляция/3-бет/чек-рейз) добавлены.
- **ПОРЯДОК в карточке турнира (приоритет показа):** 🟡 критические (диалоги «почему») → 🟢 сильные
  ходы (похвала «тут ты молодец») → 🔴 утечки → остальное → 🎲 кулеры. Сильные подняты ВПЕРЁД, сразу
  за критическими, а не в хвост.
- **ТОН:** хвалить щедрее, чем ругать — человеку лучше играется и учится, когда его хвалят больше
  (Артём). НО только за РЕАЛЬНЫЕ осознанные сильные ходы — «если есть за что», не за пустое. Пустой
  ход без замысла в сильные не попадает (уходит в мусор или в диалог про осознанность).
