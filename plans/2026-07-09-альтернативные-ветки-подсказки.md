# Альтернативные ветки решений — карта подсказок парсера

> **Статус:** черновик-дизайн (2026-07-09). Ждёт ответов Артёма на открытые вопросы → потом фазовый план кода.
> Собрано многоагентным разбором (16 типов решений × enumerate+verify + синтез).

## Замысел

Парсер для каждого решения Hero считает не только сыгранную линию, но и **альтернативные ветки** («ты сыграл колл-колл-чек — вот числа, если бы рейз»). Тренер подаёт это интуитивной подсказкой, не вердиктом.

## Граница (нарушать нельзя)

Парсер считает **ЧИСЛА** ветки (фолд-эквити, пот-оддсы, эквити, ауты, банк-при-колле, SPR, членство в чарте), но **НЕ выносит вердикт «ветка X лучше»**. Ранжирование «лучше/хуже» = модель ответа соперника = солвер, а мы сознательно не солвер (неверный вердикт = скриншот в Discord = репутационная смерть). Формула подсказки: «ты сделал A — вот числа ветки B», не «надо было B».

Правила показа: x3 — дефолтный размер гипотетического рейза; считаем всегда, показываем только когда осмысленно; глушим чистые блефы «0 в нулю» и всё, что учит спуке.

## 1. ГДЕ ПОДСКАЗЫВАТЬ

### Сквозные (считаем один раз)
- **Рестил-джем 10-25bb против опена** — ПО УСЛОВИЮ. Стек 10-25bb, ровно один опен, рука в рестил/пуш-чарте (вкл. A2s-A5s), Hero сыграл иначе. Хук: членство в чарте [уже считаем]; порог фолдов джема [достроить] — только как порог окупаемости.
- **Фолд по дисциплине чарта** — ПО УСЛОВИЮ (на олл-инах ВСЕГДА). Рука ЯВНО вне чарта (не «граница»). Хук: вердикт чарта [уже считаем]. Никогда как «сохрани стек».
- **Джем-или-фолд ≤14-15bb** — по Nash пуш-фолд-чарту [уже считаем].

### Префлоп — первый в игру (RFI)
- **Открыть рейзом вместо лимпа** (не-SB) — лимп, стек ≥20bb, рука в RFI-чарте [достроить: rfiCellState на лимпе].
- **Фолд вместо лимпа мусором** — то же, рука вне чарта [достроить].
- **Открыть вместо фолда** (упущенный вход) — фолд, стек ≥20bb, rfiCellState=ALWAYS [достроить: детектор «фолд первым»].
- **Фолд вместо открытия мусором** — open-raise, ≥20bb, вне чарта [уже считаем].
- **Джем вместо мин-рейза/фолда на коротком** — ≤14bb, рука в пуш-чарте [достроить].
- **Фолд вместо тильт-джема** — ≤14bb, пуш вне Nash [уже считаем].
- **SB: рейз 3-3.5bb вместо лимпа силой** — SB, лимп, ≥20bb [достроить: rfiCellState('SB')].
- **Размер открытия вне полосы** — ЯВНО за полосой (>4bb или мин). Десятые не флагать [достроить].

### Префлоп — один опен впереди (не блайнд)
- **Фолд доминируемой руки** — чарт vs опен = вне/граница-фолд [уже считаем].
- **Холодный колл IP** — call-регион чарта (пара/одномастная связка, НЕ доминируемый оффсьют), IP, глубоко [уже считаем].
- **3-бет на велью** — велью-регион чарта [уже считаем].

### Префлоп — BB против опена
- **Колл (защита)** — рука в чарте, опен мелкий/стандарт, глубоко [уже считаем].
- **Фолд BB** (DOWNGRADE) — ЯВНО вне чарта ЛИБО крупный опен ЛИБО короткий стек. «Граница» фолд не включает [уже считаем].
- **3-бет на велью** — велью-зона, шире против позднего опена [уже считаем]. Блеф-3бет — только если игрок сам предложил.

### Префлоп — блайнд на блайнд
- **SB: рейз 3-3.5bb** — ВСЕГДА. Рука в рейз-порции BvB, >15bb [уже считаем].
- **SB: лимп-комплит** — слабый низ, против фолда [уже считаем].
- **SB: фолд** — вне рейз- и лимп-порции [уже считаем].
- **SB: пуш вместо мин-рейза** — ≤15bb [уже считаем].
- **BB: колл против SB-опена** — ВСЕГДА. Низкая цена, рука в чарте, глубоко [уже считаем].
- **BB: фолд против SB** (DOWNGRADE) — вне/граница И (крупный опен ИЛИ короткий стек) [уже считаем].
- **BB: 3-бет велью / изо-рейз против лимпа / чек за спиной** — по зонам чарта [уже считаем].

### Префлоп — открыл и получил 3-бет
- **Фолд на 3-бет** — ВСЕГДА. Чарт vs 3-бет = вне/граница [уже считаем].
- **Холодный колл IP (сет-майнинг)** — колл-часть чарта, IP, flop-SPR ≥3 [достроить: SPR в узле].
- **4-бет на велью** (QQ+/AK) — велью-часть, стек достаточен [уже считаем].
- **4-бет-джем короткий/средний** — обычный 4-бет оставляет ≤1 банка, рука в джем-диапазоне [достроить: коммитмент].

### Префлоп — опен + коллеры (сквиз)
- **Сквиз на велью** — велью-зона, ≥25bb, ≥1 коллер [уже считаем].
- **Оверколл в мультивей** — пара/одномастная связка, глубоко, цена, IP [уже считаем].
- **Фолд по дисциплине** — ВСЕГДА. Вне велью-зоны И плохие имплайды [уже считаем].

### Префлоп — передо мной олл-ин
- **Колл по пот-оддсам + чарту** — ВСЕГДА. Закрываешь торги, рука в чарте ИЛИ запас эквити; ≤5bb почти всегда [уже считаем].
- **Колл по эквити против ОТМЕЧЕННОГО диапазона** — игрок разметил пуш, спот пограничный [достроить: таблица эквити рука-vs-рука].
- **Фолд** (DOWNGRADE) — ТОЛЬКО чарт=вне (глазомер убрать) [уже считаем].
- **Колл с баунти-поправкой** — PKO, Hero покрывает, сумма в снимке [достроить: bountyValue].

### Постфлоп — перед ставкой (ЯДРО)
- **Фолд по дисциплине** — эквити < цены И имплайды мертвы; ИЛИ крупная ставка в страшную доску без дро [уже считаем].
- **Колл по пот-оддсам** — эквити ≥ цены, живой стек [уже считаем].
- **Колл дро по имплайдам** — cleanPct < цены, но impliedExtraNeeded добирается, борд не спаренный [уже считаем].
- **Колл-блефкатч слабой парой** (DOWNGRADE, вопросом) — паттерн бет-бет-чек, недоминированный кикер, не телефон [достроить: флаг затухающей агрессии].
- **Колл вместо рейза (контроль банка)** (DOWNGRADE) — отмеченный диапазон ≈50%, высокий SPR [достроить: SPR в узле].
- **Колл олл-ина** — equityVsRange >> цены [уже считаем].
- **Рейз-полублеф с реальным дро (3x)** — настоящее дро, борд не спаренный/готовый, соперник может сбросить [достроить: foldsNeededPct + drawEquity в гипотетическом узле].
- **Дешёвый рейз против мелкой ставки (<33%)** (DOWNGRADE) — реальное эквити/дро (не голые блокеры), не телефон [достроить: foldsNeededPct].
- **Велью-рейз топ-парой+ ТОЛЬКО на мокрой доске** — рука ≥ топ-пары, two-tone/связный (не сухой) [уже считаем].
- **Коммит-джем при низком SPR** — SPR ≤2, сильная готовая [достроить: SPR в узле].

### Постфлоп — я первый (чек/бет)
- **Тонкий велью-бет (<50%)** — топ-пара средний кикер/сильная вторая пара, сухо/полусухо [уже считаем].
- **Крупный велью-бет на дровяной** — две пары+/сет/оверпара, борд не собрался, есть кому платить [уже считаем].
- **Полу-блеф бет с дро** — живое дро, не спаренный, не телефон [достроить если Hero чекнул: foldsNeededPct/potIfCalled гипотетического бета].
- **Бет-защита уязвимой рукой на дровяной** — уязвимая топ-пара/оверпара, two-tone/связная [уже считаем].
- **Стаб ~1bb в лимп-банке** — HU против чекнувшего BB, ровно ОДНА ставка [достроить: foldsNeededPct стаба].
- **Чек-сдача воздухом** — мусор без шоудауна [уже считаем].
- **Чек-контроль маргинальной рукой** (DOWNGRADE, вопросом) — средняя пара с шоудауном, OOP, глубоко, угроза чек-рейза [достроить: SPR в узле].
- **Чек-бэк на шоудаун** (DOWNGRADE, вопросом) — маргинальный блефкэтчер [уже считаем].

### Постфлоп — перед олл-ином
- **Колл (эквити против всего пуша)** — ВСЕГДА. Отмеченный диапазон ≥ цены с запасом [уже считаем].
- **Колл дро по прямому эквити** — cleanPct ≥ цены, борд не убивает доезд [уже считаем].
- **Фолд** — эквити СТРОГО ниже цены И ширина проверена [уже считаем].
- **Ре-джем поверх КОРОТКОГО пуша** — мультивей, Hero покрывает, не хедз-ап [достроить: foldsNeededPct].
- **Колл с баунти-поправкой** — нокаут, Hero покрывает [достроить: флаг формата].

### Постфлоп — мне пришёл чек-рейз
- **Фолд (дефолт)** — ВСЕГДА. Чек-рейз ≥полбанка, тёрн/ривер, слабая рука без дро, нет рида [уже считаем].
- **Колл с живым дро** — FD/ОЭСД/комбо (не гатшот), прямые оддсы ≥ цены [уже считаем].
- **Колл сильной-не-топ для контроля** (DOWNGRADE) — оверпара/две пары (не топ-пара), SPR ≥3, мокро [достроить: SPR в узле].
- **Ре-рейз на велью** — сет+/две пары топ, two-tone/связная [уже считаем].
- **Джем при низком SPR** (DOWNGRADE) — сильная готовая, SPR ≤2 [достроить: SPR/коммитмент].

### Постфлоп — донк-бет в меня
- **Фолд** — воздух/доминируемая пара без шоудауна, нет аутов. НЕ когда цена ≤ эквити [уже считаем].
- **Колл-блефкатч** (DOWNGRADE) — реальный шоудаун, цена ≤ эквити, затухающая агрессия [уже считаем].
- **Колл дро по имплайдам** — outsClean>0, не спаренный, есть чем платить [уже считаем].
- **Велью-рейз сильной рукой** — топ-пара+, two-tone/связная/монотон, не сухая радуга [уже считаем].
- **Полу-блеф рейз с дро** — настоящее дро, рег/доска под защищающегося. При сомнении вопросом [достроить: drawEquity + foldsNeededPct 3x].
- **Блеф-рейз с блокерами против рега** (DOWNGRADE, ТОЛЬКО вопросом) — игрок подтвердил «рег» + низкая связная + блокеры [достроить: foldsNeededPct + блокеры].

### Ривер (дро исчерпано)
- **Тонкий велью-бет (25-45%)** — средний+ тир, сухо, пассивный/телефон, размер мелкий [уже считаем].
- **Крупный велью-бет (60-100%+)** — сильная готовая, мокро/добрала, есть сильная-но-хуже плательщица [уже считаем].
- **Чек-бэк без велью** (DOWNGRADE, вопросом) — ТОЛЬКО маргинальный тир [достроить: бакетизация].
- **Блеф-бет** (DOWNGRADE) — ТОЛЬКО собравшаяся страшная доска + фолдящий тип [уже считаем].
- **Блефкэтч-колл (бет-бет-чек)** — затухающая агрессия, рид вопросом, недоминированный кикер [достроить: MDF].
- **Велью-колл против ставки** — отмеченный диапазон > цены, не поляризованный овербет [уже считаем].
- **Велью-рейз ривера** — near-нат, отмеченный диапазон, есть плательщицы [достроить: бакетизация + блокеры].
- **Блеф-рейз ривера** (почти NEVER) — страшная доска + блок натсов + рид + мелкая ставка [достроить].
- **Фолд против крупной поляризованной** — овербет, страшная доска, средняя рука без блокеров [уже считаем].

## 2. ГДЕ ГЛУШИТЬ (никогда)

**Чистые блефы «0 в нулю»:** блеф в телефон/в сухую низкую доску; блеф-рейз «сбросит ли готовую» (модель оппа); блеф-ре-рейз поверх чек-рейза; сквиз/3бет/4бет-блеф с блокерами (прибыльность = частота фолда = солвер) — разбирать ТОЛЬКО если игрок сам предложил.

**Пассивность там, где верен колл/фолд:** фолд «сохранить стек» (у фишек нет памяти); фолд/чек когда эквити ВЫШЕ цены (оверфолд); пассивный колл вместо велью-рейза подавляющей рукой (недобор); флэт AA/KK ради трэпа; дисконт эквити колла «как при выставлении» на олл-ине.

**Короткий стек:** холодный колл 10-25bb против опена/в сквизе/из блайнда (имплайды мертвы → канализируем в джем-или-фолд); мин-рейз/опен меньше олл-ина на ≤10bb.

**Доминируемые:** холодный колл ATo/KJo/слабых тузов; холодный флэт 3-бета OOP доминированной рукой.

**Лимп/дисциплина:** рекомендовать open-limp с не-SB (учим пассивности); «дисциплинированный» фолд руки из лимп/рейз-чарта; SB-комплит вместо фолда слабой рукой.

**Продвинутое (не для микро):** блок/проб-бет; овербет; чек-рейз-ловушка; колл-флоат; крупный велью-бет когда всё слабее сдастся; вторая бочка без руки в лимп-банке.

**Ретро и невозможное:** «надо было запушить раньше» (разворот задним числом); мини-рейз против полного олл-ина (нелегально); геройский колл без рида; ICM/баунти-поправка джема; GTO-частоты и «оптимальный» сайзинг.

## 3. ЧТО ДОСТРОИТЬ В ПАРСЕРЕ (ТЗ)

**А. Тривиальная арифметика (легко):**
1. **foldsNeededPct несделанного джема/рейза** = risk/(potBefore+risk). Та же формула, что для фактического бета — прогнать для гипотетического узла. Нужна в куче веток. Подавать как порог окупаемости, НЕ как эквити.
2. **MDF** = 1 − bet/(pot+bet) — страховка от оверфолда.
3. **Размер открытия в bb** + сравнение с полосой RFI из конфига.
4. **Пот-оддсы своей ставки** = bet/(pot+bet).

**Б. Проводка существующих грейдеров:**
5. **rfiCellState в лимп-детектор** (сейчас бланкетный вердикт) + SB-рейз-рейндж.
6. **Детектор «фолд первым в игру» (≥20bb)**.
7. **Детектор «мин-рейз/фолд первым при ≤14bb»** + pushCellState.

**В. Переиспользование перебора (range-equity.ts):**
8. **Счётчик блокеров** = combosForCode − liveCombos. Вывести наружу.
9. **drawEquity в гипотетическом узле рейза** (вызвать существующую функцию).
10. **Бакетизация отмеченного диапазона** по категориям готовых рук (handCategory по live-комбо).

**Г. Снятие состояния узла (данные в walkPot):**
11. **SPR/остаток/коммитмент в ТЕКУЩЕМ узле (тёрн/ривер)** — не только sprFlop. Нужно многим постфлоп-веткам.

## 4. ПОГРАНИЧНЫЕ — решение владельца

- **foldsNeededPct** — честный порог окупаемости, но игрок легко прочтёт как эквити/гарантию фолда. Показывать как поддержку или держать внутри?
- **Ace-blocker рестил и блеф-ветки** — второй путь (фолд-эквити) зависит от типа оппа, парсер его не знает → все сведены к «вопросу». На грани NEVER.
- **Блеф-рейз с блокерами** — только вопросом, на грани NEVER. Показываем вообще?
- **Баунти-поправка** — риск переоценить баунти → лайтовые переколлы.
- **Таблица эквити** — большой офлайн-билд ради одной ветки.
- **Флаг размера открытия** — риск GTO-придирок по десятым BB.

## 5. РЕШЕНИЯ АРТЁМА (2026-07-10, закрыто)

1. **foldsNeededPct** → держим ВНУТРИ движка, тренер объясняет словами. **Формулировка (правка 2026-07-10):** это ДОЛЯ ДИАПАЗОНА соперника, которая должна сброситься, а НЕ «частота раз». Тренер говорит «чтобы рейз окупился, больше N% его диапазона должно сброситься», НЕ «он сбрасывает чаще N% раз». Голый % игроку не показываем. ⚠️ Та же правка нужна существующей строке facts.ts «соперник сбрасывает чаще ≈Y%» при вплетении в промпт.
2. **Таблица эквити рука-vs-рука** → СТРОИМ (точно и посильно). Разовый офлайн-предпосчёт всех матчапов → рантайм-усреднение по отмеченному диапазону. Приоритет — не Фаза 1 (нужна для одного спота: префлоп-олл-ин против отмеченного диапазона).
3. **Блеф-ветки и ace-blocker рестил** → по-минимуму: только с блокерами, крайне редко, ТОЛЬКО уточняющим вопросом. Чистый блеф-рейз — выкидываем.
4. **Баунти** → поправку считаем ТОЛЬКО когда точно видно, что турнир баунти (название GG содержит «Bounty»/«KO»/«PKO») И сумма головы есть в файле. Нет полной инфы → обычные пот-оддсы без баунти.
5. **Размер открытия** → стандарт **2-2.2 BB**, крупный **2.5-3+** = сила (AQ, иногда AK, JJ+). Парсер даёт классификацию размера; вывод «крупный = монстры» тренер применяет ТОЛЬКО с учётом типа оппонента (рыба лупит крупно всем — ложный читч). По сути это опп-сайзинг-РИД, а не альт-ветка Hero.
6. **Границы стеков** → подтверждено как есть: ≥20bb=RFI-чарты, ≤14bb=пуш-фолд, 14-20bb не судим, 10-25bb=рестил-зона против опена.

## Идея «намерение игрока» (2026-07-10)

Артём: сделать так, чтобы было понятно ДЕЙСТВИЕ игрока (блеф/велью/…) - «не мы ему сказали, а он сам сделал, а мы поняли что и для чего, чтобы не тупить». Три части:

1. **Игрок называет намерение** (его половина, сократовский вопрос - ПРОМПТ, позже/гейт): тренер спрашивает «что ты этим хотел - добрать, выбить, защититься?». Игрок отвечает сам.
2. **Парсер даёт объективную ФОРМУ действия** (наша половина - ГОТОВО): `parser/action-shape.ts` `heroActionShapes` классифицирует ставку/рейз Hero по картам+борду+дро → VALUE / PROTECTION / THIN_VALUE / SEMI_BLUFF / BLUFF / MARGINAL. Это ЯКОРЬ (зеркало формы), НЕ намерение и НЕ вердикт. Сила руки - новый бакет `strength` в `heroMadeHand` (единый источник). 7 тестов зелёные.
3. **Тренер сверяет** (не тупить - ПРОМПТ, позже): сравнивает названное игроком намерение с объективной формой. Совпало → подтвердил; расхождение → сократовский толчок («ты сказал велью, но готовой руки нет и слабее тебя ничего не платит - это скорее блеф, так и хотел?»). MARGINAL-бакет прямо говорит «спроси игрока» - классификатор не гадает.

Точная версия («доберёт ли велью реально» = сколько слабее платит из ОТМЕЧЕННОГО игроком диапазона) - апгрейд через бакетизацию (№10, Фаза 3).
