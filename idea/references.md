## Копилка чужих решений

Что уже существует, какие подходы проверены, что можно взять.

### Коммерческие трекеры

**PokerTracker 4**
Ветеранский десктопный трекер: хранит базу раздач, строит HUD и статистику, позволяет фильтровать по ситуации (3-бет из позиции, текстура борда и т.п.).
Источник: https://www.pokertracker.com/products/PT4/
Ключевое: подробная фильтрация по ситуациям — полезно для изоляции конкретного вида ошибки.
**Не подходит** — нет AI-разбора, нет диалога, нет объяснений. Инструмент для опытного аналитика, не для обучения.

---

**Hold'em Manager 3**
Конкурент PT4, 25+ стандартных отчётов; есть готовые дашборды «CBetting», «3-Betting», «River Play».
Источник: https://www.holdemmanager.com/hm3/
Ключевое: тематические ситуационные отчёты — хорошая модель для быстрого обнаружения утечек.
**Беру** — идею тематических дашбордов по ситуациям.

---

**Hand2Note**
Профессиональный трекер с динамическими HUD; уникальные отчёты: winrate с рыбами / без, winrate зависимо от состава стола.
Источник: https://hand2note.com/
Ключевое: профилирование контекста стола — не просто статистика, а контекстуализированная картина.
**Беру** — идею учёта контекста (против кого именно ты теряешь).

---

**DriveHUD**
Дешёвый трекер для микро- и лоу-стейкс. «Bumper Stickers» — иконки поверх HUD вместо голых цифр. «Tilt Meter» — алгоритм определения тилта оппонента.
Источник: https://drivehud.com/
Ключевое: визуальные иконки вместо цифр + $24/год — разумная ценовая модель для микролимитников.
**Беру** — принцип «иконки вместо цифр» и модель дешёвой подписки.

---

**Poker Copilot 8**
Трекер для macOS. Версия 8 добавила AI Hand Analysis прямо в Hand Replayer: каждый ход оценивается (Great / Mediocre / Poor), даётся стратегический разбор. Каждый анализ стоит 5 кредитов SharkScope.
Источник: https://pokercopilot.com/ и https://pokercopilot.com/userguide/8/en/topic/a-i-hand-history-analysis
Ключевое: постшотный AI-разбор прямо в интерфейсе реплеера — ближайший аналог по сути.
**Беру** — как ориентир по UX разбора. Слабость: нет диалога «объясни своё решение», нет профиля игрока.

---

**PokerCraft (встроено в GGPoker)**
Бесплатный встроенный инструмент GGPoker: позиционная статистика, матрица стартовых рук, EV vs результаты.
Источник: https://ggpoker.com/blog/pokercraft-analyze-your-ggpoker-statistics/
Ключевое: у целевой аудитории (GGPoker-игроки) уже есть это — бесплатно и без настройки.
**Не подходит** как конкурент продукту, но важен как базовый ориентир пользователя — нужно предложить что-то существенно лучше.

### AI-коучи и специализированные инструменты

**GTO Wizard — HH Analyzer 2.0 + GTO Reports**
Ведущая GTO-платформа. HH Analyzer 2.0 (декабрь 2024): фильтрация по позиции и улице, автовыявление паттернов и утечек. GTO Reports (март 2025): сравнение твоей статистики с GTO-частотами, цветная визуализация отклонений.
Источник: https://gtowizard.com/ / https://blog.gtowizard.com/hand-history-analyzer-is-here-patch-notes/
Ключевое: «профиль игрока» на уровне GTO-отклонений — концептуально близко к задуманному, но сложно и дорого ($49+/мес).
**Беру** — идею визуализации отклонений от эталона. Сам продукт не подходит для микролимитника-любителя.

---

**PokerSnowie**
AI-тренер на нейросетях. «Live Advice»: импортируешь раздачи, AI сразу указывает ошибки. «Scenario»: создаёшь спот, AI анализирует и объясняет. Интерфейс рассчитан на все уровни.
Источник: https://www.pokersnowie.com/
Ключевое: постшотный анализ реальных рук с объяснениями — духовно близок к продукту.
**Беру** — как второй ближайший аналог. Слабость: нет интерактивного «объясни своё решение», нет профиля типа игрока, нет персонализации.

---

**PokerGPT**
Веб-приложение: вставляешь текст раздачи, получаешь AI-разбор с GTO и эксплойтативными рекомендациями на естественном языке.
Источник: https://www.pokergpt.app/
Ключевое: простота входа — скопировал/вставил/получил. Ориентировано на рекреационных игроков.
**Беру** — как ориентир по UX «нулевого порога». Прямой конкурент без: автозагрузки файлов, профиля игрока, диалога «объясни своё решение», персонализации.

---

**EVIE (прото-продукт, Medium)**
Описан в статье: AI-коуч для турниров с RAG + кастомная математика EV + разговорный интерфейс. Ключевая идея: математика считается отдельным движком, LLM используется только для объяснений.
Источник: https://statistician-in-stilettos.medium.com/building-an-ai-poker-coaching-app-af9a98d4d16b
Ключевое: архитектурный паттерн — не доверяй LLM математику, используй их только для разговора.
**Беру** — архитектурный принцип: отдельный слой для расчётов, LLM только для объяснений.

---

**Poker AI-lyzer**
iOS/Android приложение для рекреационных игроков — разбор раздач после сессии с объяснением ошибок. Маскот Chips ведёт игрока по разбору.
Источник: https://www.producthunt.com/products/poker-ai-lyzer-2
Ключевое: маскот-ведущий снижает тревожность новичка.
**Беру** — как подтверждение, что ниша рекреационных игроков валидна. Слабость: только мобайл, нет загрузки HH-файлов, нет профиля.

---

**GrindStack**
Мобильное приложение для лайв-покеристов: трекинг + AI-разбор через LLM + MCP tool calling для расчёта pot odds в реальном времени.
Источник: https://grindstack.app/
Ключевое: LLM + tool calling для конкретных расчётов — паттерн избежания галлюцинаций в математике.
**Беру** — технический паттерн: tool calling для математики, LLM для нарратива.

---

**Pairrd (от Raise Your Edge / Bencb)**
Интерактивная тренировочная платформа: ежедневные квизы на 500 000+ постфлоп-вопросов, видеоразборы от профи, «Play & Explain quizzes», геймификация (лидерборды, соревнования).
Источник: https://pairrd.com/
Ключевое: механика «ответь на вопрос и объясни» + ежедневная привычка + геймификация.
**Беру** — механику ежедневных квизов и геймификацию. Слабость: дорого ($499/год), не на своих раздачах, нет персонализации.

### Открытые репозитории

**asashakira/ggparser** — парсер hand history GGPoker на Python.
https://github.com/asashakira/ggparser
**Беру** — готовый парсер под GGPoker формат, можно взять за основу.

---

**LayorX/GGPoker-Hand-Analyzer** — веб-инструмент: 40+ статистик (VPIP, PFR, 3-Bet, C-Bet), charts, «персонализированные рекомендации». Всё работает локально в браузере (vanilla JS + Chart.js + Vite).
https://github.com/LayorX/GGPoker-Hand-Analyzer
**Беру** — прямой open-source прецедент: подход к статистикам и рекомендациям из GGPoker-файлов.

---

**xeema-nobody/poker-tracker** — веб-приложение: загружаешь файл из GGPoker PokerCraft, автопарсинг, сохранение в базу.
https://github.com/xeema-nobody/poker-tracker
**Беру** — готовый UX-паттерн загрузки и парсинга GGPoker файлов.

---

**willbraun/ai-poker-coach** — Full-stack: Next.js + ASP.NET + GPT-4o Mini через OpenAI Threads API. Кастомные документы по покерной стратегии как knowledge base. Социальная лента анализов.
https://github.com/willbraun/ai-poker-coach
**Беру** — техническая архитектура (Threads API + RAG с покерной литературой) + идея социальной ленты разборов.

---

**poker-apprentice/hand-history-parser + hand-history-analyzer** — npm-пакеты на TypeScript: парсер HH (Bodog/Bovada/Ignition) + анализатор статистик.
https://github.com/poker-apprentice/hand-history-parser
**Беру** — архитектурный паттерн: отдельный пакет-парсер → отдельный пакет-анализатор.

---

**pokerregion/poker** — Python-фреймворк: парсит PokerStars, Full Tilt, PKR. Хорошо задокументированный API.
https://github.com/pokerregion/poker
**Беру** — для парсинга PokerStars формата.

---

**thlorenz/hhp** — Node.js парсер: PokerStars, Ignition, PartyPoker, 888poker — кэш-игры и турниры.
https://github.com/thlorenz/hhp
**Беру** — если нужна поддержка нескольких румов сразу.

### GTO-солверы

**PioSolver / GTO+**
Настольные GTO-солверы, стандарт для профи. Точные решения, дорогие ($249–$549), требуют мощного железа и глубоких знаний.
https://piosolver.com/
**Не подходит** — слишком сложно и дорого для микролимитника. Но знание «как должно быть» можно зашить в промпт.

---

**Deepsolver**
Облачный солвер — не нужно мощное железо. GTO Trainer с двумя режимами: educational и challenge. 7-дневный бесплатный trial.
https://deepsolver.com/
**Беру** — идея «challenge mode» для тренировочной петли + облачность снижает барьер входа.

---

**Simple GTO Trainer**
Тренировка против AI-оппонента с мгновенным фидбэком: играешь руки → сразу видишь отклонение от GTO. Таблицы и графики прогресса.
https://simplepoker.com/
**Беру** — принцип «immediate feedback loop» во время тренировки.

### Ручные обходы

**Форумы (2+2, PokerStrategy, CardsChat)**
Копируют текст раздачи в форум, ждут разбора от сообщества часами или днями.
Ключевое: люди уже хотят именно этот сценарий — объяснить своё решение и получить фидбэк. Продукт даёт то же самое мгновенно.
**Беру** — как подтверждение основного use case.

---

**Discord-серверы с ручными разборами** (Upswing, RaiseYourEdge, LudusX)
Каналы для постинга раздач и получения разбора от других игроков или коучей.
https://upswingpoker.com/discord/
Ключевое: social accountability — люди постят раздачи ради давления и мотивации.
**Беру** — идея community-фичи (делиться разборами, соревноваться) как будущее расширение.

---

**Платные коучи** (BlackRain79, Smart Poker Study, Raise Your Edge)
Один на один: разбор сессий, персональный план, фидбэк на конкретные ситуации. $50–200/час.
Ключевое: это именно тот опыт, который нужно воспроизвести дёшево через AI — персонализация и диалог.
**Беру** — как шаблон желаемого результата.

---

**Excel/Google Sheets трекинг**
Часть аудитории записывает сессии вручную, считает winrate, делает заметки к раздачам.
Ключевое: эта часть аудитории вообще без инструментов — максимально низкий входной барьер.
**Беру** — понимание, что для части пользователей любой файл + понятный интерфейс уже будет шагом вперёд.

## Итог: что никто не делает

Ни один инструмент не реализует следующий сценарий целиком:

> Загрузил файл → система строит твой профиль (агрессивный / пассивный / рег) → выбирает твои конкретные проблемные раздачи → спрашивает «почему ты так сделал?» → сравнивает объяснение с тем, что реально произошло → даёт персонализированный разбор на твоём материале.

**Прямые аналоги** (загружаешь свои раздачи → получаешь AI-разбор):
- **PokerSnowie** — импортируешь реальные руки, AI сразу указывает ошибки и объясняет. Нет диалога «объясни решение» и профиля игрока.
- **GTO Wizard HH Analyzer 2.0** — загружаешь HH-файл, строится профиль отклонений от GTO, выявляются паттерны. Концептуально близко, но дорого ($49+/мес) и рассчитано на продвинутых.
- **Poker Copilot 8** — AI-разбор прямо в реплеере по твоим раздачам. Нет диалога и профиля.

**Функциональные аналоги** (AI-разбор раздачи через LLM, без файловой загрузки):
- **PokerGPT** — вставляешь текст раздачи, получаешь разбор. Нет загрузки файлов, нет профиля, нет истории.
- **willbraun/ai-poker-coach** (GitHub) — Next.js + GPT-4o Mini + RAG с покерной литературой. Буквально называется «AI poker coach», но нет профиля и диалога «объясни решение».

**Тренировочная механика** (та же петля обучения, но не на своих раздачах):
- **Pairrd** — «Play & Explain» квизы, геймификация, 500 000+ вопросов. Нет персонализации под твой материал.
- **Simple GTO Trainer / Deepsolver** — тренируешься против AI с мгновенным фидбэком после каждого решения.
