# MVP

*Утверждено: июнь 2026*

---

## Случай

Продукт для внешнего рынка. Автор — первый пользователь в роли тестировщика: играет турниры ежедневно, знает боль изнутри. Первая версия строго под турниры (принцип #9).

---

## Одна фраза

> Игрок загружает HH-файл GGPoker после проигрышного турнира → видит карточку с десятью раздачами трёх уровней, где по критическим задаётся вопрос «почему ты так сделал?» → понимает свои систематические ошибки и видит сильные решения из той же сессии — за 20–30 минут вместо никогда.

**Вход-повод:** файл после проигрышного турнира на GGPoker.
**Выход-результат:** 10 раздач за сессию — 3 критические + 2 сильные + 5 средних. Одна сессия = один турнир = один HH-файл.
**Одна боль:** нет зеркала — после слива не знает, что именно стоило турнира, и без обратной связи повторит то же завтра.

---

## Один человек

Микролимитный турнирный игрок на GGPoker. Играет, старается, иногда проигрывает — и почти никогда не разбирает сессии: не знает как, коуч дорого, форум долго. Хороший тренер стоит $80+/час — это неподъёмно. Делает редкие ручные разборы, но до конца не уверен, что посчитал правильно.

## Ядро первой пользы

Только то, без чего первой пользы не будет:

- Загрузка одного HH-файла GGPoker (MTT-формат)
- Три метрики сессии: VPIP, количество рук, финальный результат (бай-ин ±)
- Формат отображения каждой метрики: три числа в одной строке — вчера / твой средний / оптимально. Пример: «VPIP: вчера 41% · твой средний 24% · оптимально 26%». В MVP «твой средний» — накапливается из загруженных сессий; пока сессий мало — используется общий ориентир для микролимитов с пометкой об этом
- Определение одного стилевого паттерна (лузовый / тайтовый / пассивный / агрессивный) по метрикам — числа считает парсер детерминированно
- Автоматический выбор ~10 раздач за сессию по трём уровням с адаптивным соотношением:
  - **Критические** — до 3 раздач за сессию, отбираются по сочетанию «больше всего фишек на кону» и «решение было самым сложным/спорным» — не просто самая большая потеря. Олл-ин с явным преимуществом, проигранный вариансу, — не критическая раздача: решение там было верным, разбирать нечего. Полный сократовский диалог: ~5 раундов наводящих вопросов, которые ведут игрока к тому, чтобы он сам увидел свою ошибку (или сам убедился, что решение было верным) → итог
  - **Сильные** — лучшие решения сессии, короткое подтверждение без принудительного диалога: «здесь ты всё сделал правильно, вот почему»
  - **Средние** — серая зона и крупные потери, не попавшие в топ-3 критических; решение приемлемо, но есть лучшая линия; лёгкий режим: показывает ситуацию + «можно было чуть иначе»; по желанию — полный разбор по нажатию
  - Соотношение определяет парсер по реальным данным сессии, не фиксировано:
    - Отличная сессия: ~1 критическая + ~5 сильных + ~4 средних
    - Обычная сессия: ~3 критических + ~2 сильных + ~5 средних
    - Провальная сессия: до 3 критических (лимит на полный диалог не растёт, даже если спорных раздач больше) + ~1 сильная + ~6 средних
  - Если сильных раздач нет совсем — продукт говорит об этом честно, не натягивает среднюю на «молодец»
- Чат для вопросов по любой разобранной руке

## Масштаб — есть в идее, не для первой реализации → [[vision]]

- **Первое расширение после MVP:** загрузка полной истории рук (10К–100К+ раздач) для построения точного личного baseline. Требует базы данных на сервере и хранения профиля между сессиями. До этого baseline накапливается из загруженных сессий или берётся из общих ориентиров для микролимитов
- Тиры подписки: базовый $12/мес (~10 адаптивных раздач, до 20 сессий) и продвинутый $30–40/мес (все раздачи сессии, полный диалог по любой, безлимит сессий) — апгрейд естественный, когда пользователь упирается в лимит
- Поддержка PokerStars, PPPoker
- Кэш-игры
- Подбор похожих рук из базы
- История сессий и тренды прогресса
- Геймификация: стрики, accuracy score, лидерборды
- Автоматический мониторинг папки
- Социальные функции (поделиться разбором, Discord-интеграция)
- Расширенный дашборд (30+ метрик, позиционный анализ, матрица стартовых рук)
- Интеграция GTO-солвера
- Кастомные квизы из паттернов слабостей
- Multi-room поддержка

### Зафиксированные идеи (2026-06-11) — после MVP, после первого старта

**Профиль игрового стиля («лик»).** Каждому подписчику по накопленным сессиям продукт формулирует не просто статистику, а описание его стиля/слабости как игрока (например: «нит-агрессор», «лузово-пассивный» и т.п.) — обновляется по мере загрузки новых сессий.

**Режим «Тренировка».** Игрок нажимает кнопку «Тренировка» — ему по очереди показывают раздачи из его реальной сыгранной истории, и он заново принимает решение по раздаче целиком (не по отдельному действию), как будто играет сейчас. После решения — обратная связь: правильно/неправильно по этой раздаче + что он сделал по факту в реальном турнире. Если решения разошлись — сократовский диалог: «почему сейчас решил так, а тогда поступил иначе?».

**Все виды покера и все румы.** MVP строго под MTT Холдем GGPoker (принцип #9 — [[mvp]]), но направление развития — поддержка всех форматов игры (кэш, MTT, SNG, спин-н-гоу и т.д.), всех разновидностей (Холдем, Омаха и др.) и всех возможных румов (PokerStars, PPPoker, 888poker и др.), не только GGPoker.

## Математика

**Задача:** «Разобрать вчерашний турнир»

В среднем 70 рук на сессию. Экономика технологий, сделавшая это возможным — [[why-now]]. Кто уже пробовал и почему не закрыл нишу — [[deep-research]].

### Без продукта (реальность)

| Вариант | Качество | Стоимость |
|---|---|---|
| Не разбирает (реальность ~95% случаев) | 0 | $0, ошибка повторится |
| Ручной разбор | Есть, но нет уверенности в правильности расчётов | Время + сомнение |
| Начинающий тренер | Среднее | $30/час |
| Хороший тренер | Высокое | $80+/час |

### С продуктом

- Время до первого результата: 30–60 секунд
- Стоимость токенов на сессию: ~$0.20 (до 3 полных сократовских диалогов по ~5 наводящих вопросов + короткий разбор остальных раздач, Claude Sonnet 4.6) — оценка предварительная, уточнить через `count_tokens` на реальном промпте
- При $12/месяц и 20 сессиях: расходы ~$4 на токены, маржа ~$7.6 (≈64%)

### Три оси ценности

**1. Частота обратной связи — главная ось**

| | Сессий с разбором в месяц |
|---|---|
| Сейчас | ~0–1 (очень редко) |
| С продуктом | 15–20 (каждый турнир) |

Переход от нуля к системе. Не «лучше чем коуч» — «первый раз разбираешь каждый турнир».

**2. Цена vs хороший тренер**

20 турниров в месяц × $40–60 за разбор каждого = $800–1200 эквивалент → против $12/месяц = **67–100x дешевле** при сопоставимом охвате.

**3. Доверие к числам**

Ручной разбор оставляет сомнение «а вдруг посчитал неправильно». Парсер считает детерминированно — числа точные. Это отдельная ценность, не производная от скорости.

### ROI-аргумент для пользователя

Если теряешь 1–2 бай-ина в месяц на одних и тех же ошибках, а один бай-ин на микролимитах $5–20 — $12/месяц окупается, если продукт закрывает хотя бы одну повторяющуюся утечку.
