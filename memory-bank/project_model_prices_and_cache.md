## 🇬🇧 ПРОМПТ НА АНГЛИЙСКОМ? (вопрос Артёма 17.07) — ЗАМЕРЕНО, НЕ ГАДАТЬ
Замер на живом API (тот же смысл, кусок Правила 1): **русский 3.40 знака/токен, английский 4.74** →
английский дешевле по токенам на **21%**. Наш фреймворк ~20k токенов → по-английски ≈15.4k.
⛔**НО в деньгах это ~5-7% себестоимости** (меньше цента с турнира): системный промпт КЭШИРУЕТСЯ
(×0.25), и 21% срезаются с уже удешевлённой части. Та же ловушка, что со «сжатием вдвое».
⚠️**РИСК ПЕРЕВЕШИВАЕТ:** тренер обязан говорить с игроком ПО-РУССКИ. Сейчас язык промпта = язык
ответа, модель не переключается. Английские инструкции → модель думает по-английски → латиница в
русском ответе, а это НАШ САМЫЙ ЧАСТЫЙ КЛАСС БРАКА (7 из 15 в аудите 16.07; у GLM — «PASSIVE»,
«manageable», «barrel»). Плюс перевод 56k знаков = дни работы, где каждый смысловой guard надо
перенести точно (язык-блок = БРОНЯ, не вода).
**Решение: НЕ сейчас.** Если проверять — дёшево: перевести ОДИН блок, A/B на фиксированных 50
раздачах, смотреть латиницу + выдуманные числа. После переезда на 3.1 и после починки фактов.
