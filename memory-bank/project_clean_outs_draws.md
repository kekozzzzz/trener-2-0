Движок дро Hero переписан: вычитает грязные ауты, считает бэкдоры, эквити — точным перебором колоды (заменило грубое правило 2/4). Файл `parser/draws.ts` (`readHeroDraw` + `drawEquity`), эвалюатор `handCategory` вынесен из made-hand.ts (единый источник). Грязный аут размечается ДЕТЕРМИНИРОВАННО по борду (спаренный борд → фулл-риск; стрит при 3+ одной масти → флеш-риск), НЕ по угадыванию руки соперника (Правило 1). Бэкдоры — двухкарточным перебором. Горизонт пот-оддсов: против обычного бета 1 карта (тёрн), против олл-ина 2. Подача — «сырое + чистое диапазоном» с причиной (решение Артёма).
