Диапазонный движок (2026-07-03, план plans/2026-07-03-диапазонный-движок.md): «точная математика на честных входах» — оба входа (диапазон и нарезку по улицам) называет ИГРОК на сетке 13×13, всю арифметику делает парсер. Родилось из обсуждения «что мешает точной математике»: эквити против угаданного диапазона — точность для витрины; ответ на «пришёл дурак, отметил весь стол» — не подстраиваться, а ловить на противоречии цифрами.

Что сделано (тесты 17+7, весь набор 643 зелёные, сборка ок):
- `parser/range-equity.ts` — эквити Hero против отмеченных комбо честным перебором (ривер/тёрн/флоп; префлоп сознательно НЕ считаем — перебор ~10⁸, приближения противоречат идее), вычет мёртвых карт, `cutBetween` (фолд-% + «доложенные» комбо). Эвалюатор один — made-hand.ts (`cardSetValue`/`compareValues`).
- `config/poker/hand-range.ts` — `expandToken` понимает «−»-интервалы, `parseRangeNotation` строго разбирает нотацию из ТЕКСТА ответа сетки (миграции БД нет — коды не хранятся, восстанавливаются из ответа).
- `infrastructure/queue/steps/range-facts.ts` — `buildRangeReads`: улица по метке {{table:N}}, сверка ширины с VPIP (только при ровно одном известном злодее), нарезка между двумя отметками; уходит в `rangeReads` запросов вопроса и вердикта.
- Промпт-блок `renderRangeReads` (config/prompts/hand-analysis.ts, ru+en) + строка про повторную сетку в системном промпте диалога.
