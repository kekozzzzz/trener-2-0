Запрос Артёма 2026-07-05: Клод сам проверяет тренера, не дожидаясь скриншотов. Сделан прогонщик `trener/__tests__/manual/coach-audit.test.ts` — **ЛОКАЛЬНЫЙ, вне git** (папка `__tests__/manual` в .gitignore, т.к. ссылается на Test/ и openrouter-key.txt в корне).

Как работает: берёт все HH-файлы из `Test/audit/` (любой рум, роутер parseHandHistory) → критические раздачи гонит через НАСТОЯЩИЙ боевой пайплайн (те же промпты hand-analysis/dialogue-question/verdict, те же валидаторы с cleanCoachText, модель deepseek/deepseek-v3.2 напрямую через openrouter.ai) → за игрока отвечает модель-симулятор (персона думающего любителя, до 4 раундов) → плюс пара STRONG/MEDIUM заметок на язык. Рядом с каждой раздачей «правда парсера»: код руки, борд, готовая рука, вердикт префлоп-чарта, число ридсов. Результат: `Test/audit/аудит-результат.md` — его читает Клод и разбирает ошибки как Артём по скриншотам.

Запуск: `cd trener && RUN_COACH_AUDIT=1 npx vitest run __tests__/manual/coach-audit.test.ts` (env: AUDIT_HANDS критических на файл, дефолт 5; AUDIT_NOTES заметок, дефолт 2). Стоимость копеечная (~$0.03 за раздачу с диалогом).

Ограничение честности: rangeReads (эквити против сетки) и priorSpots (память тренера) в прогоне не строятся — их считает прод по БД; ответы-диапазоны симулятор даёт словами (промпту это разрешено).
