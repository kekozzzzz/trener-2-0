Когда трачу реальные деньги на внешний платный API (видео-генерация, TTS и т.п.) несколькими
шагами подряд в рамках одной сессии — каждый раз перед новой тратой явно называть **накопленную
сумму за всю сессию**, не только цену конкретного следующего шага. Особенно важно перед батчем
из нескольких генераций подряд (например, серия клипов) — там трата накапливается быстро и
незаметно, если её не суммировать вслух.

**Why:** 2026-07-30, воронка Instagram Reels ([[project_marketing]]) — сгенерировал подряд
несколько версий видео-сцены (3 правки) и потом запустил батч из 3-4 клипов стола, каждый раз
называя только цену этого конкретного шага (~$0,27-0,32). Артём остановил процесс на середине:
«потратил больше полутора долларов» — реальный итог по сессии оказался ≈$1,83, и для него это
стало неожиданностью, хотя каждый отдельный шаг был назван и вроде бы небольшой.

**How to apply:**
- Перед любой новой платной генерацией (видео, TTS, изображения через платные модели) — одной
  строкой: «уже потрачено $X в этой сессии, следующий шаг +$Y».
- Особенно строго — перед запуском батча/цикла из нескольких генераций подряд в фоне: там нет
  естественной паузы для отчёта между шагами, значит нужно назвать итоговую ожидаемую сумму
  ДО старта батча, а не постфактум.
- Отдельный технический нюанс оттуда же: остановка локального скрипта/процесса НЕ отменяет уже
  запущенную платную генерацию на стороне внешнего API — задача продолжает выполняться и
  оплачивается сервером независимо от того, жив ли ещё локальный клиент. Проверять и, если
  задача всё равно завершилась и оплачена, забирать результат бесплатным GET по id, а не
  выбрасывать уже оплаченное.
