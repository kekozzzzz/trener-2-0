**Починка автодеплоя 2026-07-16 — docs-only фильтр не работал для русских имён (баг с рождения):** git по умолчанию экранирует пути с кириллицей и заворачивает в кавычки (`"retrospectives/2026-07-16_\321\201…md"`). Фильтр «доки не пересобирают прод» проверяет `^retrospectives/` и `\.md$` — а строка начинается с кавычки и кавычкой заканчивается, поэтому НЕ узнаётся и считается кодом. Итог: **каждая ретроспектива и каждый план всё это время гнали полную пересборку с `pm2 restart`**, а рестарт во время разбора вешает диалог пользователя на 10 минут ([[feedback_no_deploy_during_analysis]]). Лечится `git -c core.quotepath=false` в ОБЕИХ командах списка файлов (`ls-files` и `diff --name-only`). Проверено на живых коммитах: документарный → build=0, код → build=1. Бэкап: `/usr/local/bin/autodeploy.sh.bak-before-quotepath`.

Бэкап: `autodeploy.sh.bak-before-ops`. ⚠️ Правки автодеплоя живут ТОЛЬКО на релее (`/usr/local/bin/`), в git их нет — при переезде/пересоздании релея переносить руками.
