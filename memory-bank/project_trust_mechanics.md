**17.08.2026:** серия правок против скепсиса «вайб-кодинг, слепили на коленке, срубят бабки». Триггер — реальная переписка Артёма с Ярославом (тот увидел продукт и стал жёстко пресс-тестить: «спрос есть?», «готов, что скажут не отличный?»).

Живое: `/about` (личная история основателя, без слова «один» в лоб — считывается само через первое лицо, а не декларацию), `/example` (настоящий полный разбор одной раздачи без регистрации, с раскрывающимся исходным HH-файлом), `/uptime` (публичный статус, зеркалит `/api/health`), `/changelog` (только конкретные видимые изменения продукта, НИКОГДА «улучшили промпт»/«стал лучше работать» без объяснения — правило закреплено в `CLAUDE.md`, раз в 1-2 недели, черновик показывать Артёму на правку), формулы расчёта VPIP/пот-оддсов/эквити на `/hand-review`, публичная гарантия на точность чисел парсера (НЕ суждений ИИ-тренера) — раздел 5 политики возврата (`/legal`) + подсказка на `/support`.

**Осознанно НЕ делаем** (после разбора трастовых паттернов успешных сайтов — Baremetrics Open Startup, 37signals policies-в-git, Linear Trust Center, GTO Wizard/Upswing/Run It Once):
- Общая money-back-гарантия — решение Артёма: бесплатная проба и так честно фильтрует, кому продукт подходит.
- Публичный roadmap/бэклог фич (в духе Linear) — `plans/` пишется для внутренней работы, включая честные записи о своих ошибках; публичная версия требует отдельной курируемой ветки, цена выше пользы для покерной аудитории.
- Привязка личного покерного бэкграунда к внешним рейтингам (как Hendon Mob у live-тренеров Upswing/RIO) — для онлайн-микролимитных MTT такой публичной базы физически нет, переносить некуда.
- Живой счётчик разборов (Baremetrics-стиль) — уже решено в `design-system.md`: показывать только когда цифра станет весомой. Сейчас пользователей почти нет, маленькая честная цифра сейчас усилила бы именно тот страх («никто этим не пользуется»), который озвучил Ярослав, а не сняла его.

Артём сам поднял вопрос.
