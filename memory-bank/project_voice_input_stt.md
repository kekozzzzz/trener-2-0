Боевой движок голосового ввода (микрофон в поле ответа) собран 2026-06-27. Заменяет прежний макет на Web Speech API. Заменил и прежнее решение «Yandex SpeechKit» из первоначального плана (отменено реальностью).

**Архитектура:** браузер пишет звук → перекодирует в WAV 16кГц **на клиенте** (`lib/encode-wav.ts`, Web Audio — движок принимает только wav/mp3, а MediaRecorder отдаёт webm) → POST на `/api/stt` (вход по сессии + часовая квота `consumeQuota` + лимит размера) → адаптер `infrastructure/adapters/stt/openrouter.ts` (OpenAI-формат) → **КЗ-релей `https://92.60.75.87/openrouter`** → OpenRouter → модель. Прямой выход с Yandex Cloud к OpenRouter/Alibaba флаки (рвётся пачками, 7/20), поэтому релей обязателен (тот же, что у Claude/DeepSeek [[project_deepseek_migration]]).

**Движок: `mistralai/voxtral-small-24b-2507`** (через OpenRouter). Выбран смоук-тестом из аудио-моделей OpenRouter — лучший по русскому покерному жаргону (взял олл-ин, оверпара, ICM, SPR, сквиз, пот-оддсы) и самый дешёвый по входу. **Qwen3-ASR на OpenRouter НЕТ** (нет в списке моделей аккаунта), хотя изначально целились в неё. DashScope-адаптер `qwen.ts` оставлен запасным.

**Качество:** живую речь и числа берёт отлично; узкий жаргон добивается двумя костылями — словарь-контекст system-сообщением (`config/poker-asr-fixups.ts` → `POKER_ASR_CONTEXT`) + детерминированные авто-правки ПОСЛЕ распознавания (`lib/apply-poker-fixups.ts`: АЛЫН→олл-ин, по дотс→пот-оддсы и т.п.). Плюс игрок видит текст и правит. Выбор движка в `index.ts`: OpenRouter→DashScope→фейк по ключу. 16 тестов зелёные, tsc чист.

**ЗАДЕПЛОЕНО И LIVE 2026-06-28** (коммит 03a3d06). Проверено живым тестом: релей→Voxtral отвечает HTTP 200, валидный chat.completion. Микрофон в проде работает. Никаких ОТДЕЛЬНЫХ STT-ключей ставить не пришлось — STT включается по тому же `OPENROUTER_API_KEY`, что и DeepSeek-разбор (выбор адаптера по наличию ключа), а секрет релея у STT падает на `ANTHROPIC_PROXY_SECRET` (правка 03a3d06).

⚠️ Был баг, всплывший при включении: STT и LLM-разбор делят одну env `OPENROUTER_BASE_URL`, но ждали разный формат — STT давал двойной `/api/v1` и микрофон отвечал ошибкой. Починено в 03a3d06: единая схема — база ВКЛЮЧАЕТ `/api/v1` (`OPENROUTER_BASE_URL=https://92.60.75.87/openrouter/api/v1`), адаптер дописывает `/chat/completions`. Security-review STT прошёл ранее (эндпоинт по сессии, валидирует вход, без SSRF). Словарь правок (`POKER_ASR_FIXUPS`) тюнился на сравнении движков — стоит дотюнить под ошибки именно Voxtral по живым записям (напр. «бла-бла» слышит как «бля-бля» — не правил по просьбе Артёма). План `plans/2026-06-25-голосовой-ввод-ответа.md`.

**Скорость (2026-06-28, коммит 8acaa4f):** было ~6.4с на 7с речи. Замер [stt-timing] показал: модель Voxtral ~2-4с (пол, не трогаем — она же и точнее всех: Qwen3-ASR/voxtral-mini через наш чат-протокол дают 500, Gemini Flash быстр но врёт), а ~2.5с уходило на загрузку тяжёлого несжатого WAV (218КБ) по медленному каналу через релей. Решение: клиент шлёт СЫРУЮ сжатую запись (webm/opus, битрейт 32кбит/с → ~25КБ), а в wav её перекодирует СЕРВЕР через **ffmpeg** (`lib/transcode-audio.ts`, конвертация ~70мс). Клиентский `encode-wav.ts` удалён. ⚠️ **ffmpeg теперь обязательная прод-зависимость** (поставлен `apt install ffmpeg` на VM). Итог: 222КБ→25КБ загрузки, ~6.4с→~2.5-3с. Плюс живая звуковая дорожка при записи (canvas+AnalyserNode, как у ChatGPT). Серверный лог [stt-timing] оставлен для контроля.

**2026-07-05 (запушено 42cdaa4, автодеплой):** новый режим отказа Voxtral — на короткой/неразборчивой фразе («выкидывать надо») возвращает ЭХОМ сам словарь-подсказку `POKER_ASR_CONTEXT`, и весь список терминов вставлялся в поле как «речь игрока». В `app/api/stt/route.ts` добавлен `looksLikeContextEcho` (текст — дословный кусок подсказки, либо ≥10 словарных терминов разом) → `TRANSCRIBE_FAILED`, поле остаётся чистым, у кнопки красная ошибка — тем же путём, что отказы/кавычки/преамбулы.

**Релейная находка (важно для инфры):** активный vhost на КЗ-релее — `/etc/nginx/sites-enabled/anthropic-relay` (грузится первым; рядом дубли .bak — не трогать). Секрет проверяется как `if ($http_x_proxy_secret = "...") set $deny 0`. Я добавил туда `location /openrouter/`. [[project_deploy_status]]
