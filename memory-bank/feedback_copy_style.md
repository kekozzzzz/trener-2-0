Артём правит маркетинговые тексты (посты в Telegram-канал и т.п.) под живой человеческий стиль, без следов генерации.

**Why:** по тексту не должно быть видно, что писал ИИ — иначе теряется доверие аудитории.

**How to apply:**
- Только короткие тире «-», НИКОГДА длинные «—» (главная палевная метка).
- Слитные живые абзацы, не рубить каждое предложение в отдельную строку; обычно 2-3 куска: завязка → разбор/цифры → призыв.
- Без «Стоп.», без значков «≈», без списков через тире, без литературной параллельности («не X, а Y»).
- Без жаргона «бай-ины» в публичных текстах — денежный итог по-человечески («за месяц складывается в заметный минус»).
- Покерный язык естественный: «доска спарилась» (не «парится»).
- Заход понятен новичку: узнаваемая ситуация, а не загадочные ярлыки вроде «Слив-сцена #1».
