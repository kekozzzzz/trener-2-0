Артём правит маркетинговые тексты (посты в Telegram-канал и т.п.) под живой человеческий стиль, без следов генерации.

**Why:** по тексту не должно быть видно, что писал ИИ — иначе теряется доверие аудитории.

**How to apply:**
- Только короткие тире «-», НИКОГДА длинные «—» (главная палевная метка).
- Слитные живые абзацы, не рубить каждое предложение в отдельную строку; обычно 2-3 куска: завязка → разбор/цифры → призыв.
- Без «Стоп.», без значков «≈», без списков через тире, без литературной параллельности («не X, а Y»).
- Без жаргона «бай-ины» в публичных текстах — денежный итог по-человечески («за месяц складывается в заметный минус»).
- Покерный язык естественный: «доска спарилась» (не «парится»).
- Заход понятен новичку: узнаваемая ситуация, а не загадочные ярлыки вроде «Слив-сцена #1».
- «Сливаешь» / «слив» — грубое, принижающее слово для вывесок и общего копирайта (тэглайн бренда, заголовки лендинга, УТП). 2026-08-14 убрано из Telegram-имени («Whygrid — почему ты сливаешь» → «Whygrid — покерный тренер») и из finalSubtitle лендинга («где сливаешь фишки» → «где теряешь фишки»). Слово остаётся уместным точечно — внутри разбора конкретной откровенно провальной раздачи, где мягче сказать нельзя («по факту сливаешь бабки в никуда»), а не в общих вывесках.
- **«Парсер» → «алгоритм»** (2026-08-15, решение Артёма): программистский термин непонятен обычному игроку. Заменено во всех ПУБЛИЧНЫХ текстах (сайт ru/en, bio каналов, посты) — переписывать по смыслу предложения, не механической заменой слова (иногда ломает грамматику, напр. «парсер - код» → просто «точный алгоритм», без лишней аппозиции). НЕ трогать: промпты ИИ (`config/prompts/*.ts`), код-комментарии, `llms.txt`/`llms-full.txt` (читают ИИ-краулеры, не люди) — там слово уместно и менять его отдельное решение с разрешением (правка промптов в проде).
