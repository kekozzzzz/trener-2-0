## КАК ЗАЙТИ НА VM (рабочий способ)
КЗ-релей (92.60.75.87, мой ключ там root) как jump к прямому IP (КЗ→РФ маршрут рабочий). Ключ в `/tmp/vmkey` (кириллица в $HOME ломает ProxyCommand); host key меняется после ребута → отключить проверку:
```
cp ~/.ssh/id_ed25519 /tmp/vmkey; chmod 600 /tmp/vmkey
PJ='ssh -i /tmp/vmkey -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -W %h:%p root@92.60.75.87'
ssh -i /tmp/vmkey -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o ProxyCommand="$PJ" trener-vm@81.26.186.177
```
На релей напрямую: `ssh -i /tmp/vmkey -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null root@92.60.75.87`. [[project_llm_connectivity_block]]
