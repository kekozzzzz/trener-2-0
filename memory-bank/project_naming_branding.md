«Тренер 2.0» — старое рабочее название. **Имя финализировано 2026-06-19: Whygrid** (Артём подтвердил — не рабочее, а финальное). Брендом будет международный, НЕ российский домен (Артём хочет, чтобы открывался у всех сразу) — покупаем на Cloudflare (там же туннель, портативно при переезде за рубеж 2027). Зону выбирает по живому поиску Cloudflare: приоритет `.com` → иначе `.app`/`.io`; НЕ брать `.gg`/`.poker` (платформозависимо). Веб-поиск 2026-06-19: известного бренда «Whygrid» нет, конфликта не видно. Домен нужен СЕЙЧАС — ЮKassa при подключении требует постоянную ссылку на сайт + оферту/политику (временный Cloudflare-туннель не годится). Цвета вордмарка: «WHY» — лайм #D4FF33, «GRID» — белый #F5F5F5.

**Логотип финализирован 2026-06-23: знак «grid»** — квадрат 2×2, три ячейки в белой обводке + правая верхняя лаймовая (знак=название бренда). Концепт B (развилка-Y) ОТМЕНЁН Артёмом после нескольких раундов скетчей. Знак живёт внутри `<Wordmark/>` (лок-ап знак+WHYGRID), favicon — `trener/app/icon.svg` (тот же знак на тёмной плитке #0E0E0E). Все варианты — `design/logo-favicon-preview.html`, правило — design-system.md §7 запись 2026-06-23.

**Why:** старое имя не несёт смысловой нагрузки бренда; новое имя и логотип подобраны с учётом [[feedback_naming_style]] (без транслита кириллицы, без GG/GGPoker — бренд платформонезависим).

**How to apply:** знак + вордмарк + favicon ЗАДЕПЛОЕНЫ и LIVE на проде (сверено 2026-06-29; icon.png 200, шапка с лого). Осталось из ребрендинга: журнал решений в architecture/00-правила-проекта.md; og-картинка (для шеринга) пока не сделана. Все правки лого идут ТОЛЬКО через `trener/components/ui/wordmark.tsx` (знак) и `trener/app/icon.svg` (favicon). См. [[project_seo_metadata]].
