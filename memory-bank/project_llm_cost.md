**ПЕРЕСЧЁТ 2026-07-01 (актуально). Живой провайдер — DeepSeek v3.2 через OpenRouter** (`LLM_PROVIDER=openrouter`). Ставки config/llm-pricing.ts: $0.27/M вход, $1.1/M выход, $0.027/M чтение из кэша. Себестоимость турнира на DeepSeek: **~$0.03–0.09** (от «до» до). Разбивка: ~$0.02 авто (13 разборов раздач selectHandsForCard, коридор 10–20 + обзор турнира + характеристика игрока), +~$0.01 если игрок проходит сократовский диалог по ~3 критич. рукам. Пессимист (плотнее токенизация 2.0 симв/ток И кэш DeepSeek не попал между руками) — до ~$0.09.

**⚠️ Старая цифра $0.26–0.90 — это Claude Sonnet 4.6, НЕ живой провайдер.** Тем же расчётом подтверждено: при откате флагом на Sonnet ($3/M вход, $15/M выход) турнир снова ~$0.26–1.00. DeepSeek дешевле ~11×. См. [[project_deepseek_migration]].

Главный вес цены — общий системный промпт COACH_FRAMEWORK (config/prompts/hand-analysis.ts, ~16 680 символов ≈ ~6–7k токенов), уходит на КАЖДЫЙ вызов, но одинаков → попадает в авто-кэш DeepSeek за 0.027 (10× дешевле входа). Кэш — единственный рычаг, который заметно поднимет счёт, если перестанет попадать. Добавленное недавно (профиль оппонентов, чарты) цену почти не сдвинуло — оно в пользовательском запросе, не в системном.

**Вызовы на турнир:** автоматически на загрузку — разборы раздач карточки (selectHandsForCard, CARD_MIN_TOTAL=10, CARD_MAX_TOTAL=20, CRITICAL берём все) + 1 обзор турнира + 1 характеристика игрока. Диалог (вопрос/вердикт/чат) — ПО ТРЕБОВАНИЮ, только если игрок вовлекается. Первый вопрос по CRITICAL приходит бесплатно внутри разбора раздачи.

**Кэширование промптов ВКЛЮЧЕНО 2026-06-21** (anthropic.ts: `cache_control: ephemeral` на системном блоке). На загрузке (10 разборов подряд, один system, в пределах 5-мин TTL) — минус ~треть входа. На медленном интерактивном диалоге — нейтрально (TTL истекает между раундами). На ответы модели влияния НЕТ. Через релей КЗ работает.

Оговорка: токены — обоснованная оценка (русский ~2.5 симв/токен), не лабораторный замер; точно — взять реальные суммы из таблицы `LlmUsage` (пишется по факту из usage провайдера). Порядок верен.
