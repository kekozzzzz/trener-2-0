Собран по прямой просьбе Артёма («состряпай новый рилз, с учётом всех скиллов, клипы не
повторяй, музыку/звуки — которых не было, тему придумай»), уточнение — тема рекламная, про
продукт, как в последних заходах (см. [[project_ad_reel_pivot]]).

**Тема — новый угол, не пересекается ни с одним из 11 прошлых роликов** (проверено по
`clip-usage-history.json` + текстам всех `generated/reel-*.txt`): тренер сделан специально под
МИКРОЛИМИТНЫЕ турнирные бай-ины на GGPoker, а не под хайроллеров/финалки WSOP, про которые
обычно курсы и коучи. Разобранные ранее темы: сократовский вопрос, свои раздачи (не чужие
примеры), не RTA (легально), парсер считает числа (не чат-бот), цена коуча, якорение, вес
решения (не результат), повторяющийся лик. Отклонённые варианты для этого захода: профиль
соперника (продукт explicitно НЕ показывает это игроку, см. [[project_opponent_profiling]] —
рекламировать нельзя, неточно); память споты/«тренер помнит тебя» (уже фактически покрыто
reel-repeated-leak).

**Сценарий** (`generated/reel-your-stakes-narration.txt`, озвучка `reel-your-stakes-voice.wav`,
28.72с, TTS тот же OpenRouter Gemini Charon): «Курс — про хайроллеров. Коуч — про финалки WSOP,
про лимиты, которых у тебя ещё нет. А ты гриндишь баи-ины на пару долларов на GGPoker — свои
настоящие турниры. Тренер разбирает именно это: твой стек, твой бай-ин, твою реальную раздачу.
Не абстрактный пример из учебника. И, как всегда, сначала спрашивает — почему ты так сыграл.
Первый разбор — бесплатно. Загрузи турнир и проверь.» CTA — классический вариант («загрузи
турнир»), не «напиши в комментариях» (было в anchoring) и не «перейди по ссылке» (было в
decision-weight) — ротация по [[feedback_telegram_link_frequency]]-принципу (не один и тот же
CTA подряд).

**Производство — полный Remotion-конвейер, как decision-weight** (см.
[[project_remotion_motion_graphics_skill]]), композиция `YourStakes` в
`remotion-reels/src/scenes/YourStakes.tsx`:
- Транскрипция локальным whisper.cpp (`transcribe-local.mjs`, кэш модели с прошлой сессии
  переиспользован) → сырые суб-токены склеены в слова своим скриптом
  (`scripts/merge-words-your-stakes.mjs`, тот же приём «склеить без ведущего пробела»
  из [[project_remotion_motion_graphics_skill]] v4). ASR дважды ослышался («баи-ины»→«боины»,
  «бай-ин»→«боин», тот же класс ошибки, что «олл-ина»→«олына» в decision-weight) — текст
  фраз взят из ОРИГИНАЛЬНОГО сценария, не из распознанного, тайминги — из ASR.
- **12 клипов, 0 пересечений с любым из прошлых 11 роликов**: 85 (роял-флеш, растущий веер,
  живой сток 15с — используется с начала файла, там уже есть движение, проверено покадрово,
  не статичный кадр), 107 (дилер/виски/сигара), 93 (фишки у золотой пепельницы), 24
  (парень в худи, разочарованная реакция — известный баг лживой `format=duration`, использован
  `nb_frames/fps`=5.0417с), 11 (точный счёт фишек), 1 (aллин-шоув 40k), 15 (пуш ставки фишками),
  18 (палец барабанит от напряжения), 34 (рука тянется к картам), 26 (реакция-напряжение), 32
  (обе руки загребают выигрыш), 25 (улыбка облегчения). Визуальная драматургия: роскошь/WSOP
  (85→107→93) → слом на грindера в худи (24) → его реальная игра (11→1→15→18→34) →
  сигнатурный вопрос (26) → тёплый CTA (32→25).
- **Музыка — lord-knows.mp3, ВПЕРВЫЕ в использовании** (до этого только never-going-broke.mp3
  в decision-weight). Реальный BPM по волне — **64.6**, не каталожные 86.5 из
  `music-library.json` (детектор `librosa.beat.beat_track` поймал другую долю/сабдивижн —
  для целей пульсации это не важно, тайминги битов измерены НАПРЯМУЮ по этому же файлу).
  Трек имеет ~12с безбитового интро — первая половина ролика не пульсирует, это ожидаемо,
  не баг. Биты — `remotion-reels/src/beatTimesYourStakes.ts`, скрипт
  `scripts/detect_beats_your_stakes.py`.
- **Технический апгрейд, важно для будущих роликов**: `PhraseBeat.tsx` раньше жёстко
  импортировал `BEAT_TIMES` из decision-weight — при новой музыке пульсация шла бы в такт
  ЧУЖОМУ треку. Добавлен необязательный проп `beats?: number[]` (дефолт — старый
  `BEAT_TIMES`, decision-weight не тронут) — теперь КАЖДЫЙ новый ролик должен передавать
  СВОИ тайминги через этот проп, не полагаться на дефолт.
- SFX по содержанию клипа — переиспользованы калиброванные файлы из decision-weight
  (`sfx/real/card-flick-real.mp3`, `chip-clack-real-1..4.mp3`, те же volume-множители) на
  клипах 85/11/1/15, плюс `sfx/coins-clink.mp3` (не -real, обычный) на рейке выигрыша (32,
  волна ослаблена до 0.45 с учётом старого урока «монета ≠ фишка» — здесь это именно РЕЙК
  нескольких фишек, где металлический перезвон уместен, не單ичный вращающийся диск).
  Whoosh (настоящая запись) на всех 6 punch-фразах, один riser перед сигнатурным «почему ты
  так сыграл».
- Первый рендер (`generated/reel-your-stakes-remotion-v1.mp4`) прошёл БЕЗ ошибок сборки,
  визуально проверен по 8 контрольным кадрам (safe zone, split/center/impact-раскладки,
  водяной знак, кроссфейд между фразами) — выглядит на уровне decision-weight v9-v18 без
  повторения их 18 раундов правок, ПОТОМУ ЧТО переиспользованы уже откалиброванные компоненты
  (PhraseBeat/VideoRow/Layers) вместо разработки с нуля.

**v9 (2026-09-04) — курсор чинился три раза подряд, третий раз — правильно.** Настоящий баг:
длительность показа курсора была ДОЛЬШЕ времени жизни самой кнопки-фразы — курсор висел в
воздухе после её ухода, пока на экране уже шла другая фраза в другом месте. **Методологический
урок, важный на будущее**: два предыдущих раунда "проверки" (v7, v8) вырезали кроп кадра ВОКРУГ
СОБСТВЕННЫХ расчётных координат курсора — такая проверка ничего не может показать, кроме
подтверждения самой себя (кроп по построению покажет курсор "рядом" с тем, что я и так считал
центром). Полнокадровый скриншот без предвзятого кропа вскрыл реальное рассогласование сразу.
**Правило на будущее**: при проверке позиционирования элемента — либо кроп вокруг НЕЗАВИСИМО
известной точки (например, реального центра текстового блока, посчитанного отдельно), либо
полный кадр целиком; никогда не кропать вокруг собственного же предположения, которое проверяешь.
Заодно добавлено движение курсора из угла кадра к кнопке (Артём вспомнил похожий приём из
другого, не названного, референса) — компонент `PointerIcon.tsx` получил `travelFromX/Y`.

**v10 (2026-09-04) — "долларов" (8с) прыгает при смене клипа + пиксельные зелёные буквы.**
Разобрал покадрово (10fps): текст не телепортируется, просто растёт (`anim="grow"`) до 1.9x
РОВНО в момент смены видео-клипа (12 клипов поделены поровну, граница попадает на середину
именно этой фразы) — одновременный резкий рост текста и резкая смена фона читались как
