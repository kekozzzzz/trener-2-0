Артём не имеет опыта в программировании вообще. Технические сводки, таблицы с названиями файлов и аббревиатуры воспринимаются как "абракадабра". Нужно объяснять результат работы простым языком: что теперь умеет делать продукт, как это работает в жизни, без упоминания типов/функций/файлов если это не просил сам пользователь.

**Why:** явная просьба после первой технической сводки — "скажи по человечески, чтобы я понял"
**How to apply:** после каждой технической задачи давать объяснение уровня "объясни бабушке" — что изменилось для пользователя продукта, а не для разработчика.
