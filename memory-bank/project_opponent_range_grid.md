Две UI-фичи на странице разбора руки. Глоссарий + сетка диапазона.

**Глоссарий (сделан 2026-06-25, ЗАДЕПЛОЕН — см. статус внизу):** компонент `trener/components/metrics/glossary.tsx` (MetricsGlossary), кнопка «?» справа над метриками на странице турнира; расшифровывает VPIP/PFR/RFI/SPR/BB/AF/пот-оддсы простым языком.

**Сетка диапазона (сделана 2026-06-25, ЗАДЕПЛОЕНА — см. статус внизу).** Идея Артёма: НЕ «тренер вычисляет диапазон оппонента», а сетка как ФОРМА ОТВЕТА — когда тренер спрашивает «какой диапазон даёшь оппоненту», игрок кликает руки на сетке 13×13 вместо текста. Поэтому Правило 1 не затронуто (диапазон даёт человек), чарты 3-бета/защиты НЕ нужны. План plans/2026-06-25-сетка-диапазона-в-вопросе.md.

Реализация (3 фазы, tsc чист, 19 тестов): `config/poker/hand-grid.ts` (раскладка + комбо + компактная нотация `99+, AJs+`, % от 1326) и тесты; `components/poker/range-grid.tsx` (клик+протягивание, выделение лаймом, «N комбо · X%»); `range-answer-form.tsx` (выбор → текст-ответ «Думаю, у оппонента диапазон: … (N комбо, X% рук)» через тот же submitAnswerAction). Триггер контекстный: LLM в JSON возвращает `answerMode:"range"`, шаг очереди дописывает метку `{{range}}` в начало вопроса (config/dialogue.ts `applyRangeMarker`/`splitRangeMarker`), страница по метке показывает сетку. Метку ставит код, не модель → безопасно. Фейк-адаптер даёт диапазонный вопрос на CRITICAL (видно сетку в деве).
