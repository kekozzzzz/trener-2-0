Когда Артём описывает конкретный пример креатива (например, мини-сцену «чел сидит за компом,
проиграл раздачу, задаётся вопросом — как надо было сыграть») — это иллюстрация жанра/вкуса,
которую он хочет, а не фиксированный сценарий для копирования. Дальнейшую генерацию конкретных
сценариев, промтов для видео-мини-сцен, текстов для озвучки, хуков и подписей делаю сам — по уже
задокументированным правилам формата в `.business/marketing/instagram-reels-funnel.md` (§3
формат, §7 типы контента, §11 пайплайн генерации) — не прошу у него пример/уточнение на каждый
отдельный ролик.

**Why:** Артём прямо сказал 2026-07-28: «то, что я тебе сказал, вот эту мини-сцену, это просто
как пример... в дальнейшем ты сам и ты и остальные нейросети без моего участия всё это будут
делать» — явный сигнал на делегирование творческой генерации, не желание микроменеджить каждую
сцену/ролик.

**How to apply:**
- Производство контента для Reels (конкретные сценарии слив-сцен, промты для мини-сцен через
  видео-генерацию, текст для TTS-озвучки, подписи, хуки) — генерирую автономно по уже принятым
  правилам, без запроса примеров у Артёма на каждую единицу контента.
- Ограничение НЕ распространяется на то, что прямо требует его разрешения по правилам проекта
  (`CLAUDE.md` «Спроси разрешения»): трата реальных денег на генерацию (§11 — новый вид расхода),
  подключение нового платного сервиса (например Fish Audio, если Gemini TTS не устроит),
  фактическая публикация в эфир/прод. Разница простая: **творческое содержание — автономно,
  деньги/новые сервисы/публикация — с подтверждением**, как и раньше.
- См. [[project_marketing]] для истории решений по этой воронке.
