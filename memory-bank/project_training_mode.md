Решено 2026-06-20: после WPN-парсера делаем **режим «Тренировка»**. ИТОГОВАЯ версия v1 — **префлоп-тренажёр диапазонов на СЛУЧАЙНЫХ спотах** (не по реальным раздачам игрока): генерируется позиция + 2 карты Hero, игрок жмёт «открыть/сбросить», система **детерминированно сверяет с чартом** → верно/неверно + причина. БЕЗ LLM, БЕЗ диалога, **стоимость ≈ 0**. Самодостаточно — не зависит ни от парсера, ни от HH игрока.

Объём v1: **только префлоп, RFI** (банк не открыт, Hero первый заходит, «открыть или сбросить»). Постфлоп нельзя — нет солвера/оракула. Колл/3-бет на чужой рейз — позже (другие чарты).

Принято: тренировка — первой (до кэша); тарифы **средний + максимальный** (не базовый; стоимости теперь почти нет, гейт про ценность). **Гарантия правила №2:** вердикт только ПОСЛЕ фиксации решения игроком (решение = «ответ перед оценкой»). Глубокое сократовское «почему» остаётся в основном разборе.

**ГЛАВНЫЙ ОТКРЫТЫЙ ВОПРОС — откуда чарт** (источник правды): либо Артём даёт свой, либо я предлагаю стандартный микро-МТТ чарт ему на утверждение. Без утверждённого чарта грейдер не пишем. Чарт — в конфиге/БД (правило №3).

История решения (почему так): отбросили LLM-судью (вариант B/C) — посчитал по ценам Sonnet 4.6, «вся раздача с LLM» ~$1/сессия, на безлимитном тарифе не влезает + риск «уверенно неверного» вердикта. Отбросили «по своим раздачам» — в HH нет нужного, и сложнее. Случайная генерация + чарт = точно, дёшево, просто.
