2026-06-30 Артём закинул `Test/руки/` (118 реальных турнирных файлов, вне git, 5 папок по датам). Классификация по заголовку: **Winamax 74, PokerStars 25, 888poker 18, WPN 1**. Построено:

- **`trener/parser/winamax/`** — новый. Как WPN (без двоеточий, матч по именам из Seat), но свои улицы `*** ANTE/BLINDS ***`/`PRE-FLOP`/`SHOW DOWN`, склеенный борд `[a b c][d]` (борд берём из `Board:` в SUMMARY), посты без «the», Seat `(N)` + KO-суффикс `(N, X€ bounty)`, номер турнира — в имени стола `Table: 'Имя(<id>)#стол'`, `and is all-in`, `Uncalled bet (N) returned`.
- **`trener/parser/poker888/`** — новый. Суммы в `[скобках]`, `raises [Y]` = АБСОЛЮТ улицы (проверено по сумме банка), `calls/bets [X]` = инкремент, борд `** Dealing flop ** [ 8h, 3c, 4s ]`, карты через запятую, Seat `( 14,587 )`, `Seat N is the button` (без `#`). Олл-ин в тексте НЕ пишется → метим по вкладу==стек. «Uncalled bet» НЕ печатается → непокрытую ставку ВЫЧИСЛЯЕМ (на финальной улице top-коммиттеру возврат над второй по величине ставкой; на не-терминальных излишка нет). chipResult сверен вручную (+510, банк 765).
- **PokerStars (настоящий)** — берёт мой PS-парсер [[project_ipoker_chico_parsers]]. Фикс: Seat KO-суффикс `(2995 in chips, $15 bounty)` (`SEAT_LINE` → `in chips[^)]*\)`, без него места/действия не парсились, AF=0). Римский Level/3-частный бай-ин/двойная дата CUST+ET — не мешают.
- Роутер `parser/index.ts` + `sniffTournamentKey` для Winamax (id в имени стола) и 888 (`Tournament #id`); склейка многостольных проверена (888 #249461856: 4 стола→182 руки; наблюдаемая раздача без героя корректно отброшена).
