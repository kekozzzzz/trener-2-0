Артём принёс сторонний open-source проект **piratex** (`~/Desktop/piratex`) — self-hosted
платформа анализа коротких видео: по ссылке на Reel/Short скачивает видео → транскрибирует
(Whisper через Groq) → покадровый vision-анализ (GPT-4o) → генерирует сценарий и «стратегию»
(хук, теги, обложка) через Claude/GPT. Просьба была разобраться, что из этого взять в наш
маркетинг Reels для Тренера, не в сам продукт (это не покерный инструмент, а видео-аналитика).

**Развёртывать сам сервис не стали** — overkill под наш масштаб (FastAPI+Postgres+Redis+
обязательная Apify-подписка для скачивания видео, а на момент разбора реально опубликован
всего 1 ролик). Вместо этого вытащили конкретные текстовые приёмы из его промптов
(`strategist.py`, `summarizer.py`) и вписали в [[feedback_copy_style]] / `.business/marketing/copywriting.md`:

- **§4.1** — для Reels Тип 1 и карусели генерировать 3-4 варианта хука разными техниками
  (признание/сцена-в-моменте/недосказанность/цифра-удар/провокация) и оценивать по 3 критериям
  (внимание/попадание в боль/эмоция) вместо того, чтобы брать первый пришедший в голову вариант.
- **§5** — приём «рваный ритм» (burstiness): нарочно чередовать длину предложений
  (2-4 → 8-12 → 15-20 → снова 2-4 слова), а не только вычищать стоп-слова из старого списка.
- **§8 (новый раздел)** — чек-лист самопроверки текста из 5 пунктов перед сдачей («звучит как
  рассказ другу», есть конкретная цифра, разная длина предложений, нет стоп-слов, CTA конкретный).

**Отложено, не сделано:**
- Разовый структурный анализ 5-10 успешных Reels в покерной/беттинг-нише (хук/тайминг
  фаз/типы сцен по образцу piratex `scene_detector.py`/`vision_analyzer.py`). Не требует Apify:
  можно скачать видео вручную (Артём) и транскрибировать через уже одобренный маркетинговый
  OpenRouter-ключ моделью Voxtral — той же, что уже используется в STT продукта, см.
  [[project_voice_input_stt]] — вместо нового сервиса. Нужен шаг Артёма: прислать 5-10
  ссылок/файлов роликов конкурентов.
- Мониторинг трендов (формула X-factor/hot-score из `trend_monitor.py`: views/медиана автора,
  скорость набора, вовлечённость, time decay) — требует платную Apify-подписку под скрейпинг
  профилей. Это «новый платный сервис» — нужно отдельное разрешение Артёма по правилам проекта,
  и есть смысл ждать, пока не будет доказанной пользы от первых двух шагов.

**Why:** правило проекта — новый платный внешний сервис только с явным разрешением
(`CLAUDE.md` «Спроси разрешения, прежде чем»); дешёвые шаги (правки промпта) сделаны сразу,
дорогие (Apify, ручной сбор конкурентов) — с паузой на решение Артёма.

**How to apply:** при следующем возврате к теме анализа контента-конкурентов не пересматривать
piratex с нуля — читать эту память + `.business/marketing/copywriting.md` (актуальные правки уже
внутри). Если Артём принесёт ссылки конкурентов — использовать связку
ffmpeg (уже прод-зависимость) + Voxtral через маркетинговый OpenRouter-ключ, не заводить Groq/Apify.
