Артём планирует переезд за границу ориентировочно лето 2027 (±год, зависит от успеха продукта).

**Маршрут инфраструктуры:**

1. **Сейчас** — локальная разработка, PostgreSQL 17 на компьютере.
2. **Первый деплой (RU, 2026)** — Yandex Cloud: Managed PostgreSQL + Object Storage + Serverless Containers. Обязательно по 152-ФЗ пока в России с RU-аудиторией.
3. **После переезда (ориентир лето 2027)** — добавить международный деплой: Hetzner или Fly.io + Neon/Supabase + Stripe + Cloudflare R2. Меняются только 4 адаптера (`adapters/payments`, `adapters/storage`, `adapters/email`, хостинг). Бизнес-логика не трогается.

**Платёжная стратегия (обновлено 2026-06-17):**
- Фаза 1: ЮKassa (Россия, самозанятость) — сейчас
- Фаза 2: открыть ИП в Армении + Stripe — триггер: первые реальные доходы, НЕ ждать физического переезда. Причина: деньги из ЮKassa не выводятся на армянский счёт (санкции/ограничения переводов), а жить и тратить в Армении нужно будет. Два адаптера работают параллельно.
- Фаза 3: Stripe основной, ЮKassa закрывается. Долгосрочная цель — международная аудитория всех стран.

**Why:** Dual-deployment (RU + международный) — единственный законный путь обслуживать оба рынка. Adapter-архитектура проекта для этого и сделана.

**How to apply:** При планировании деплоев учитывать, что первый деплой — Yandex Cloud (не Railway/Vercel/AWS). При первых доходах напомнить про ИП в Армении + Stripe. Международная инфраструктура добавляется рядом, не заменяет.
