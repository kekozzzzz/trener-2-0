Решено 2026-06-20: добавить поддержку комнат сети Winning Poker Network — **ACR Poker и PokerKing** (одна сеть, общий формат → один парсер на обе). Это отдельный парсер, НЕ расширение регулярки: формат WPN отличается от GGPoker почти всюду (заголовок `Game Hand #`, Hero — реальный ник из `Dealt to <ник>`, действия без двоеточия, суммы с копейками, нет названия турнира и бай-ина в заголовке). У GG-парсера к комнате привязан только один шлагбаум в `parser/ggpoker/index.ts` (`RC-GGPoker-`), всё остальное в `hand.ts` формат-нейтрально.

Метрика «результат в бай-инах»: была всегда `+0.00` (баг — бай-ин не читался, считалась разница стеков двух раздач, не покрыта тестами). Проверено на реальном файле (110 раздач): **в HH вообще нет денег** — ни `$`, ни места, ни приза. Денежный ROI из хенд-хистори невычислим. **Решение: результат турнира убран из показа совсем** (список, страница турнира, статус — сделано). Денежный ROI вернём на **кэш-игре** (там win/loss за сессию чистый) или через отдельный парсер «сводки турнира».

**ЗАДЕЛАНО 2026-06-29 (НЕ закоммичено, НЕ задеплоено):** WPN-парсер написан и проверен.
