Когда заходит речь о новом, отдельном от текущего репозитория проекте (не связанном по теме) — Артём заводит для него отдельную папку и открывает её отдельной сессией/окном VS Code, а не продолжает работу над ним в чате текущего проекта, даже если файлы технически лежат по абсолютному пути и путаницы в файловой системе не возникло бы.

**Why:** 2026-08-13, при создании `Desktop\проект` (общие правила, не связанные с покером, для будущих проектов) — предложил провести интервью по идее прямо в текущем чате «Тренер 2.0». Артём остановил: «я думал, это будет в отдельной сессии... чтобы тут у нас с мешаниной не получилось». Смешивание — не про файлы, а про контекст чата: история, память сессии, тема разговора должны соответствовать теме проекта.

**How to apply:** Когда создаётся или обсуждается новый несвязанный проект — не пытаться сразу вести содержательную работу по нему (интервью по идее, код, контент) в текущей сессии другого проекта. Подготовить каркас (файлы, структуру) можно и в текущей сессии по прямой просьбе, но содержательное продолжение — предложить перенести в новую сессию/окно на папке нового проекта, не предполагать, что "раз уже здесь — можно и дальше здесь". Согласуется с [[feedback_marketing_catalog_sync]] (соседние репозитории не трогаем) — тот же принцип разделения контекстов, но шире: не только "не трогать чужой репо", а "новая тема = новая сессия" по умолчанию.
