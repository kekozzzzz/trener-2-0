- **HUD-миф «VPIP надёжен с 20 рук»**: на n=20 интервал [6%,44%] — от нита до маньяка. Реально:
  100 рук ±8 п.п., 500 ±4, 1000 ±2.5.
- ⚠️Раздачи СКОРРЕЛИРОВАНЫ → эффективное n меньше счётчика → реальные полосы ШИРЕ формулы (цифры
