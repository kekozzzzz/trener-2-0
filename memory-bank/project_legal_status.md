Юридический статус (ранее) не был оформлен — намеренно отложен до стадии выкатки MVP. Артём знает, что нужна самозанятость.

**Минимум для старта:** самозанятый (НПД) — самый быстрый и дешёвый старт. Регистрация за 10 минут в приложении «Мой налог», без визита в налоговую.

**Ограничения самозанятого, важные для продукта:**
- Лимит дохода 2.4 млн ₽/год (~$26k). При курсе ~90 ₽/$ это ~200 платящих пользователей по $12/мес — потолок достижим за 1–2 года успешного роста.
- Нельзя нанимать сотрудников по трудовому договору.
- Когда лимит приближается → переход на ИП (УСН 6%).

**Что нужно сделать до первой оплаты:**
1. Зарегистрировать самозанятость в приложении «Мой налог» (или Сбербанк/Тинькофф — интегрировано)
2. Привязать расчётный счёт (обычный физлица подходит для самозанятого)
3. Подключить ЮKassa (принимают самозанятых)
4. Заполнить `.business/company/legal.md`

**Why:** ЮKassa не подключается без юридического статуса. Платить налог как самозанятый — 6% с юрлиц/ИП (таких как ЮKassa-мерчанты), 4% с физлиц. Для SaaS-подписок — скорее всего 6%.

**How to apply:** Напоминать при любом разговоре о деплое, ЮKassa, первых платящих пользователях или финансах продукта.
