Когда собираешь конкретный Reel/видео из [[project_allclips_canonical_folder]] (`.business/marketing/all-clips/`) — фиксировать, какие номера клипов (`1.mp4`, `3.mp4`, `10.mp4`...) пошли в этот конкретный ролик, и для какого дня/поста. Записывать в `all-clips/index.md` (отдельный раздел «Использование» или колонка «в каком ролике») сразу после сборки, не постфактум.

**Why:** Артём мыслит и командует по номерам клипов («поменяй десятый на другой») — без записи, какой номер пошёл в какой конкретный ролик, каждая такая команда потребует заново поднимать контекст (какой ролик, какая сборка), это лишний раунд вопросов.

**How to apply:** Сразу после того как собран ролик с использованием клипов из `all-clips/` — дописать в `index.md` факт: список номеров + для какого дня/ролика. Когда Артём говорит «замени N-й клип» — сначала смотреть в этой записи, для какого ролика был использован N-й, потом менять именно там, не переспрашивать с нуля.
