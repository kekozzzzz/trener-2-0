Мечение внешних ссылок на посты (GipsyTeam, Telegram, ...): `whygrid.app/go/<code>` — Route Handler (`app/go/[code]/route.ts`) ставит cookie `wg_src` первым касанием (90 дней, не перезаписывается повторным переходом по другой ссылке) и пишет строку в новую таблицу `landing_visits`; на регистрации `auth_events.utm_source` заполняется из этой cookie (по образцу уже существующего `country` по IP). Список источников — `config/acquisition-sources.ts`, добавление нового источника = одна строка в файле (Артём называет источник словом, я дописываю).

⚠️ **`code` в ссылке ≠ `slug` источника** (правка 2026-07-19, вторым сообщением после первой версии): ссылка нарочно непрозрачная — случайный 6-значный код (`294817`), не «gipsyteam»/«1»/«2» — чтобы по виду ссылки на форуме нельзя было догадаться, что это метка. Внутри (БД, `/admin`) источник хранится и показывается человекочитаемым `slug`/`label` как обычно. Новый источник → новый код подбирать вручную (любые 6 цифр без очевидного порядка), не по счётчику.

`/admin` переименован из «Статистика» в «Админ» (просьба Артёма 2026-07-19, и в навигации, и в заголовке страницы). Новый блок «Источники»: по каждому источнику — кнопка копирования готовой ссылки + счётчики заходов/регистраций (всего и за 30 дней).

**Почему не middleware/edge:** Next middleware по умолчанию Edge-рантайм, прямой Prisma-коннект там не работает надёжно — решили через обычный Route Handler (Node.js-рантайм по умолчанию), клиентский JS не понадобился вовсе.
