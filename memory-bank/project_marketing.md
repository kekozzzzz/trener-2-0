Артём ведёт маркетинг продукта (Whygrid / Тренер 2.0) вместе со мной. Вся стратегия, цифры и рабочие документы лежат локально в `.business/marketing/` (папка вне git) — туда и писать, не искать заново.

**Решение 2026-06-26:** ограничение «только личная сеть / форумы нельзя» СНЯТО — продукт живой с оплатой ЮKassa, перешли от теста спроса к привлечению. Первый бюджет **$300**, делим 50/50 (платный тест в Telegram / органика). Это бюджет на разведку (какой канал+сообщение цепляют), не на клиентов: в покер-нише активный игрок из TG-закупа ~$14, а подписка $12/мес.

**Ключевые опоры (в файлах .business/marketing/):**
- `channels.md` — состояние каналов + экономика + источники цифр. Яндекс.Директ/VK Реклама = НЕ ИДЁМ (покер в стоп-листе, блок аккаунта). Работаем через Telegram-закупы (telega.in/админы напрямую) + контент + GipsyTeam через пользу.
- `telegram-channel.md` — канал СОЗДАН 2026-06-26: @whygrid (t.me/whygrid), display «Whygrid — почему ты сливаешь», аватар design/whygrid-avatar.png (знак grid, центрирован через PIL). Готовы bio, рубрики (Слив-сцена / Один вопрос / Цифра, которую ты не считаешь), 5 стартовых постов, чек-лист запуска.
- `content.md`, `audience/avatar.md` — тон: **ROI-нарратив, не коучинг** («теряешь 1–2 бай-ина в месяц на одних и тех же ошибках»). Без AI-хайпа и GTO-жаргона.

**Главный рычаг:** бесплатное ядро — продаём не подписку, а бесплатный разбор раздачи. Целевая метрика рекламы — стоимость человека, загрузившего раздачу (< ~$1–1,5), потом % из них в платный диалог.

**Канон «один смысл везде» (2026-06-26):** `.business/marketing/messaging.md` — ЕДИНЫЙ источник правды по сообщению, любой текст сверять с ним. Ядро: слоган **«Почему ты сливаешь»**, три опоры (повторяющиеся ошибки → твои деньги → ты сам поймёшь через сократовский вопрос), крючок «первый разбор бесплатно». North-star метрика всех каналов одна — цена за «загрузил раздачу» → % купивших диалог, по UTM в Метрике. Стоп-лист: без «выигрыша/заработка», GTO, AI-хайпа, «бай-инов» и слова «базовые ошибки» (задевает думающего игрока). Аудит сайта: главная whygrid.app уже на сообщении, единственная рекомендованная правка — H1 «базовых ошибках» → «одних и тех же ошибках» (НЕ внесена в код, ждёт решения Артёма). Доп. файлы 2026-06-26: `copywriting.md` (слова-магниты/хуки/CTA), `growth-playbook.md` (рост канала/прогрев/free→paid/SEO), `INDEX.md` (карта папки).
