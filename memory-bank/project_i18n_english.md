Второй язык — английский, для нерусскоязычных гостей. План: `plans/2026-07-01-английский-язык.md`.

**Архитектура:** `next-intl` в режиме БЕЗ локали в URL (маршруты плоские, перекраивать под `/en` не стали). Язык хранится в куке `LOCALE`. Определение по браузеру (`Accept-Language`) прямо при отрисовке (кука → фолбэк на заголовок), плюс middleware ставит куку при первом заходе. Правило детекта: русскоязычный браузер → ru, ЛЮБОЙ другой → en (`i18n/config.ts` detectLocale). Клиент-безопасные константы в `i18n/config.ts`, серверное чтение куки в `i18n/locale.ts`, смена языка — серверный экшен `i18n/actions.ts`. Словари `messages/ru.json` + `messages/en.json` (namespace на страницу). Глобус-переключатель `components/lang-switcher.tsx` в общей шапке `auth-nav.tsx`.
