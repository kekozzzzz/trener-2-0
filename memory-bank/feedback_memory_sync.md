Когда статус фичи меняется (особенно «задеплоено» / «не задеплоено»), сразу правь И индекс `MEMORY.md`, И подробный файл фичи — не оставляй расхождения между ними. Артём ловил, что я «забываю» уже сделанное, потому что индексная строка и тело файла спорили (напр. касса/деплой 28-го: индекс говорил «задеплоено», а файлы фич всё ещё «НЕ задеплоено»).

**Why:** каждый новый чат стартует только с индекса; если индекс или файлы врут — я осторожничаю и переспрашиваю про уже готовое, теряю доверие. graphify знает только структуру кода, статусы проекта он не хранит — это работа памяти.

**How to apply:**
- После деплоя/мёрджа прошёлся по затронутым записям и снял «НЕ задеплоено» в ОБОИХ местах (индекс + файл).
- Сверяй с реальностью (git log/коммиты/миграции), а не только с тем, что память пишет сама про себя.
- Если запись устарела/перекрыта другой — помечай «⤳ УСТАРЕЛО, см. [[...]]», не оставляй два конфликтующих факта как равные.
- Если на файл ссылается строка индекса, а в теле файла факта нет — допиши факт в файл (указатель не должен вести в пустоту).
