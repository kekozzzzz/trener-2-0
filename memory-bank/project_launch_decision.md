Артём принял решение (2026-06-09) строить сразу нормальный самосервисный продукт — без этапа "сначала три ручных оплаты".

**Обоснование:** схема с ручными переводами не работает на практике — никто не будет платить лично незнакомому человеку, чтобы получить доступ к сайту. Это убивает доверие ещё до того, как человек увидел продукт.

**Риск принят осознанно:** "Прогорим — увы. Буду сам учиться покером зарабатывать."

**Что значит "нормальный сайт":** человек заходит, сам регистрируется, сам платит картой, сам загружает файл, сам получает результат. Без участия Артёма.

**Why:** ручная схема — не продукт, а "кружок по интересам". Самосервис — единственная рабочая модель для незнакомых пользователей.

**How to apply:** Запрет 6 (не строить инфраструктуру до 3 оплат) фактически отменён этим решением. При планировании задач — строим полноценный продукт сразу. Приоритет: оплата + регистрация → сократовский диалог → дизайн → деплой.
