**Найдено 2026-08-21:** Артём увидел рекламу в Telegram-канале GipsyTeam — сервис
`baseanalise.com/ru`, разовый персональный видео-разбор ВСЕЙ базы рук игрока человеком-
экспертом ($490–1690 за пакет, гарантия возврата после 100 000 рук без улучшения).
Разная ниша (регуляры до NL1000, не микролимитчики), разная модель (разовая покупка,
не подписка) — не прямой конкурент, но навёл на идею.

**Идея:** единый СВОДНЫЙ ОТЧЁТ по всей истории рук игрока сразу, а не по турниру/раздаче
за раз — «вот твои главные системные утечки за всё время игры», одним читаемым текстом.

**У нас уже есть строительные блоки для этого:**
- [[project_leak_tracker]] — 9 детекторов системных ликов без LLM, уже считает паттерны между турнирами
- [[project_trainer_spot_memory]] — отпечаток спота, похожие раздачи, дневник тренера (coach_notes)
- [[project_opponent_profiling]] — профиль соперника из повторных встреч

Чего нет — единого агрегирующего отчёта-витрины, который собирал бы всё это в один
читаемый разбор «твои главные утечки за всю историю», а не разрозненные детекторы,
разбросанные по разным экранам.

**Статус: ИДЕЯ, НЕ ПЛАН.** Это полноценная новая фича продукта, не мелкая правка —
требует отдельного плана (`plans/`) и явного обсуждения с Артёмом (что именно показывать,
триггер показа, где в UI, как не превратить в очередной «трекер ликов 2.0»), не начинать
писать код с наскока по итогам разбора конкурента. Записано в `.business/marketing/
competitors.md` рядом с самим конкурентом — там же полное описание Baseanalise.
