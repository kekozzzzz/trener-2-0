# Сканирующая подсветка при скролле

Полоса чуть ниже статус-строки «сканирует» страницу: текст/блок с атрибутом `data-glow`, проезжая через неё, подсвечивается, уезжает — гаснет. LIVE на главной с 18.08.2026, задокументировано в `design/design-system.md` §4.1 п.14.

Два уровня, назначаются осознанно по месту (не «через один»):
- **soft** (по умолчанию) — только аура (`box-shadow`), для второстепенного содержимого (пример, иллюстрация).
- **strong** (`data-tier="strong"`) — рамка + заголовок загораются лаймом, для цифр-доказательств.

Механизм — `components/site/scroll-glow.tsx`, один экземпляр в корневом layout. Прямой расчёт позиции на каждом кадре скролла (`requestAnimationFrame` + `getBoundingClientRect`), НЕ `IntersectionObserver` — см. reference-заметку про IntersectionObserver в «Разное» ниже в этом же индексе. Первая версия на Observer была ненадёжна (часть блоков не загоралась вовсе, другие «залипали» подсвеченными на сотни лишних пикселей) и переписана в тот же день.

Переиспользуемый проп `scrollGlow?: "soft" | "strong"` есть на `Tilt`, `BentoCell`, `Tile`, `ProductWindow`, `StatRow` (`components/site/detail.tsx`) — подключить на новом месте просто.

**Why:** заказ Артёма 18.08.2026, одобрено по прототипу `design/scroll-highlight-preview.html` перед переносом в продукт.

**Как расширить:** сейчас подключено только на главной (`app/page.tsx`). Если Артём попросит расширить на другие страницы (`/about`, `/charts`, `/pricing` и т.д.) — механизм уже готов, нужно только расставить `scrollGlow`/`data-glow` по месту, без доработки самого компонента.

Заодно 18.08.2026 убраны два статичных световых пятна фона (`backdrop-glow-tr`/`backdrop-glow-bl` в `components/site/backdrop.tsx`) — конфликтовали с новым эффектом визуально, Артём поймал сразу.
