БУДУЩАЯ ФИЧА (заметка Артёма 2026-06-30, «нужно будет внедрять»): показывать ИТОГ турнира — призовые / место / сколько голов выбил (нокауты). Перед внедрением — карта доступности данных по румам, проверена по РЕАЛЬНЫМ файлам игрока (Test/ и Test/руки/, 2026-06-30). Все файлы в Test/ настоящие, кроме скачанных образцов в Test/samples/.

## Приз / место (финиш турнира)
- **PokerStars** — ИНЛАЙН прямо в раздачах: «X finished the tournament in Nth place» + приз. Всё в одном файле, удобнее всех.
- **GGPoker** — в файле раздач НЕТ; только ОТДЕЛЬНЫЙ маленький файл-сводка «Tournament Summary» (место + сумма, напр. «1639th : Hero, $2 / You finished … 1639th place / received $2»). Сводка легко отсутствует: из 2 GG-турниров игрока была лишь для одного (#291235125 есть, #289598162 нет).
- **Winamax** — в файлах раздач НЕТ (это нарезки по ОДНОЙ раздаче, имя вида `НАЗВАНИЕ(id)#0004.txt`); нужен отдельный summary-файл рума.
- **888poker** — в файлах раздач НЕТ (нарезки по столам, `ID #<turnir> Table #<n>.txt`); нужен отдельный summary.

## Выбитые головы / бонти (нокауты)
- **PokerStars** — ДА полностью: цена головы у каждого в сид-листе (`$15 bounty`) + события выбивания инлайн. Реально посчитать, кого выбил.
- **Winamax** — ЧАСТИЧНО: цена головы у каждого в сид-листе (`9€ bounty`), но явных строк «кого выбил» нет — вычислять по переходу головы. Только KO-турниры.
- **GGPoker** — НЕТ нигде: в раздачах «Bounty» только в НАЗВАНИИ турнира («Bounty Hunters Deepstack»), не события; в сводке числа выбитых тоже нет.
- **888poker** — в имеющихся файлах бонти нет (турниры не-нокаутные, `$20+$2` = фи). KO-турниры 888 не проверялись.

## Выводы для внедрения
- Полный итог (место+приз+бонти) ИНЛАЙН даёт ТОЛЬКО PokerStars. Для GG/Winamax/888 нужен отдельный файл-сводка рума → парсер должен уметь его (а) распознавать, (б) склеивать с турниром по id. У GG сводка = текущий UNSUPPORTED_FORMAT (parser/index.ts отдаёт ошибку на 273-байтовом summary — научить распознавать как сводку, не как HH).
- Для GG придётся просить игрока грузить ещё и файл-сводку (иначе приза нет, а нокаутов нет в принципе).
- Покрытие по выбитым головам неровное: полное — PokerStars, частичное (вычислять) — Winamax, нет — GG/888.
- ГЕРОЙ по румам: в GG аноним «Hero»; в PS/Winamax/888 — РЕАЛЬНЫЙ ник игрока, парсер вычисляет героя по открытым картам (а не по метке «Hero»).
