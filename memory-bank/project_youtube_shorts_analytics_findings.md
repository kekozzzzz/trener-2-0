Разобрано 7 Shorts с 08.08 по 17.08.2026 по скринам аналитики YouTube Studio (Артём присылал по каждому ролику отдельно). Ключевые находки:

**Хронологический разрыв в удержании.** Три самых старых ролика (8, 9, 11 авг) — «продолжили смотреть» 18,2% / 34,1% / 36,2%. Четыре свежих (13-17 авг) — 60,0% / 50,6% / 56,0% / 53,6%. Граница ровная, без переходных значений между старыми и новыми.

**Доля аудитории из России растёт монотонно по датам публикации**: 28,8% → 32,1% → 55,3% → 71,1% → 91,0% → 92,0% (шесть точек подряд без единого отката назад). Вероятное объяснение — не смена контента, а то, что алгоритм YouTube постепенно «понял» целевую аудиторию канала по мере регулярных публикаций и стал сужать раздачу именно на неё; старые ролики изначально уходили шире, в СНГ и дальнее зарубежье, отсюда и хуже удержание — нецелевая аудитория быстрее отваливается.

**Целевая аудитория подтверждена точно**: 97-100% мужчины, ядро 25-34 года, преимущественно с телефона — совпадает с профилем микролимитного турнирного игрока GGPoker.

**Длина ролика не критична для вовлечённости.** Более длинные ролики (28-32 сек) закономерно теряют % полного досмотра, но доля «заинтересованных просмотров» и «продолжили смотреть» не хуже, иногда даже лучше, чем у 17-секундных — не обязательно резать всё под 15-17 сек ради метрик.

**Reach ≠ resonance.** Ролик от 8 авг получил средний охват (1070 просмотров) при худшем в выборке удержании (18,2%) — попадание в ленту и удержание внимания оказались независимыми метриками, нельзя судить о качестве ролика по одним просмотрам.

**Сравнение «какой хук работает лучше» пока невозможно** — кликов на сайт почти нет ([[project_youtube_link_restriction]]), поэтому судить можно только по удержанию/охвату, не по реальной конверсии в регистрации.

Why: разбирали вместе с Артёмом 18.08.2026 по скринам аналитики семи роликов, чтобы понять, что реально работает в контенте до появления возможности мерить клики.

How to apply: при разборе новых Shorts сравнивать с этими цифрами как базой. Ожидать, что доля RU-аудитории и удержание продолжат расти естественным образом по мере регулярности публикаций — не обязательно приписывать рост конкретным правкам в контенте. Не делать выводов «этот хук лучше того» на основе одних просмотров без учёта даты публикации и без данных о кликах.
