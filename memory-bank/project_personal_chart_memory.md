Фича-направление (обсуждено 2026-06-29, ещё один пункт к памяти тренера, рядом с [[project_trainer_spot_memory]]): у игрока копится **личный чарт открытия** как поправка-дельта поверх базового RFI-чарта ([[project_training_rfi_chart]]), чтобы тренер не флагал раз за разом широкий опен, который для этого игрока осознанно нормален.

Решения по конструкции (выбор Артёма):
- **Поправка поверх базового**, не полная замена. База остаётся опорой, личное — дельта (список рук «отсюда открываю шире»).
- **Копит улики, не с одного спора.** Один аргумент чарт не меняет: тренер помечает спорный спот (инфраструктура памяти спотов уже есть) и считает повторы; на 2-3-м одинаковом обоснованном споре рука уходит в личную дельту.
- Судит по-прежнему парсер детерминированно (Правило 1 цело) — сравнивает опены с базой+дельтой; ИИ лишь ловит спор и двигает счётчик, планку не считает.
- Защита от размывания коучинга встроена: даже по расширенной личной планке кривой опен всё равно подсвечивается. Дельта — не индульгенция.

Открытый момент UI: показывать игроку накопленный личный чарт (что система про него «выучила», с возможностью поправить), иначе дельта = невидимая магия.

## Связка: «твои примерные чарты» (визуализация фактических открывашек)
Идея Артёма 2026-06-29, тесно сцеплена с дельтой выше. Отдельная КНОПКА (не на весь экран, панель/модалка) «как ты открываешься» — сетка 13×13 (переиспользуем компонент из [[project_opponent_range_grid]]) на каждую позицию, строится из РЕАЛЬНО сыгранных рук по прошествии ~30 турниров.

Сетка как ЗЕРКАЛО, не учебник. ОДНА сетка — **его факт** (как реально открывался, со счётчиком «K4o ×4»). Дельта — НЕ второй слой/чарт, а правило ПОДСВЕТКИ на этой же сетке: отстоянные клетки гаснут (спокойные), неотстоянные нестандартные — горят с вопросом «почему так часто?». Уточнение (Артём 2026-06-29): не «два слоя для сравнения» — игрок смотрит на одну вещь, на себя; дельта лишь решает, какая клетка под вопросом, какая спокойная. Помечать ли отстоянные явно (зелёным) или просто не зажигать — мелкая UI-деталь (зелёная пометка нужна лишь для прозрачности «система записала это как мой стиль, поправь если зря»). Кормит фичу выше: постоянно-горящая клетка → либо коучинг, либо в дельту.

### Развилка метрики (Артём, 2026-06-29): судить по ЕГО данным, не по нашему чарту
Идея Артёма: красить клетки не по отклонению от базового RFI, а по ЕГО СОБСТВЕННОМУ результату — наводишь на руку, видишь сколько фишек выиграл/проиграл этой рукой из этой позиции за последние ~30 турниров (постоянно обновляется); красный=минус, зелёный=плюс, серый=около нуля. Плюс идеи: вообще снимает спор «чей чарт правильный / учим или нет» — ничего не навязываем, данные сами задают вопрос.
**КРИТИЧЕСКИЙ КАВЕАТ (мина): результат по конкретной руке за 30 турниров = почти чистая ДИСПЕРСИЯ, не скилл.** ~15-20 рук на AKs за дистанцию: один кулер красит клетку, цвет отражает как зашла карта, а не игру. Красить отдельные клетки по фишкам = учим играть ОТ РЕЗУЛЬТАТА (рыбное мышление) — ровно то, от чего лечим. НЕ делать так в лоб.
Как спасти идею «по его данным», не толкая в results-oriented:
- Серый по умолчанию, не красить пока руку не сыграли N+ раз (для большинства рук за 30 турниров так и останется серой — честно).
- Укрупнять, а не 169 клеток: красить ГРУППЫ (мелкие пары, слабые тузы, suited-коннекторы) — выборка копится быстрее, цвет начинает значить.
- Красный = «давай посмотрим/звоночек к разбору», НЕ приговор «плохо»: горящая клетка заносит спот в сократовский диалог («отсюда минус за дистанцию — игра или не шло?»), судит разговор, не цифра.

### Ориентир по выборке (research 2026-06-29, web): ЧАСТОТА ≠ РЕЗУЛЬТАТ
Числа из интернета, наш порог точности:
- **Частоты/тенденции (как открывается)** сходятся быстро: базовые префлоп-стат (VPIP/PFR/опен%) вменяемы с ~20-50 рук, надёжны 500-1000 рук; открывашки ПО ПОЗИЦИИ ~300-1000 рук. В МТТ играешь ~30-50 рук/турнир → позиционные открывашки набираются за **~15-30 турниров**. → интуиция Артёма «30 турниров» ВЕРНА для зеркала «как ты открываешься».
- **Результат/EV (сколько приносит рука)** сходится в сотни раз медленнее: кэш-винрейт бессмыслен < 50k рук, надёжен 100-200k; МТТ-ROI — ~1000 турниров для прикидки, 3000-5000 для доверия (игрок с ROI 30% идёт 200+ турниров без крупной оплаты). → красить клетки по плюс-минусу НЕЛЬЗЯ на нашем объёме — подтверждает мину выше.
- **Отдельная клетка vs группа:** даже частота надёжна по позиции и по ГРУППАМ рук, не по каждой из 169 клеток (конкретный AKs ~раз в 300 рук × нужная позиция → 30 случаев = десятки тысяч рук/сотни турниров). Подтверждает «укрупнять».
**ИТОГ-ОРИЕНТИР:** порог **~30 турниров (~1000 рук)** для зеркала «как открываешься по позициям и группам рук»; деньги/EV по конкретной руке из цвета убрать совсем. Сетка = про ИГРУ (частоты), не про РЕЗУЛЬТАТ.
Источники: pokertrainer.se, pokerstrategy.com, mosesbet.com (MTT ROI), nsdpoker.com, smartpokerstudy.com (HUD), blackrain79.com.

### Принципиальное решение (Артём, 2026-06-29): слой «как надо» НЕ показывать
Тонкий продуктовый момент. Базовый RFI-чарт игроку на экране НЕ рисуем как «эталон, копируй» — иначе продукт превращается в ещё одно чарт-приложение (которых сотня) и теряет сократовскую нишу (Правило 4). Плюс чарты Артёма средние/примерные/личные — выдавать их за истину = размывать их же.
- База остаётся ПОД КАПОТОМ: решает, что подсветить, но сама не отображается как ответ.
- Красная клетка = не «делай так», а повод для вопроса «отсюда открываешь это часто — почему?» → сократовский диалог → обоснует (в дельту) ИЛИ сам увидит течь.
- Формула: обучаем тем, что игрок сам себя увидел в зеркале, НЕ выданным ответом. Зеркало + вопрос = мы; готовый чарт на экране = уже не мы.

Конструктивные решения/каветы:
- Размер выборки — главный риск: ~1000 клеток × мало турниров → большинство рук видены 1-2 раза. Красить красным только при N+ повторах, ВСЕГДА показывать счётчик, не ярлык «плохой». Слово «примерные» в названии оставить (честно про точность).
- «Открылся как говно» = мягкий порог (заметно вне базы, ~2+ «кольца» шире), НЕ любая нестандартная рука — иначе сетка вся красная и подсветка обесценится. ← решение к обдумыванию, склоняемся к мягкому порогу.
- Детерминированно, без LLM (агрегация по сыгранному, как [[project_player_characteristic]] «точно от 10 турниров»); Правило 1 цело. Вероятно тариф средний+макс, как тренажёр.
